# 知识、法师与魔法社会演变

状态：知识激活、普遍潜能、法师亲自引导和家族垄断已确认；具体家族制度、激活仪式和普及速度待定。

## 法师由知识产生

所有人体内都有休眠纳米机器人。成为法师的关键不是继承罕见的超自然血统，而是学习如何识别、唤醒、稳定并控制体内的纳米机器人。

绝大多数人都具有成为潜在法师的可能。个体在学习速度、控制精度、个人储备和身体承受能力上可以存在差异，但这些差异通常不构成无法跨越的世袭边界。

这意味着魔法潜能在生物层面相对公平，实际魔法能力却会因为知识、教育、时间、资源和社会权力分配而高度不平等。

当代居民不知道自己在激活纳米机器人。他们可能将这一过程解释为建立魔力回路、唤醒灵性、打开内在之门、接受启蒙或获得神秘学资格。正式名称待文化体系确定后再设计。

## 初次激活必须由法师引导

准确知识是激活的核心，但只有文字、图形和自我练习不足以让休眠纳米机器人完成第一次稳定唤醒。学徒必须由一名掌握引导方法的现役法师亲自指导。

底层机制可以理解为：引导师先以自身活跃纳米机器人建立可响应状态，再通过精确的声音、动作、接触或局部魔力协调，帮助学徒体内的休眠个体完成第一次同步。人物层面只会把它理解为传承、启蒙或导师点燃了学徒的内在魔力。

引导不等于直接赐予能力。学徒仍需事先学习身体感知、发音、注意力和安全知识，并在激活后自行完成稳定训练。没有准备的强行引导可以失败，具体风险待定。

并非每一名刚激活的法师都自动知道如何引导别人。引导术本身属于更高层的传承知识，法师家族可以只教授给被允许延续家族知识的人，从而长期控制新法师的产生速度。

## 为什么当前仍不是全民法师社会

“理论上能够学习”不等于“现实中容易获得”。法师数量可以受到以下现实条件限制：

- 大多数人缺少识字、数学、符号和系统训练；
- 初次激活必须得到掌握引导术的现役法师亲自协助；
- 准确发音、呼吸、动作和注意力控制难以只靠文字自学；
- 错误知识可能无效或伤害身体；
- 学习需要大量不直接生产食物的时间；
- 私人教师、法阵材料和适合训练的魔力环境由法师家族控制；
- 法师家族限制基础知识、引导术和高阶法术传播；
- 普通人可能被灌输“只有特定血脉才能施法”的观念；
- 未经许可激活可能被定义为犯罪、异端或危险行为。

因此，法师稀少首先是家族传承和知识传播受限的结果，而不是世界法则只偏爱少数血统。

## 法师家族取代法师学院

世界不设置面向社会公开招生、独立于家族传承的法师学院。绝大部分魔法知识由法师家族掌控，并通过私授、口传、家族手稿和个人引导延续。

“法师家族”不必只由严格的生物血亲组成。为了延续知识，它可以通过婚姻、收养、赐姓、宣誓、师徒关系或吸收附属家庭扩展，但新成员必须被纳入家族权力和保密体系。

家族内部可能存在：

- 只传给少数继承人的引导术；
- 分阶段开放的法术手稿；
- 由长寿法师亲自保存的口传细节；
- 对旁支、婚入者和外姓学徒不同的知识权限；
- 禁止私自引导外人的家规；
- 通过联姻、交换继承人或共同仪式完成的知识交易。

不同家族可以长期掌握不同法术传统。缺少学院统一整理后，同一种效果可能存在多套互不兼容的发音、动作和解释，错误、残缺和家族偏见也会随传承延续。

## 能力不是简单的会与不会

魔法成长可以形成连续层级，而不是一次激活后立刻掌握强大法术：

```text
休眠者
  → 知道激活理论
  → 初次成功唤醒个人储备
  → 学会维持和感知
  → 掌握低风险基础调用
  → 形成专业法术知识
  → 能够协调大范围环境魔力
```

初次激活只代表体内纳米机器人开始响应。施法者仍需学习目标控制、环境判断、安全限制和具体发音组合。一个刚激活的人可以获得轻微的恢复和感知变化，却不能因此立即释放战争法术。

这使普通教育、职业训练和高阶研究都能在世界中具有实际价值。

## 知识垄断形成的社会结构

如果少数法师家族长期控制激活方法，它们就同时控制：

- 更强健且长寿的人口；
- 医疗与高阶生产能力；
- 战争中的施法者；
- 对魔法理论的解释权；
- 下一代法师的筛选和认证；
- 对魔力丰饶区和训练资源的使用权。

法师阶层的长寿还会强化这种垄断。高阶法师可以积累跨越普通人数代的财富、职位、秘密和人际网络，使知识不平等逐渐固化成类似血统的不平等。

即使“魔法血统论”在底层事实中并不成立，法师家庭仍可能因为教育、营养、资料和导师优势而连续产生法师，从而让社会误以为能力主要由遗传决定。

## 起义与知识解放

一旦有人证明普通人经过正确训练也能激活，魔法知识就可能成为政治事件的核心：

- 地下教师秘密训练矿工、农民和士兵；
- 脱离家族的法师秘密引导外人；
- 军队招募或强迫引导师，成批指导平民以扩充施法者兵力；
- 起义者争取家族叛离者，并夺取手稿和私人训练场；
- 教会将未经授权的激活称为亵渎；
- 统治者要求登记所有觉醒者；
- 改革派要求把基础魔法教育列为公共权利；
- 垄断集团散布激活必然致死或只有贵族血脉有效的宣传。

知识传播会改变力量分布，但不会让所有人立刻平等。新法师仍需要资源、组织、安全训练和环境魔力，错误的普及方式还可能造成事故和地区魔力透支。

## 从低魔社会走向高魔社会

世界是否属于低魔或高魔，不只取决于纳米机器人总量，也取决于有多少人掌握调用知识。

```text
知识被少数组织垄断
  → 法师稀少，魔法主要服务统治、宗教和战争
  → 激活方法开始传播
  → 基础魔法进入生产、医疗和日常生活
  → 社会需要新的教育、法律和魔力资源制度
  → 世界逐渐进入高魔阶段
```

这一转变可以由世界自主运行产生，而不需要预先写成固定剧情。一次战争、家族分裂、引导师叛逃、秘密传承链形成或大规模起义，都可能提高魔法知识和亲自引导的可获得性。

高魔化同时会提高地区魔力消耗。法师人口增长可能带来能源节点争夺、城市魔力配给、贫魔区扩大、生产方式改革和对新补充来源的探索。因此“知识解放”既能改善普通人的生活，也会产生新的资源与治理问题。

## 需要继续决定

1. 初次激活是一次永久变化，还是需要长期维持。
2. 一名引导师一次可以指导多少人，以及自身需要付出什么代价。
3. 激活训练通常需要几天、数月还是数年。
4. 错误激活只是失败，还是可能造成疾病、失控和死亡。
5. 儿童、成年人和老年人的激活难度是否不同。
6. 当前时代有多少人口知道“普通人也能成为法师”。
7. 法师家族如何决定直系、旁支、婚入者和外人能够获得多少知识。
8. 国家、教会和普通贵族如何与不受学院统辖的法师家族相处。
9. 当前世界正处于稳定垄断期，还是已经出现知识扩散的早期征兆。
