# 世界表层与隐藏真相

状态：核心方向已确认；历史年表、文明身份和专有名称待定。

## 核心命题

这个世界的表层是经典而自洽的剑与魔法世界，底层则建立在一个失落科技侧文明留下的星球环境和遗迹之上。

前文明不是前期题材，也不是随处可见的“科幻皮肤”。当代居民生活在王国、领地、教会、法师组织、商会和冒险者构成的现实社会中。魔法对他们而言是真实且可重复观察的自然现象，而不是等待被揭穿的骗局。

设计层可以暂时使用“前文明”指代失落文明，但它不是当代居民已知的正式名称。

## 多重历史覆盖

世界至少具有以下历史层次，具体年代待后续确定：

```text
失落科技侧文明
  ↓ 发生尚未命名的历史断裂
早期魔法文明
  ↓ 多轮兴衰、迁徙和战争
古代王国与宗教文明
  ↓
当前剑与魔法文明
```

当代人熟悉的古代城堡、法师塔、王陵、神庙、地下都市和战争堡垒，主要属于后来的魔法文明。真正的前文明设施位于更深的地层、封闭区域或尚未被识别的结构内部。

一个后世神庙可以建立在未知能源节点上，一座法师塔可以借用了深层结构产生的异常环境，但建造者不必知道底层设施存在。探索者即使抵达所谓“遗迹最深处”，也可能仍停留在后世覆盖层。

## 当代居民的概念边界

除极北龙族封闭社会外，当代居民能够理解：

- 锻造、建筑、机关、水车和航海等具体工艺；
- 魔法、炼金术、符文、血脉和宗教仪式；
- 人工制造物、自然物、生命与灵体等本地分类。

这些外部文明没有一个能够对应现代“科技体系”的分类概念，也没有机器、程序、网络、纳米尺度或人工智能所需的知识基础。

因此，面对真正的前文明造物时，他们不能得出“这是科技设备”的结论。他们甚至可能无法确认它是被制造出来的，因为它没有接缝、工具痕迹、符文、魔力或已知材料结构。

极北龙族社会是作者层面的唯一已确认例外。它完整保存了前文明知识体系，能够正确理解和使用相关技术；但这一例外被地理隔离、AI命令和信息控制封闭，不能自动成为外部人物的常识。

人物可以观察，不能越过知识基础直接分类。例如：

> 那面灰白之壁既非石也非铁。火焰不能使其升温，法术也无法触及它。第三日，壁面在无人触碰时出现了一道开口。

不能从人物视角写成：

> 探险队发现了一扇自动门。

“自动门”已经包含人物不可能拥有的用途判断和运行原理。

## 前文明造物的表现原则

真正的前文明造物首先应当表现为“不符合当前世界规律”，而不是“明显来自未来”。

可以观察到的性质包括：

- 材料既不像石、木、金属，也没有已知的加工痕迹；
- 表面无缝、无法切割，或者受损后缓慢恢复；
- 不表现出已知魔力，却能自行改变形态或造成效果；
- 内部尺寸、温度、洁净程度或空间结构违背当前经验；
- 对特定声音、血液、人物或时间产生重复反应；
- 建筑各部分具有超出当前测量能力的精确关系。

不应频繁使用以下直接泄露科幻类型的表现：

- 现代显示屏、键盘、线缆和按钮；
- 可被当代人直接读懂的状态文字；
- 主动解释自身用途的通用人工智能；
- 完整播放前文明历史的影像说明；
- 明显仿照现代枪械、实验室或飞船走廊的外观。

高度发展的前文明不必保留二十一世纪设备形态。它的设施可以将计算、制造、储存和交互整合进材料与空间本身。

## 多种错误解释可以长期并存

面对同一个无法理解的物体，不同文化和人物可以产生互相矛盾的解释：

- 教会认为它存在于诸神创造现世之前；
- 法师认为它位于现有魔法法则之外；
- 学者拒绝判断，只记录可重复现象；
- 贵族将其与祖先血脉和统治合法性联系；
- 当地居民将其视为灾祸、禁地或不应命名之物。

这些解释都不自动接近底层真相。世界开局时不设置一个掌握完整真相的全知秘密组织；即使存在残留管理智能，其资料和记忆也可以损坏、残缺或无法与当代语言互译。

## 长期揭露层级

下表用于作者控制秘密深度，不代表当代居民拥有这些术语：

| 层级 | 可被人物建立的认识 |
|---|---|
| 1 | 世界存在魔法、神明、魔物和已知古代文明遗迹 |
| 2 | 魔法具有严格、可重复并可被系统研究的规律 |
| 3 | 少数结构比任何有记录的魔法文明都更古老，且无法归类 |
| 4 | 多类异常之间可能存在共同联系，但其媒介和运行方式未知 |
| 5 | 世界生态、种族或魔法环境可能曾受到某种外部力量塑造 |
| 6 | 只有在形成全新知识体系并获得大量证据后，才可能逼近星球和前文明的真实历史 |

大多数人物终其一生只接触第一层。顶尖研究者也可能只到达第二或第三层。第四层以后应由罕见的跨地区、跨世代证据推动，不能通过一次鉴定术或单座遗迹直接获得。

## 客观事实与人物认知分离

未来世界数据需要同时保存：

```text
底层客观事实
  → 人物实际观察到的现象
  → 人物基于文化和知识作出的解释
  → 主视角目前知道的内容
```

例如：

| 层级 | 记录内容 |
|---|---|
| 底层客观事实 | 某深层结构正在对进入者进行身份认证 |
| 人物观察 | 无缝墙面在某人靠近后出现开口 |
| 人物解释 | 墙壁可能记住了某种血脉或誓言 |
| 主视角知识 | 只显示主视角亲历、获知并尚未遗忘的部分 |

普通事件日志、人物记忆和正式表现层不得使用底层术语替人物解释现象。管理员需要调试底层真相时，应进入明确隔离的作者视图，不能把该信息混入主视角界面。
