# 伊瑟拉生命起源与种系

状态：基源种族的共同祖先框架、三大演化超支、分化年代与迁徙路线已确认。本文件是作者层生物谱系事实；各文化的创世神话、种族起源故事可以与底层不同。

## 红线

1. 全部物种来自**本土生命演化**；星外前文明不是任何种族的祖先、播种者或改造者。
2. 不是"同一批被改造的人类"；各族为**多个生态位各自演化出的智慧谱系**。
3. 种族生理 ≠ 文化 ≠ 个人特质(继承 05 号拆分原则)。
4. **作者层 vs 民俗**：本文件的真实生物谱系是作者层事实；各文化的起源故事是解释，不得误当底层真相。
5. 本文件不新增基源种族、不改变 05 号已确认的种族名单、不改变灰精灵/蜥蜴人的已定来历。

## 共同祖先框架

各族共享本星球生命的**远古非智慧远祖**，但分属互相远缘的演化超支，各自独立走向智慧。对"共同祖先"的回答是：共同的是**生命起点**，不是单个智慧祖先。这就解释了为何各族生理差异如此之大——它们来自不同的演化支，而非同源近亲各自变异。

## 三大演化超支与各族归属

各族按生理与生态位划入三个互相远缘的动物超支：

| 超支 | 生物来源 | 包含种族 | 共性来源 |
|---|---|---|---|
| **睿兽支** | 温血、社会性、直立的哺乳—灵长演化 | 人类、精灵、兽人、巨人、地精 | 类人形态、手势/语言、社会性，由不同生态位分化 |
| **主龙支** | 鳞甲、高认知恒温演化的爬行—主龙 | 龙族、蜥蜴人 | 鳞片、耐湿、较强魔力感知 |
| **麟土支** | 穴居、致密、震动感知的地行演化 | 矮人 | 致密身体、低重心、地下适应 |

同超支内各族由不同生态位分化；不同超支之间生物上互相远亲。这解释了为何人类与精灵都"类人"却差异巨大、为何矮人矮而致密、为何龙族与蜥蜴人相似，而三者之间彼此远缘。

## 谱系树

```text
本星球生命起点
 ├─ 主龙支(最早)→ 龙族│蜥蜴人(人类×龙族混合)
 ├─ 麟土支   → 矮人
 └─ 睿兽支
     ├─ 巨人(高原孤立生态位)
     ├─ 精灵(古林/湖林,长寿低生育)
     ├─ 兽人(草原/高地,高体能)
     ├─ 地精(丘陵/湿地,短寿群体)
     └─ 人类(河谷/海岸,适应最广)
```

## 分化年代(环前相对时序)

| 年代层 | 事件 |
|---|---|
| 环前远古 | 本星球生命起点；三大超支分离；主龙支(龙族)出现最早 |
| 环前上古 | 麟土支(矮人)、巨人(高原)出现 |
| 环前中古 | 精灵(古林)、兽人(草原)、地精(湿地)演化 |
| 环前近代 | 人类(河谷)扩散；各族在 Noryia 连通大陆迁徙，形成当今 21 州分布(29) |

## 迁徙与当前分布

各族从起源生态位居向 Noryia 连通大陆扩散，形成当今 21 州分布(见 `29-noryia-nations-and-factions.md`)：

- **人类**：河谷、温带海岸与开放平原 → 米尔斯塔、唐瓦利亚、厄特兰等州。
- **精灵**：古老林地、湖林与高魔力稳定区 → 奥勒林、凯斯鲁利尔、谢姆纳塞卢、卡里昂、叶斯梅尔等州。
- **矮人**：山脉、深层岩谷与地下水系统 → 吉鲁扎尔、索尔卡、托尔纳格、迪盖兹等州(新图"尤顿/巨人"模板映射为矮人)。
- **地精**：破碎丘陵、湿地边缘与高风险资源区 → 恩盖、比奥克、泽里奥、弗瑞阿加布、布拉特、巴格等州(新图"狗头人/哥布林"模板映射为地精)。
- **兽人**：草原、高地与季节性资源边界 → 格鲁尔边地及部分护路/护航誓团。
- **巨人**：高原、孤立山地与低密度资源区 → 稀少，仅少数高地与海岸集会地；新图不再有巨人主导政体(W029/W078)。
- **龙族**：环前极北与高纬度海陆交错生态环境 —— 几乎不迁，对外仅传说与极少数伪装观察者。
- **灰精灵**：雾幕山林与湖林西缘(见 22 号)；**蜥蜴人**：苇湾河口 → 斯拉克大公国(新图"蛛形"模板映射为蜥蜴人，见 22 号)。

这些分布与 `18-states-cultures-and-conflicts.md` 各政体的主导种族分布一致，也与各族在 `05-species-and-cultures.md` 中的生态位描述相符。

## 作者层 vs 民俗的边界

底层真实谱系是作者层事实。当代各文化的创世神话、祖灵故事、宗教起源叙述属于解释，可能与底层不同、彼此矛盾。模型只能把文化起源故事当作可观察的文化说法，不能据此推断真实的生物谱系关系，也不能把任一文化叙述当成客观真相。
