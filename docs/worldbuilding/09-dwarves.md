# 矮人种族卡

状态：普通与法师寿命、成熟、世代、身体、震动感知、材料固化、物性调律、人口和社会制度已确认；隐藏起源待统一谱系阶段讨论。

## 定位

矮人是第一版主要基源种族之一。其寿命只比人类更长，不采用接近精灵的超长生命周期。身体、材料感知与固化魔法方向仍是讨论草案，尚未确认为世界事实。

## 已确认寿命

- 普通矮人的自然寿命约为100至150年；
- 当前世界条件下的常见实际寿命约为75至110年；
- 矿井事故、粉尘、坍塌、地下疾病、战争、营养和劳动条件会使许多矮人提前死亡；
- 普通矮人法师常见寿命约为180至250年；
- 少数强大、生活稳定且很少长期透支的矮人法师可以达到300至350年。

此前提出的180至220年普通自然寿命草案已经作废，不能继续作为后续设计依据。

## 成熟与世代

- 矮人大约在17至20岁完成主要身体成熟；
- 社会成年因文化、职业与家族制度不同，通常位于20至30岁；
- 平均世代间隔约为30至40年；
- 生育率和人口增长速度仍待确认。

矮人法师寿命通常高于人类法师，但明显低于普通精灵，更不会接近精灵法师的千年层级。

## 身体结构

- 成年矮人身高约1米，个体会在这一基准附近自然波动；
- 肩部、胸腔和骨盆较宽，骨骼和肌肉密度高于人类；
- 重心低，站立稳定，抓握、负重和持续发力能力较强；
- 力量体重比很高，但绝对力量不会仅凭种族自动超过体型更大的专业战士；
- 短距离移动速度中等，长距离奔跑、跨越和跳跃能力较弱；
- 身体散热能力较差，不适合在炎热潮湿环境中长期高强度活动；
- 身体密度使游泳和水上自救更加困难，需要专门训练。

约1米的身高会影响矮人的实际生活：地下通道、住宅、家具、工具、车辆和防御工事可以采用更小尺度；人类进入传统矮人设施时可能需要弯腰或无法携带大型装备，矮人在以人类尺度建造的城市中也会面对使用障碍。

矮人的身体优势不等于每个成员都是战士、矿工或铁匠。职业能力仍然来自训练、知识、工具和经历。

## 地下环境适应

- 对低温、低照度和昼夜变化不明显的环境适应较好；
- 呼吸道对普通矿尘有一定防护，但不能免疫粉尘疾病；
- 能在较低照度下辨认物体，但不能在完全黑暗中直接视物；
- 对封闭空间的方向、距离和结构变化判断较准确；
- 长期生活在地表的矮人能够适应阳光，不设置见光虚弱。

矮人适合地下环境，不代表其生理结构强迫所有个体住在地下。

## 震动与结构感知

矮人的手掌、足部、骨骼传导和内耳对细微震动较为敏感。通过直接或间接接触固体，并结合敲击、倾听和经验，他们可以判断：

- 附近是否存在持续移动；
- 岩壁后是否可能存在空洞；
- 建筑内部是否产生新的裂纹；
- 器物是否承受异常压力；
- 敲击回声是否与材料外观一致。

这种能力具有明确限制：

- 必须接触连续的固体介质；
- 复杂结构只能提供模糊信息；
- 城市、工坊和战场中的大量震动会形成干扰；
- 距离越远，判断越不可靠；
- 需要训练才能区分自然、生产活动和生物移动；
- 不能直接得知材料名称、物品用途、所有者或历史。

面对真正的前文明无缝材料时，矮人可能比其他种族更早确认它不具有正常岩层或金属结构，但仍然无法把它识别为科技造物。

## 魔法特点：材料固化

矮人魔法倾向把魔纹固定在固体材料内部，让魔力场与材料结构长期耦合并维持稳定状态。当代矮人会用符文、锻造祝福、炉火仪式、石之记忆或材料契约等本地概念解释这一过程。

矮人适合：

- 修复材料内部的微小裂纹；
- 提高武器、工具和建筑的结构稳定性；
- 加固墙壁、桥梁和矿井；
- 降低机械震动和磨损；
- 固定需要长期维持的法术效果；
- 制造储存少量魔力或持续从环境取能的器物。

材料品质、结构设计、魔纹精度、可用魔力和施法者知识都会限制结果。矮人不能凭空制造无条件不可破坏或永远运行的物品。

## 两类固化效果

### 结构改变

魔纹推动材料内部结构重新达到稳定状态，例如去除裂纹、改善受力、重新排列部分结构或让部件精确结合。效果完成后可以在很少持续耗能的情况下保留。

### 持续运行

持续魔纹需要长期留在物品中，执行自动修复、恒温、发光、主动减震、感应响应或其他复杂效果。此类器物需要自身储能、环境魔力或魔力水晶补充。

## 地区魔力与器物回收

固定在器物中的共振结构会束缚一部分场能，持续型器物还会不断从储能材料或周围抽取魔力。少数大型私有工坊的集中制造会降低周边可用魔力，使后续制造越来越困难。

```text
大量制造魔法器物
  → 场能被器物束缚并持续抽取
  → 工坊地区魔力下降
  → 新器物制造成本上升
  → 等待补充、迁移生产或回收旧物
```

器物被正确拆解后，束缚的场能可以逐渐释放，持续抽取也会停止；粗暴损坏可能造成残留干涉、能量逸散或危险失稳。由此可以在法师家族和大型工坊内部形成魔力配额、旧器物回收、报废物拆解权和战争征收等制度，但尚未形成城市级公共魔法网络。

## 魔法倾向与弱项

| 项目 | 矮人倾向 |
|---|---|
| 身体强化 | 强 |
| 材料感知 | 很强 |
| 法术固化 | 很强 |
| 长期稳定 | 很强 |
| 远距离控制 | 较弱 |
| 空中自由塑形 | 较弱 |
| 幻觉类法术 | 较弱 |
| 快速连续变化 | 较弱 |

较弱不代表不能学习，而是需要更多训练和能量。人类可以学习矮人固化方法，但难以仅凭知识复制矮人对材料内部变化的感知优势。

## 法师家族与材料传统

不同矮人法师家族可以分别保存岩石与建筑、金属与武器、陶瓷与耐热结构、晶体与魔力储存、机械减震或封印维护等传统。

工坊可以训练普通工匠，但不等于法师学院。初次激活、引导术和真正的家族魔法仍由法师家族私有并亲自传承。

## 生育与人口

矮人生育率略低于人类、明显高于精灵。稳定地区人口通常每年增长约0%至0.3%，新矿区或粮食充足地区可以达到约0.3%至0.7%；矿难、战争、通风崩溃和贸易中断会迅速造成负增长。

地下城市的人口承载受到淡水、通风、排污、承重、地区魔力、食物贸易和安全开采空间共同限制，不能只靠继续开凿房间无限扩张。

## 家庭、工坊与法师家族

- 家庭负责亲属、抚养、生活和私人继承；
- 工坊负责生产、职业训练、合同和长期工程；
- 法师家族掌握激活、引导和材料魔法；
- 工程共同体可以由多个家庭、工坊和法师共同组成。

矮人可以离开出生家庭加入其他工坊，也可以从事农业、医疗、贸易、行政、运输和其他职业。种族身体特点不能把所有人物锁定为矿工或铁匠。

## 三维土地与城市维护

地下土地需要分别处理地表入口、不同深度的隧道、上下岩层承重、地下水、通风、矿脉、废弃矿井和更深层结构。拥有某层矿脉不代表可以破坏上方城市的承重安全。

城市政治会围绕通风、水源、承重检查、法师工坊许可、器物回收、食物贸易、防御和坍塌救援形成。具体政体可以是国王、家族议会、工坊联盟或其他制度，但任何统治者都无法长期忽视实际维护者。

## 长期工程责任

- 重要器物和工程保存制作者与材料来源；
- 工坊需要承担约定的长期维护义务；
- 工坊消亡后必须转移仍未结束的维护责任；
- 隐瞒结构缺陷可能构成严重犯罪；
- 拆解旧器物前需要确认所有权、支撑作用和魔力后果；
- 看似废弃的构件仍可能承担城市其他部分的功能。

持续型器物束缚并抽取魔力，因此世家奢侈器物、战争征收、报废物拆解权、回收后释放的魔力归属和私人工坊造成的贫魔责任都会成为真实法律与政治问题。普通矮人城市不会因此自动拥有公共魔法供能和遍布全城的魔法设施。

## 地表贸易

地下城市通常需要从地表获得粮食、木材、纤维和部分药材，并输出矿物、耐用器具、工程服务和回收材料。地表战争与贸易封锁会直接威胁地下城市，地表矮人聚落也可以发展为农业、商贸和外交中心。

## 进阶魔法：物性调律

物性调律建立在材料感知与固化魔法之上。矮人法师可以在原材料允许的范围内，用魔纹改变材料与魔力场的耦合并推动结构重排，从而改变：

- 硬度与韧性；
- 弹性与刚性；
- 表面摩擦；
- 导热与隔热；
- 震动传递、吸收与特定频率响应。

当代矮人不使用物理性质或微观结构等现代术语，而会认为材料具有硬、韧、躁、静等性情，法师能够聆听、调整并固定材料的新性情。

### 永久调质

永久调质魔纹推动材料内部结构重排，例如消除裂纹、改善受力、调整弹性、改变孔隙或让部件精确结合。完成后只需要很少能量维持。

### 动态调节

动态魔纹让材料依据冲击、温度、震动或使用者产生变化，例如受击时提高刚性、过热时提高导热、主动减震或改变表面摩擦。动态调节需要持续供能，并长期占用更多可用魔力。

### 守恒与材料上限

1. 不能凭空创造质量或能量；
2. 不能同时把所有性质提高到极限；
3. 改变范围越大，时间、能量和魔力消耗越高；
4. 施法者通常需要接触并理解材料；
5. 不熟悉的材料更容易调整失败；
6. 超过承受范围会导致开裂、变形或效果失控；
7. 动态性质在魔力枯竭区会减弱或停止；
8. 未知的前文明材料无法只凭矮人感知直接修改。

### 性质取舍

| 提高的性质 | 可能代价 |
|---|---|
| 极端硬度 | 脆性增加 |
| 高弹性 | 承重稳定性下降 |
| 低摩擦 | 难以制动和抓握 |
| 高摩擦 | 磨损和发热增加 |
| 高导热 | 使用者更容易被烫伤 |
| 强隔热 | 内部热量难以散出 |
| 强减震 | 机械能传递效率下降 |

高水平矮人法师的价值不是无条件强化所有属性，而是依据用途在多种性质和代价之间取得平衡。

## 当前单纹边界

矮人当前掌握的加固、硬化、韧化、导热、减震等能力分别来自不同完整魔纹。每个魔纹具有固定核心效果，只能通过材料选择、供能和维持方式有限调整。

矮人尚不能把多个物性魔纹连接成会自行判断条件的复合系统。某些看似能够响应温度或冲击的珍贵器物，必须来自本身具有完整反馈结构的已发现单纹，矮人只能整体复制，不能自由设计其分支与循环。
