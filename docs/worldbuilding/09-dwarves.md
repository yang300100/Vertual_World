# 矮人种族卡

状态：普通与法师寿命、成熟、世代、身体和震动感知已确认；魔法、人口、社会和隐藏起源待讨论。

## 定位

矮人是第一版主要基源种族之一。其寿命只比人类更长，不采用接近精灵的超长生命周期。身体、材料感知与固化魔法方向仍是讨论草案，尚未确认为世界事实。

## 已确认寿命

- 普通矮人的自然寿命约为100至150年；
- 当前世界条件下的常见实际寿命约为75至110年；
- 矿井事故、粉尘、坍塌、地下疾病、战争、营养和劳动条件会使许多矮人提前死亡；
- 普通矮人法师常见寿命约为180至250年；
- 少数强大、生活稳定且很少长期透支的矮人法师可以达到300至350年。

此前提出的180至220年普通自然寿命草案已经作废，不能继续作为后续设计依据。

## 成熟与世代

- 矮人大约在17至20岁完成主要身体成熟；
- 社会成年因文化、职业与家族制度不同，通常位于20至30岁；
- 平均世代间隔约为30至40年；
- 生育率和人口增长速度仍待确认。

矮人法师寿命通常高于人类法师，但明显低于普通精灵，更不会接近精灵法师的千年层级。

## 身体结构

- 成年矮人身高约1米，个体会在这一基准附近自然波动；
- 肩部、胸腔和骨盆较宽，骨骼和肌肉密度高于人类；
- 重心低，站立稳定，抓握、负重和持续发力能力较强；
- 力量体重比很高，但绝对力量不会仅凭种族自动超过体型更大的专业战士；
- 短距离移动速度中等，长距离奔跑、跨越和跳跃能力较弱；
- 身体散热能力较差，不适合在炎热潮湿环境中长期高强度活动；
- 身体密度使游泳和水上自救更加困难，需要专门训练。

约1米的身高会影响矮人的实际生活：地下通道、住宅、家具、工具、车辆和防御工事可以采用更小尺度；人类进入传统矮人设施时可能需要弯腰或无法携带大型装备，矮人在以人类尺度建造的城市中也会面对使用障碍。

矮人的身体优势不等于每个成员都是战士、矿工或铁匠。职业能力仍然来自训练、知识、工具和经历。

## 地下环境适应

- 对低温、低照度和昼夜变化不明显的环境适应较好；
- 呼吸道对普通矿尘有一定防护，但不能免疫粉尘疾病；
- 能在较低照度下辨认物体，但不能在完全黑暗中直接视物；
- 对封闭空间的方向、距离和结构变化判断较准确；
- 长期生活在地表的矮人能够适应阳光，不设置见光虚弱。

矮人适合地下环境，不代表其生理结构强迫所有个体住在地下。

## 震动与结构感知

矮人的手掌、足部、骨骼传导和内耳对细微震动较为敏感。通过直接或间接接触固体，并结合敲击、倾听和经验，他们可以判断：

- 附近是否存在持续移动；
- 岩壁后是否可能存在空洞；
- 建筑内部是否产生新的裂纹；
- 器物是否承受异常压力；
- 敲击回声是否与材料外观一致。

这种能力具有明确限制：

- 必须接触连续的固体介质；
- 复杂结构只能提供模糊信息；
- 城市、工坊和战场中的大量震动会形成干扰；
- 距离越远，判断越不可靠；
- 需要训练才能区分自然、生产活动和生物移动；
- 不能直接得知材料名称、物品用途、所有者或历史。

面对真正的前文明无缝材料时，矮人可能比其他种族更早确认它不具有正常岩层或金属结构，但仍然无法把它识别为科技造物。

## 尚待确认

1. 身体强化、材料固化和长期稳定是否作为主要魔法特点。
2. 固化魔法是否长期占用材料内部的纳米机器人。
3. 生育率、人口增长、家庭、工坊、法师家族和政治制度。
4. 矮人在世界底层历史中的真实起源。
