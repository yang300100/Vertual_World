# 矮人种族卡

状态：普通与法师寿命、成熟、世代、身体、震动感知和材料固化魔法已确认；人口、社会和隐藏起源待讨论。

## 定位

矮人是第一版主要基源种族之一。其寿命只比人类更长，不采用接近精灵的超长生命周期。身体、材料感知与固化魔法方向仍是讨论草案，尚未确认为世界事实。

## 已确认寿命

- 普通矮人的自然寿命约为100至150年；
- 当前世界条件下的常见实际寿命约为75至110年；
- 矿井事故、粉尘、坍塌、地下疾病、战争、营养和劳动条件会使许多矮人提前死亡；
- 普通矮人法师常见寿命约为180至250年；
- 少数强大、生活稳定且很少长期透支的矮人法师可以达到300至350年。

此前提出的180至220年普通自然寿命草案已经作废，不能继续作为后续设计依据。

## 成熟与世代

- 矮人大约在17至20岁完成主要身体成熟；
- 社会成年因文化、职业与家族制度不同，通常位于20至30岁；
- 平均世代间隔约为30至40年；
- 生育率和人口增长速度仍待确认。

矮人法师寿命通常高于人类法师，但明显低于普通精灵，更不会接近精灵法师的千年层级。

## 身体结构

- 成年矮人身高约1米，个体会在这一基准附近自然波动；
- 肩部、胸腔和骨盆较宽，骨骼和肌肉密度高于人类；
- 重心低，站立稳定，抓握、负重和持续发力能力较强；
- 力量体重比很高，但绝对力量不会仅凭种族自动超过体型更大的专业战士；
- 短距离移动速度中等，长距离奔跑、跨越和跳跃能力较弱；
- 身体散热能力较差，不适合在炎热潮湿环境中长期高强度活动；
- 身体密度使游泳和水上自救更加困难，需要专门训练。

约1米的身高会影响矮人的实际生活：地下通道、住宅、家具、工具、车辆和防御工事可以采用更小尺度；人类进入传统矮人设施时可能需要弯腰或无法携带大型装备，矮人在以人类尺度建造的城市中也会面对使用障碍。

矮人的身体优势不等于每个成员都是战士、矿工或铁匠。职业能力仍然来自训练、知识、工具和经历。

## 地下环境适应

- 对低温、低照度和昼夜变化不明显的环境适应较好；
- 呼吸道对普通矿尘有一定防护，但不能免疫粉尘疾病；
- 能在较低照度下辨认物体，但不能在完全黑暗中直接视物；
- 对封闭空间的方向、距离和结构变化判断较准确；
- 长期生活在地表的矮人能够适应阳光，不设置见光虚弱。

矮人适合地下环境，不代表其生理结构强迫所有个体住在地下。

## 震动与结构感知

矮人的手掌、足部、骨骼传导和内耳对细微震动较为敏感。通过直接或间接接触固体，并结合敲击、倾听和经验，他们可以判断：

- 附近是否存在持续移动；
- 岩壁后是否可能存在空洞；
- 建筑内部是否产生新的裂纹；
- 器物是否承受异常压力；
- 敲击回声是否与材料外观一致。

这种能力具有明确限制：

- 必须接触连续的固体介质；
- 复杂结构只能提供模糊信息；
- 城市、工坊和战场中的大量震动会形成干扰；
- 距离越远，判断越不可靠；
- 需要训练才能区分自然、生产活动和生物移动；
- 不能直接得知材料名称、物品用途、所有者或历史。

面对真正的前文明无缝材料时，矮人可能比其他种族更早确认它不具有正常岩层或金属结构，但仍然无法把它识别为科技造物。

## 魔法特点：材料固化

矮人魔法倾向让纳米机器人进入固体材料，并长期维持一种稳定结构或效果。当代矮人会用符文、锻造祝福、炉火仪式、石之记忆或材料契约等本地概念解释这一过程。

矮人适合：

- 修复材料内部的微小裂纹；
- 提高武器、工具和建筑的结构稳定性；
- 加固墙壁、桥梁和矿井；
- 降低机械震动和磨损；
- 固定需要长期维持的法术效果；
- 制造储存少量魔力或持续从环境取能的器物。

材料品质、结构设计、纳米机器人数量和施法者知识都会限制结果。矮人不能凭空制造无条件不可破坏或永远运行的物品。

## 两类固化效果

### 结构改变

纳米机器人修整材料内部结构，例如去除裂纹、改善受力、重新排列部分结构或让部件精确结合。效果完成后可以在很少持续耗能的情况下保留。

### 持续运行

纳米机器人需要长期留在物品中，持续执行自动修复、恒温、发光、主动减震、身份响应或其他复杂效果。此类器物需要自身储能、环境魔力或魔力水晶补充。

## 地区魔力与器物回收

被固定在器物中的纳米机器人暂时无法参与地区中的其他魔法。大规模制造持续型器物会降低工坊周边的可用魔力，使后续制造越来越困难。

```text
大量制造魔法器物
  → 活跃纳米机器人被长期固定
  → 工坊地区魔力下降
  → 新器物制造成本上升
  → 等待补充、迁移生产或回收旧物
```

器物被正确拆解后，一部分纳米机器人可以重新释放；损坏、隔离或失去响应能力的个体可能长期留在材料中。由此可以形成工坊魔力配额、旧器物回收、报废物拆解权和战争征收等真实经济制度。

## 魔法倾向与弱项

| 项目 | 矮人倾向 |
|---|---|
| 身体强化 | 强 |
| 材料感知 | 很强 |
| 法术固化 | 很强 |
| 长期稳定 | 很强 |
| 远距离控制 | 较弱 |
| 空中自由塑形 | 较弱 |
| 幻觉类法术 | 较弱 |
| 快速连续变化 | 较弱 |

较弱不代表不能学习，而是需要更多训练和能量。人类可以学习矮人固化方法，但难以仅凭知识复制矮人对材料内部变化的感知优势。

## 法师家族与材料传统

不同矮人法师家族可以分别保存岩石与建筑、金属与武器、陶瓷与耐热结构、晶体与魔力储存、机械减震或封印维护等传统。

工坊可以训练普通工匠，但不等于法师学院。初次激活、引导术和真正的家族魔法仍由法师家族私有并亲自传承。

## 尚待确认

1. 生育率、人口增长、家庭、工坊、法师家族和政治制度。
2. 矮人在世界底层历史中的真实起源。
