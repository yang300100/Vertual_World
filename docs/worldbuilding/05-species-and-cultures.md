# 智慧种族与文化设计

状态：多智慧种族、差异化和区域谱系原则已确认；基源种族名单与各分支细节待逐一讨论。

## 已确认边界

正式世界不只存在人类，还存在精灵、地精以及后续可能加入的其他智慧种族。每个种族都应具有能够影响生活方式和历史选择的自身特点，不能只更换外表或名称。

与此同时，种族特点不能直接决定每个成员的性格、职业和道德立场。世界数据和叙事必须拆分：

```text
种族生理与感知倾向
  ≠ 所属文化和社会制度
  ≠ 家庭教育与阶层
  ≠ 人物个人特质和当前状态
```

同一种族可以拥有多个国家、宗教、语言和互相敌对的文化；同一文化也可以由多个种族共同组成。

## 基源种族与区域衍生族群

种族不能只用一张互不关联的平面名单表示。设计层应区分：

| 层级 | 含义 |
|---|---|
| 基源种族 | 能够作为一条主要生物谱系起点的种族 |
| 衍生分支 | 从一个基源种族长期分化出的稳定遗传群体 |
| 混合谱系 | 两个或多个种族产生并稳定繁衍的后代群体 |
| 改造谱系 | 因魔法、环境或其他力量发生可遗传变化的群体 |
| 地区文化 | 共享语言、制度和历史，但不一定具有独立生理谱系的人群 |
| 个体状态 | 诅咒、疾病、变形或其他不能稳定遗传的变化 |

所谓“区域种族”更准确地说是区域衍生族群。它必须能够回答自己从何而来、为何在该地区出现，以及如何成为能够延续的稳定群体。

## 衍生族群的形成链

每个区域衍生族群至少需要记录：

```text
祖先来源
  → 迁徙、混血、隔离、灾害或改造触发
  → 多代生理与魔法差异积累
  → 获得稳定繁衍能力
  → 形成共同身份和一种或多种文化
  → 与祖先和邻近族群产生新的关系
```

形成逻辑应同时回答：

1. 最初参与者是谁，人口规模是否足以延续。
2. 差异是遗传、生理适应、身体魔纹与魔力场耦合，还是纯文化结果。
3. 新特点经过多少代稳定下来。
4. 该群体能否继续与祖先种族繁衍。
5. 离开原地区后，新特点会保留、减弱还是消失。
6. 当代居民如何解释自己的来源，是否与底层事实一致。
7. 周边政权把他们视为独立种族、祖先分支、混血者还是某种社会身份。

只有文化、服饰或政治身份不同的群体，不应被设计层错误拆成新种族。反过来，已经具有稳定生理差异的谱系，也不必因为当代社会拒绝承认就从客观数据中消失。

## 第一版基源种族名单

### 主要基源种族

主要基源种族拥有足以形成多个稳定政权、文化和地区人口的规模：

```text
人类
精灵
矮人
地精
兽人
```

### 稀有基源种族

巨人具有独立谱系与完整智慧，但人口、繁衍或生存条件使其无法像主要种族一样形成高密度人口。

龙族对外部文明而言几乎只存在于古老传说，偶发目击也缺少能够被重复验证的证据。其真实人口与社会隐藏在极北封闭区域，完整保存前文明科技，并以巨型企业联合体构成高度发达的赛博朋克社会。

龙族观察外界时使用无法从外观识别的人类拟态身份。即使极少数个体以龙形出现，也只呈现符合外部时代认知的有机龙体与魔法现象，不携带可见科技改装。

### 暂不列入基源种族

- 亡灵、狼人和吸血鬼暂按死亡、疾病、诅咒或改造状态处理；
- 魔像属于被制造的造物；
- 恶魔、天使和灵体的客观分类仍待决定；
- 侏儒尚未加入正式种族名单。

## 已确认方向的区域谱系

灰精灵和蜥蜴人的谱系方向已经确认，具体历史、生理参数和形成机制仍待讨论。

### 蜥蜴人：人类与龙的稳定混合谱系

蜥蜴人由人类与龙的混血后代经过多代繁衍形成。要使其成为真正的稳定族群，后续需要解释：

- 龙与人类为何能够产生具有生育能力的后代；
- 最初是否有多个混血始祖，而非单一个体；
- 龙的形态变化、魔法或身体机制是否参与生殖兼容；
- 哪些龙类特征能够稳定遗传；
- 蜥蜴人是否仍可与人类或龙繁衍；
- 他们如何看待人类祖先与龙族来源。

### 灰精灵：精灵长期分化出的区域分支

灰精灵由某支精灵因迁徙、隔离和特殊环境长期演化形成。后续需要解释：

- 祖先为何离开其他精灵群体；
- 环境对身体、感知和魔法造成了什么选择压力；
- “灰”对应肤色、毛发、魔力表现还是外族称呼；
- 他们是否仍能与其他精灵繁衍；
- 生理分化和后来的文化分裂分别发生在何时；
- 灰精灵是否承认自己属于精灵分支。

这两个谱系已经确立来源方向，但具体答案需要后续讨论确认。

## 客观谱系与当代分类

世界底层保存真实的生物和历史谱系，当代人物只拥有各自文化中的分类。

例如，底层事实可以确认灰精灵来自某支精灵，但一个灰精灵政权可能宣称自己是完全独立的创世种族；人类学者也可能把外形相近却没有共同祖先的两个族群错误归为一类。

因此需要分开记录：

- 客观谱系关系；
- 各文化使用的种族名称；
- 人物相信的起源故事；
- 法律承认的身份；
- 个体自己的身份认同。

## 每个种族需要确定的维度

### 身体与生命周期

- 平均身高、体型和生理结构；
- 成熟速度、寿命和衰老方式；
- 繁衍方式、生育率和家庭周期；
- 对疾病、毒素、温度和食物的适应；
- 睡眠、恢复和基础体能。

### 感知与认知

- 视觉、听觉、嗅觉和魔力感知差异；
- 时间感、空间感和记忆特点；
- 是否存在特殊但有明确代价的感官能力；
- 身体结构如何影响工具、语言和建筑。

认知差异不能简单写成某个种族“更聪明”或“更愚蠢”。应优先设计擅长处理的信息类型、学习方式和生活环境。

### 魔法与身体魔纹

- 该种族身体通过何种结构与魔力场发生潜在耦合；
- 激活是否需要相同的核心魔纹共振引导；
- 个人储备、环境协调和身体维护是否存在统计差异；
- 不同种族的身体、感官和动作范围如何影响魔纹构建传统；
- 跨种族法师能否互相完成初次引导；
- 某些身体特点是否会提高一种能力，同时削弱另一种能力。

即使存在种族差异，知识和训练仍应当具有重要作用，不能轻易推翻已经确认的“魔法不是少数血统专属”原则。具体适用范围需要在逐个种族设计时确认。

### 生态与生产方式

- 最适合的栖息环境；
- 食物、土地、矿产和能源需求；
- 常见生产技术和交通方式；
- 人口密度与聚落规模；
- 与其他种族竞争或互补的资源。

### 社会与文化

- 亲属、家庭和继承制度；
- 国家、部落、城市或其他政治组织；
- 对法师家族和知识垄断的态度；
- 宗教、死亡观和历史记忆；
- 内部阶层、地区差异和政治冲突。

文化必须来自历史、环境和制度，不能把生物特点直接等同于文化命运。

### 跨种族关系

- 是否承认彼此为完整法律主体；
- 贸易、迁徙、通婚和共同定居是否存在；
- 法律如何处理跨种族家庭、继承和所有权；
- 不同寿命如何影响契约、外交和历史记忆；
- 偏见来自哪些真实历史事件或利益冲突。

“精灵”和“地精”目前仍是设计层暂用名称。正式设定需要避免直接照搬单一作品中的固定模板，尤其不能默认所有精灵高贵善良，或所有地精野蛮邪恶。

### 地精与侏儒的命名边界

本世界的“地精”对应哥布林式种族，而不是西方奇幻中常见的侏儒式小型工匠种族。

地精可以具有经典哥布林的外形辨识度，但它们是完整的智慧种族，不是供冒险者无条件讨伐的怪物类别。地精个体拥有财产、关系、记忆、政治立场和道德选择；地精社会也可以形成家庭、聚落、法律、贸易、战争与法师家族。

侏儒目前不属于已确认种族。如果以后加入，必须使用独立名称和谱系，不能与地精视为同义词。

## 人物数据原则

未来正式人物至少应分别关联：

- `species`：相对稳定的生理种族；
- `culture`：成长环境和学习到的文化；
- `family`：家庭、法师家族或其他亲属组织；
- `traits`：人物自身长期特质；
- `state`：人物当前身体、情绪和行动状态。

模型裁判不能仅凭种族标签决定人物行为。种族只提供身体条件和统计倾向，具体选择必须结合文化、利益、经历、关系、知识和当前处境。

## 下一步

第一版基源种族已经确定。接下来按人类、精灵、矮人、地精、兽人的顺序分别完成种族卡，并逐步连接精灵分支、混合族群和改造族群；每次只确定一个种族的生理、生命周期、魔法关系、文化分支和内部矛盾。
