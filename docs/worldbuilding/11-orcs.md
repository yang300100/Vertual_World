# 兽人种族卡

状态：身体、生命周期、食物需求和身体强化魔法已确认；人口、家庭、社会、传承制度和隐藏起源待讨论。

## 定位

本世界的兽人指经典 Orc 式智慧种族，不是所有兽形种族的统称。兽人拥有完整的人格、家庭、财产、法律、政治和文化能力，不能被默认写成战争种族或供其他种族讨伐的怪物。

兽人的核心是体型高大、身体耐久、能量消耗高；激活后的魔法擅长调动自身生理能力，能够产生强大短时爆发，但必须承担真实的营养、体力和组织损伤代价。

## 身体

- 成年身高约1.8至2.1米；
- 骨骼、肌肉和心肺能力较强；
- 绝对力量、负重和持续劳动能力在主要种族中较高；
- 伤口止血与基础恢复能力较好，但不能自动再生；
- 食物、蛋白质、水和生活空间需求高于人类；
- 狭窄空间、精细工具和小型种族设施使用不便。

兽人力量是种族平均倾向，不代替训练。没有战斗经验的兽人仍可能被专业的人类、矮人、精灵或地精战士击败。

## 生命周期

- 大约在14至16岁完成主要身体成熟；
- 社会成年因文化而异，通常位于16至20岁；
- 自然寿命约为65至85年；
- 当前世界条件下常见实际寿命约为45至60年；
- 平均世代间隔约为20至25年；
- 普通兽人法师常见寿命约为110至160年；
- 少数强大、生活稳定且很少长期透支的兽人法师可以达到180至220年。

战争、狩猎事故、高食物需求和强化透支会使许多兽人无法达到自然寿命。

## 魔法特点：身体调动

兽人体内纳米机器人激活后，倾向直接参与身体维护和短时强化。

| 项目 | 兽人倾向 |
|---|---|
| 个人储备 | 中等偏高 |
| 身体强化 | 很强 |
| 短时爆发 | 很强 |
| 痛觉与伤势控制 | 较强 |
| 外部精细控制 | 较弱 |
| 长期复杂法术 | 较弱 |
| 远距离施法 | 中等偏弱 |
| 透支风险 | 很高 |

兽人法师可以暂时提高肌肉输出、反应、耐力和恶劣环境承受能力，也可以控制出血、压制疼痛并维持受伤身体行动。具体知识仍需通过法师引导和训练获得，不是所有兽人的天生能力。

## 强化代价

纳米机器人不能凭空创造身体能量。短时强化会同时消耗个人储备、糖分、脂肪、水分、电解质、组织承载能力和原本用于身体治疗的纳米机器人。

过度强化可能导致：

- 肌肉撕裂；
- 骨骼和关节损伤；
- 高热与脱水；
- 心肺负担；
- 旧伤恶化；
- 强化结束后失去行动能力；
- 长期反复透支造成寿命折损。

因此兽人身体强化越强，施法者越需要训练、补给、恢复时间和对自身极限的判断。

## 尚待确认

1. 生育率、人口增长、聚落密度与食物承载。
2. 家庭、氏族、国家、游牧和定居社会的多种形态。
3. 兽人主要采用家族、战团、神殿、学校还是其他魔法传承制度。
4. 身体强化法师与治疗、生产、狩猎和战争之间的关系。
5. 兽人的主要文化、政权和与其他种族的历史关系。
6. 兽人在世界底层历史中的真实起源。
