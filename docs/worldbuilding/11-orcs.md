# 兽人种族卡

状态：身体、生命周期、食物需求、身体强化魔法、人口、家庭、誓团社会和导师传承已确认；具体文化与隐藏起源待讨论。

## 定位

本世界的兽人指经典 Orc 式智慧种族，不是所有兽形种族的统称。兽人拥有完整的人格、家庭、财产、法律、政治和文化能力，不能被默认写成战争种族或供其他种族讨伐的怪物。

兽人的核心是体型高大、身体耐久、能量消耗高；激活后的魔法擅长调动自身生理能力，能够产生强大短时爆发，但必须承担真实的营养、体力和组织损伤代价。

## 身体

- 成年身高约1.8至2.1米；
- 骨骼、肌肉和心肺能力较强；
- 绝对力量、负重和持续劳动能力在主要种族中较高；
- 伤口止血与基础恢复能力较好，但不能自动再生；
- 食物、蛋白质、水和生活空间需求高于人类；
- 狭窄空间、精细工具和小型种族设施使用不便。

兽人力量是种族平均倾向，不代替训练。没有战斗经验的兽人仍可能被专业的人类、矮人、精灵或地精战士击败。

## 生命周期

- 大约在14至16岁完成主要身体成熟；
- 社会成年因文化而异，通常位于16至20岁；
- 自然寿命约为65至85年；
- 当前世界条件下常见实际寿命约为45至60年；
- 平均世代间隔约为20至25年；
- 普通兽人法师常见寿命约为110至160年；
- 少数强大、生活稳定且很少长期透支的兽人法师可以达到180至220年。

战争、狩猎事故、高食物需求和强化透支会使许多兽人无法达到自然寿命。

## 魔法特点：身体调动

兽人激活后的稳定魔力共振与身体结构耦合较强，倾向直接参与身体维护和短时强化。

| 项目 | 兽人倾向 |
|---|---|
| 个人储备 | 中等偏高 |
| 身体强化 | 很强 |
| 短时爆发 | 很强 |
| 痛觉与伤势控制 | 较强 |
| 外部精细控制 | 较弱 |
| 长期复杂法术 | 较弱 |
| 远距离施法 | 中等偏弱 |
| 透支风险 | 很高 |

兽人法师可以暂时提高肌肉输出、反应、耐力和恶劣环境承受能力，也可以控制出血、压制疼痛并维持受伤身体行动。具体知识仍需通过法师引导和训练获得，不是所有兽人的天生能力。

## 强化代价

魔纹不能凭空创造身体能量。短时强化会同时消耗个人储备、糖分、脂肪、水分、电解质、组织承载能力和原本用于维持身体稳态的魔力。

过度强化可能导致：

- 肌肉撕裂；
- 骨骼和关节损伤；
- 高热与脱水；
- 心肺负担；
- 旧伤恶化；
- 强化结束后失去行动能力；
- 长期反复透支造成寿命折损。

因此兽人身体强化越强，施法者越需要训练、补给、恢复时间和对自身极限的判断。

## 人口与资源承载

兽人生育能力接近人类，但幼年和成年个体都需要更多食物和空间，因此人口增长主要受粮食、水源和牧群限制。

| 地区状态 | 年度人口趋势 |
|---|---:|
| 普通稳定地区 | 约0%至0.4%增长 |
| 牧群、粮食和水源充足 | 约0.5%至1%增长 |
| 连续歉收或迁徙受阻 | 快速负增长 |
| 高产农业与稳定医疗 | 人口明显扩张 |

大型兽人军队需要庞大补给系统，不能只靠强壮身体长期劫掠生存。食物供给、粮仓、水源、牧场和迁徙路线会成为重要政治资源。

## 多种社会形态

兽人可以形成草原牧民、山地氏族、河谷农业国家、沿海渔业聚落、多种族城市社区和依赖工程运输的定居社会。迁徙型社会拥有围绕水源、路线、季节和牧群建立的法律，并不天然比定居国家原始。

不同兽人文化可以对战争、财产、家庭和法师拥有完全不同的态度。身体强壮和强化魔法不能被模型直接推导为好战性格。

## 家庭与誓团

- 家庭负责亲属、抚养、私人财产和继承；
- 氏族可以提供更广泛的血缘互助；
- 誓团由成年人基于公开承诺自愿组成；
- 誓团可以负责狩猎、运输、建造、防御、医疗、生产或施法；
- 一个人可以退出旧誓团或建立新誓团，但需要处理已经承担的责任。

誓团不等于战团。治疗者、牧人、工程者、运输者和灾害救援者同样可以组成誓团。

## 实践型导师传承

兽人的身体强化风险很高，难以只靠文字学习。不同誓团可以由有经验的法师在真实劳动、狩猎、医疗、防御和救援中带领学徒。

学徒先学习营养、呼吸、伤势判断、停止强化和恢复，再由合格导师亲自完成激活。法师家族与国家机构可以存在，但不垄断所有兽人魔法知识。

## 强化魔法的非战争用途

身体调动可以用于搬运、工程、长途运输、高原与荒漠行动、伤势维持、坍塌救援、医疗恢复、农业和牧群管理。战争只是其中一种用途。

它也会产生劳动剥削风险：领主、国家或誓团首领可能强迫法师工人透支身体。强化劳动造成的伤害由谁负责、法师能否拒绝危险命令，会成为法律和政治问题。

## 尚待确认

1. 兽人的主要文化、政权和与其他种族的历史关系。
2. 不同兽人社会如何处理誓团退出、违誓、赔偿和国家征用。
3. 兽人在世界底层历史中的真实起源。
