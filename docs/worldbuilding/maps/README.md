# 世界地形地图图册

> **修订状态**：当前世界物理地图已切换为导入的 `map_new/Noryia.svg`(等距圆柱，单块连通大陆，见 `docs/worldbuilding/29-noryia-nations-and-factions.md`、W117)。本页旧列的四区地形图与政治图属"三大陆 + 13 政体"旧线，仅作旧线背景参考。

地图版本：`0.1-draft`

这些地图只表现自然地形，不是政治地图。国家、城市、道路、遗迹和人口分布将在后续世界观讨论中单独确定。

## 世界坐标与连续图册

- 所有地图共享同一套逻辑经纬度：经度 `[-180, 180]`，纬度 `[-90, 90]`；东经、北纬为正。
- `planet-master.png` 覆盖整个世界。`tiles/z1/` 的8张一级地图由母图确定性裁切并放大，可无缝拼回母图。
- 每张图的起止经纬度登记在 `atlas.json` 和数据库 `world_maps` 表中。内部切片使用半开区间 `[min, max)`；最东、最北边界包含终点，因此相邻地图边界连续，但坐标只归属一张切片。
- 人物、NPC、地点以及未来的建筑/奇观都保存世界经纬度；前端根据当前地图边界投影到像素位置，地图分辨率不是事实源。
- 重新生成一级地图：运行 `powershell -ExecutionPolicy Bypass -File scripts/render_world_map_tiles.ps1`。

## 候选语义地形与导航数据

`navigation/northern-main-continent/` 是北方主大陆第一版候选语义地形包，包含高程、海陆、坡度、地表、河流、道路、桥梁/港口/山口门户、高层路线图和审核叠加图。

这些数据全部标记为 `candidate`，只用于审核和路线规划原型，尚未接入真实数据库。生成规则、通行约束和审核顺序见 `docs/design/06-terrain-and-routing.md`。

## 已固定的宏观关系

```text
极北封闭区
      ↓ 冰海、风暴与长夜隔离
北方主大陆 —— 东方裂海群岛
      ↓
南方大陆
```

- 北方主大陆是初始故事的主要外部舞台；
- 南方大陆跨越赤道，拥有更强的日照与不同魔力恢复条件；
- 东方裂海群岛适合航海、火山、海峡和跨文化贸易；
- 极北封闭区只显示自然冰原，不在地图上标注龙族科技设施；
- 母图与分图的海岸线、山脉方向和主要水系应视为同一版地理参考。

## 使用边界

- 地图中的山脉、河流、湖泊、荒漠、冰架和森林是设计参考，不代表每条水系已经完成模拟；
- 未标注城市不代表该处无人，只代表政治与人口尚未设计；
- 极北地图不暴露龙族企业、城市或科技设施；
- 当前图册只绘制星球自然地表，不表现可从地表观测的轨道环状巨构；其视角大小、轨道和视觉规律确定后应单独制作天文结构图，不能直接画进自然地形母图；
- 后续国家边界应根据河流、山脉、资源、交通和历史事件生成，不能直接按种族平分大陆；
- 如果世界观改变宏观海岸线，必须同时更新母图与对应分图。
