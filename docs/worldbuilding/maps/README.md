# 世界地形地图图册

地图版本：`0.1-draft`

这些地图只表现自然地形，不是政治地图。国家、城市、道路、遗迹和人口分布将在后续世界观讨论中单独确定。

## 地图清单

| 文件 | 范围 | 用途 |
|---|---|---|
| `planet-master.png` | 整个星球 | 固定四大地理区域的相对位置、海岸线与极地关系 |
| `northern-main-continent.png` | 北方主大陆 | 初始世界主要舞台的山脉、河流、气候与地形基础 |
| `southern-continent.png` | 南方大陆 | 赤道雨林、草原、中央高原、内陆荒漠和南部温带地形 |
| `eastern-fractured-sea.png` | 东方裂海群岛 | 火山弧、岛链、海峡、内海和航海地理基础 |
| `far-northern-enclave.png` | 极北封闭区 | 冰原、山环、冰海和龙族区域的外部自然地貌 |

## 已固定的宏观关系

```text
极北封闭区
      ↓ 冰海、风暴与长夜隔离
北方主大陆 —— 东方裂海群岛
      ↓
南方大陆
```

- 北方主大陆是初始故事的主要外部舞台；
- 南方大陆跨越赤道，拥有更强的日照与不同魔力恢复条件；
- 东方裂海群岛适合航海、火山、海峡和跨文化贸易；
- 极北封闭区只显示自然冰原，不在地图上标注龙族科技设施；
- 母图与分图的海岸线、山脉方向和主要水系应视为同一版地理参考。

## 使用边界

- 地图中的山脉、河流、湖泊、荒漠、冰架和森林是设计参考，不代表每条水系已经完成模拟；
- 未标注城市不代表该处无人，只代表政治与人口尚未设计；
- 极北地图不暴露龙族企业、城市或科技设施；
- 后续国家边界应根据河流、山脉、资源、交通和历史事件生成，不能直接按种族平分大陆；
- 如果世界观改变宏观海岸线，必须同时更新母图与对应分图。
