## 图例与边界规则

- 半透明色块表示主要政体的有效行政范围或海域管辖范围；
- 粗黑线加彩色内线表示主要国界、盟约边界或海域行政边界；
- 与国家颜色相近的浅色虚线表示一级行政区之间的内部边界；行政区名称显示在对应国名卡的第三行；
- 金色圆点表示当前核心城市或季节性行政中心；
- “主导种族”表示在人口、公共语言和政治精英中占主导地位的主题族群；其他种族可以拥有完整公民、商旅、家族或地方身份，但不构成同等规模的统治族群；
- 山脉、河流、岛链、海峡和海岸是划界时的优先自然依据，行政边界不代表每一块边地都已完成细部测绘；
- 极北封闭区不制作公开政治地图，避免泄露龙族内部城市和设施。

## 重新渲染

在项目根目录运行：

```powershell
.\scripts\render_political_maps.ps1
```

脚本只重建 `political/` 下的政治地图，不会改写 `docs/worldbuilding/maps/` 中的自然地形原图。
