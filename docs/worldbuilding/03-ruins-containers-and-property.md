# 遗迹、容器与财产权

状态：无随机宝箱和财产权原则已确认；各地区法律与发掘制度待定。

## 不采用游戏式宝箱

正式世界不存在专门等待主视角开启的随机无主宝箱。剑与魔法社会可以拥有木箱、铁箱、货柜和保险柜，但它们是普通财产容器，不是奖励标记。

- 冒险者的补给属于冒险者。
- 军队物资属于军队、领主或国家。
- 商队货箱属于商人或委托人。
- 盗贼藏匿的赃物仍存在原主人和非法持有人。
- 坟墓中的陪葬品不会因为原主人死亡就自动成为无主物。

未经许可打开容器可能已经构成非法侵入；拿走其中物品可能构成盗窃、抢夺、侵占、盗墓、私吞证物或违反发掘契约。世界允许人物实施这些行为，但必须如实记录并产生法律、关系、声誉和组织后果。

## 真正前文明设施没有“科技宝箱”

前文明造物既不需要伪装成传统宝箱，也不应频繁表现为现代金属储物箱。高度发展的设施可以把储存、运输和制造整合进建筑材料与空间：

- 墙面在满足未知条件后形成开口；
- 物品从不可见的内部结构被送达；
- 某个空间长期保持密封、恒温或无尘；
- 设施在需要时现场形成器具；
- 身份不同的人靠近时得到完全不同的反应。

当代人物看到的是墙面变化、物体出现或某处无法进入，不会知道那里存在仓储、认证、物流或制造系统。人物视角不能使用“储物终端”“自动制造器”等底层用途名称。

## 可见遗迹主要属于后世文明

冒险者日常探索的城堡、王陵、法师塔、神庙和地下都市主要由后来的魔法文明建造。这里出现的传统箱柜符合当地历史，但依旧有明确用途和主人。

真正前文明结构通常位于更深处，可能被后世建筑包围、覆盖、崇拜或封锁。后世居民可以围绕异常区域生活数百年，而不知道建筑下方还存在另一层结构。

## 合法获得遗迹收益

冒险和探索的收益应来自有因果依据的制度，而不是看到容器就取得所有权。

### 发掘与探索契约

领主、国家、教会、法师家族、土地所有者或当地共同体可以签发许可，规定：

- 谁可以进入；
- 哪些物品可以带走；
- 哪些发现必须登记；
- 发掘物如何分成；
- 是否缴纳税款或研究样本；
- 危险物品必须交给谁保管。

### 主动交付

某个无法理解的深层结构可能在满足条件后主动交付物品。对当代人而言，这可能被解释为圣所赐物、誓约回应或血脉认可。底层是否属于合法权限转移，仍需后续设定，但至少不是人物擅自破坏容器并取走物品。

### 法律认可的打捞

无主状态需要由法律、契约或共同体规则认定，例如原组织灭亡、继承关系断绝、物品被明确遗弃，或在公示期限后无人提出有效主张。发现者不能仅凭“这里没人”自行宣布所有权。

### 悬赏、讨伐和战争所得

任务报酬、合法狩猎、战争缴获和犯罪证物分别受不同规则约束。强盗携带的财物可能需要归还原主，智慧魔物也可能拥有被某些社会承认的财产权，军队缴获物则可能受到军法和分配制度限制。

## 物品关系不能压缩成一个所有者

后续物品系统至少需要表达：

| 关系 | 含义 |
|---|---|
| 实际持有者 | 当前控制或携带物品的人物、组织或地点 |
| 原始所有者 | 物品最初属于谁 |
| 法律所有者 | 特定司法或文化体系承认谁拥有它 |
| 权利主张者 | 正在对物品提出所有权、继承权或宗教权利的实体 |
| 访问授权 | 某个容器或深层结构实际上允许谁接近和使用 |
| 发现者 | 谁在当前时代首先重新发现它 |
| 来源记录 | 物品历次生产、发现、转移、丢失和争夺事件 |

同一件遗物可以同时出现多种互相冲突的关系。例如冒险者实际持有，王国依据领土法主张所有，教会认为它是不可交易的圣物，而深层结构只对另一个人产生反应。

这些冲突不是数据错误，而是能够推动人物、组织和地区事件的世界事实。

## 表现层规则

正式表现层不应把所有可交互容器高亮为“战利品”。在人物拥有相关知识时，应优先显示：

- 可见外观和状态；
- 已知持有者或所有权标记；
- 人物是否获得进入、开启和取物许可；
- 角色自己对法律与风险的判断；
- 来源不明或存在争议时的不确定性。

“打开”和“取走”是不同动作。能够打开不等于有权取走，实际持有也不等于获得合法所有权。
