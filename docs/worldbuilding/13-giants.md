# 巨人种族卡

状态：身体、生命周期、稀少人口、分散亲族、周期集会和低频大型魔法已确认；具体文化、地区关系和隐藏起源待地理历史阶段讨论。

## 定位

巨人是人口极少的基源种族。其核心是身体巨大、资源需求高、生命周期较长，以小型亲族群体分散生活；魔法倾向低频、缓慢、大范围和高稳定，而不擅长快速精细施法。

巨人拥有完整人格、财产、关系、法律和历史记忆，不能因体型巨大被自动归为魔兽或无条件讨伐目标。

## 身体

- 成年身高约3至5米；
- 骨骼、关节与肌肉能够承担巨大体重；
- 绝对力量很强，但转向和精细动作受体型限制；
- 食物、水、居住和迁徙空间需求巨大；
- 无法正常使用其他种族建筑、车辆和工具；
- 单个巨人的迁徙就可能影响道路、农田和当地资源。

巨人不会无限生长。不同地区未来可以形成相对稳定的体型分支，但必须符合资源承载与谱系逻辑。

## 生命周期

- 大约在30至40岁完成主要身体成熟；
- 社会成年通常位于40至60岁；
- 自然寿命约为250至350年；
- 当前环境下常见实际寿命约为180至280年；
- 平均世代间隔约为80至120年；
- 生育率极低，一对巨人一生通常只养育少数后代。

战争、疾病和灾害造成的人口损失很难恢复，一名成年巨人死亡就可能改变整个地区的亲族结构。

## 社会结构

巨人主要生活在小型亲族群体中，常见地区包括孤立山谷、高原、冰原、大型森林边缘和其他普通种族难以利用的荒野。

多个家庭可以每隔数年或数十年在固定地点举行周期集会，用于：

- 交换消息与伴侣；
- 调解领地与迁徙争端；
- 传承口述历史和魔纹；
- 分配路线与资源；
- 共同处理灾害；
- 完成单个家庭无法承担的大型仪式。

集会结束后，各家庭再次分散。巨人不建立高密度城市，也不意味着其社会缺少规则和长期记忆。

## 施法介质与储能

巨人仍然依靠施法魔纹介质读取神经结构并投影单纹。常见介质可以是巨型石杖、整根树木、石柱、骨制长杖、图腾或山壁实体纹路。

巨人需要容量与输出都很高的储能石。此类物品充能缓慢、携带困难，并会明显消耗附近环境魔力，因此不会形成大量公共设施。

## 魔法倾向

| 项目 | 巨人倾向 |
|---|---|
| 安全输出 | 很高 |
| 控制速度 | 较慢 |
| 精细小范围控制 | 较弱 |
| 低频稳定效果 | 很强 |
| 大范围作用 | 较强 |
| 快速战斗施法 | 较弱 |
| 储能物品需求 | 极高 |

巨人可能保存加固山坡、改变震动、制造低频冲击、稳定冰川岩层、远距离传声和维持体温等完整单纹。这些仍是彼此独立的单纹，不代表巨人掌握复合语法。

## 与其他种族的关系

巨人可能与小型聚落交换保护和食物，被国家雇佣处理大型工程，因迁徙破坏农田而发生冲突，或守护某片土地数百年。

巨人能够记得其他国家已经遗忘的旧边界、誓约和灾难。现存政权是否承认这些古老主张，会成为地区事件的来源。

## 尚待确认

1. 巨人的主要地理分布和体型分支。
2. 不同亲族的文化、语言和集会制度。
3. 巨人与国家、兽人、矮人和极北地区的历史关系。
4. 巨人的储能石、施法介质和完整单纹来源。
5. 巨人在世界底层历史中的真实起源。
