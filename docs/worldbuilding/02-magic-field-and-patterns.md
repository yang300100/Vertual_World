# 魔力场、魔纹与人工魔法起源

状态：自然魔力场、天然魔纹、人类模仿起源、当前单纹低魔阶段、法杖施法魔纹、神经共振引导、储能物品与地区枯竭已确认；进阶组合语法仅为作者层与龙族知识。

## 魔力是自然规律

魔力不是前文明造物，也不依赖遗迹、纳米机器人、人工智能或任何仍在运行的设施。它是宇宙本身的一种基础场，如同光、电磁和引力一样天然存在，并以波动形式传播。

即使所有前文明造物彻底消失，魔力、魔兽、法师和魔法文明仍然能够继续发展。

设计层使用“魔力场”和“魔力波”描述其物理本质。当代文化可以使用魔力、地脉、元素、神恩、灵潮等不同名称。

## 魔力波的基本性质

魔力波至少具有以下可研究属性：

| 属性 | 作用 |
|---|---|
| 振幅 | 当前可用能量与效果强度 |
| 频率 | 更容易与哪些材料、生命或自然现象耦合 |
| 相位 | 多条魔力波叠加、抵消和同步的关系 |
| 波长 | 适合影响的空间尺度与传播特性 |
| 相干性 | 魔法能否保持稳定和精确 |
| 传播方向 | 能量与效果到达目标的路径 |
| 边界响应 | 不同材料、环境和生命对魔力的吸收、反射与引导 |

不同地区不仅具有魔力总量差异，也具有不同频谱、相干性和背景干扰。这使某些地区更适合精密治疗、长期法阵、热与光、材料加工或快速变化。

## 魔纹是什么

魔纹是能够约束、引导和组合魔力波的几何结构。它不是文字，也不是自然语言命令，更像天线、电路、透镜、共鸣腔或波纹干涉图。

特定纹路组合决定特定效果。魔力场不会理解施法者的愿望，也不会由隐藏意识选择实现方式。相同魔纹在相同材料、能量和环境条件下，应产生可重复的相近结果。

绘制图案本身通常不会产生魔法。有效魔纹至少需要：

```text
正确几何比例
+ 完整连接关系
+ 能够响应魔力的介质或投影
+ 足够的魔力输入
+ 闭合、点亮或其他启动条件
```

随机线条极少同时满足这些条件，因此不会让日常图案频繁意外施法。

## 二维有向闭合结构

当前文明掌握的单个魔纹是位于平面或物体曲面上的二维结构。曲面魔纹仍然是二维纹路，只是贴合在三维物体表面。

- 线条引导魔力波传播；
- 转折和交叉改变叠加与干涉关系；
- 封闭区域形成稳定共振与作用边界；
- 源点接收储能物品、魔力水晶或固定设施提供的环境供能；
- 有向关系规定魔力在纹路中的主要流向；
- 最后闭合使完整结构开始工作。

最终完整几何结构决定魔法效果。自然语言、愿望和绘制顺序不会改变核心功能。

### 朝向

魔纹平面的朝向决定主要输出方向。法师移动法杖是在调整投影位置、平面朝向、距离和大小，而不是用动作向魔力场下达命令。

### 缩放

同一魔纹可以在有限范围内等比例缩放。太小会无法稳定展开，太大会超过供能与控制能力；拉伸和局部比例变化会破坏共振。

### 旋转与镜像

- 普通旋转只改变空间朝向，不改变核心效果；
- 镜像可能反转有向关系，通常失效或产生危险异常；
- 缺线会使纹路无法闭合或只产生不完整响应；
- 不同线条粗细与介质必须保持在已验证容差内。

### 绘制与闭合

绘制顺序不决定最终效果。当前法师可以使用不同顺序准备同一魔纹，只需避免在其他部分完成前提前闭合。

魔纹未闭合时保持低响应；最后闭合只负责启动完整结构，不携带额外指令。

## 距离、范围与细节变体

一个完整单纹具有固定核心效果，但部分细节纹路允许在已知容差内变化，用于调整：

- 焦点距离；
- 输出扩散角；
- 作用截面大小；
- 近距离强度分布；
- 有效持续距离。

当前法师不会把这些细纹理解为参数模块，只知道家族或传承中验证过的若干画法。例如同一个火焰纹可能保存近距、标准和远距三种细节版本，核心火焰效果保持不变。

超出已验证范围会导致：

- 投影无法稳定；
- 能量提前逸散；
- 焦点偏移；
- 范围扩大但强度严重下降；
- 法术在抵达目标前瓦解；
- 魔力反冲法杖或储能物品。

距离越远，通常需要更高投影精度和更多能量。调整细纹不能让一个低功率储能物品无代价获得无限射程。

## 障碍与传播

绝大多数魔法不能无视障碍攻击其后方目标。法杖只决定投影方向和已知焦点距离，不会识别敌人、自动绕路或选择性跳过前方物体。

一般规则是：

```text
魔纹沿平面朝向输出
→ 效果沿对应介质传播
→ 遇到第一个足以吸收、阻挡或改变耦合的物体
→ 在障碍处发生作用、衰减、反射或失稳
```

能否穿透取决于魔法的耦合类型和障碍材料：

| 魔法类型 | 障碍表现 |
|---|---|
| 火焰、高温与可见光 | 通常被实体墙壁吸收或阻挡 |
| 动量、冲击与护盾 | 通常先作用于第一个实体物体 |
| 材料调律 | 通常需要接触或与目标处于连续材料结构中 |
| 震动 | 可以沿相连固体传播，但会受材料与接缝影响 |
| 声音 | 可以绕射或穿过部分结构，但衰减明显 |
| 热传导 | 可以通过连续材料缓慢传递，不等于隔墙瞬间攻击 |
| 光学隐蔽 | 受视线、遮挡和观察方向影响 |
| 治疗与生命作用 | 通常需要接触、近距或无遮挡的稳定投影 |

所谓穿透不是魔纹知道墙后有目标，而是对应波动本来能够在该介质中继续传播。法师无法攻击自己没有位置和路径信息的隐藏对象。

反射、折射和穿透还可能改变方向、频谱和强度。当前法师只能使用少量经验规则，无法像龙族设备一样实时计算复杂传播。

## 几何、频谱与物理效果

魔力通过完整魔纹时，会因线条、交叉、封闭区、有向关系和比例形成特定频率、相位与空间分布，设计层称为“耦合频谱”。

```text
魔力输入
→ 在二维魔纹中传播与干涉
→ 形成固定耦合频谱
→ 与某类物质或自然场交换能量
→ 产生固定核心效果
```

魔纹没有意识，不理解火焰、治疗、敌人、保护或愿望。几何决定频谱，频谱决定可以与什么发生作用。

### 热耦合

与物质热运动交换能量，用于加热、点燃、熔化和热量转移。低温魔法必须把目标热量转移到魔力场或其他区域，不能创造负能量。

### 动量耦合

建立场梯度并与物体交换动量，用于推动、拉拽、偏转、减速和护盾。强力效果必须承担反作用、环境扰动或额外场能消耗。

### 光与电耦合

与电磁现象交换能量，用于发光、闪光、电流、改变光线路径和视觉隐蔽。

### 材料耦合

影响材料内部受力与结构，用于硬化、韧化、减少裂纹、改变摩擦、导热和震动传递。矮人物性调律属于这一类。

### 生命耦合

与生命体自身的生理稳态和恢复活动共振，用于止血、修复、器官稳定、身体强化和异常反应抑制。魔纹只能放大和引导真实存在的生命信息，不能凭空得知完美身体结构或无条件复活死者。

同一魔纹的固定几何产生固定频谱和核心效果。增加供能只能在结构承受范围内增强效果，不能让火焰纹变成治疗纹。

## 当前时代：单纹魔法

极北龙族以外的当前文明只掌握“完整复制一个魔纹并得到一种固定效果”的方法。他们把每个有效魔纹视为不可拆分的整体，不知道其中可能存在功能片段和组合语法。

当前单纹魔法具有以下边界：

- 一个魔纹通常对应一种固定核心效果；
- 法师可以通过供能多少有限调整强度和持续时间；
- 目标和方向主要依靠位置、朝向与法师手动控制；
- 维持型效果通常需要储能物品持续供能或依靠固定魔力水晶；
- 当前魔纹不能自行理解抽象条件；
- 当前文明不会把多个魔纹连接成一个自动协同的新法术；
- 同时释放多个法术只是多个单纹并存，不是组合魔纹。

因此当前世界仍处于低魔阶段。拥有更多魔纹不等于理解更深规律，许多家族只是精确保存少量有效图案和使用经验。

## 文明自主发现魔纹规律

自主设计魔纹不是龙族的种族能力。龙族只是当前唯一保存完整前文明理论、测量工具和计算系统的文明。任何其他文明都可以通过自身发展独立达到相同能力。

可能的发展阶梯是：

```text
收集并临摹完整魔纹
→ 建立统一图谱、比例和材料记录
→ 比较相似魔纹的共同结构
→ 制造测量魔力频率、相位和强度的工具
→ 建立波动、几何和耦合数学
→ 从效果反推所需频谱
→ 从频谱计算新的二维魔纹
→ 发现模块、连接和复合结构
→ 进入高魔与可编程魔法阶段
```

达到这一阶段需要：

- 足够多且来源不同的完整魔纹样本；
- 可重复的精密绘图和测量标准；
- 能记录失败而不被家族销毁的知识制度；
- 几何、比例、波动和统计理论；
- 能承受失败的实验场、魔力与材料；
- 能区分几何误差、介质误差和供能误差的长期研究；
- 让研究跨越个人寿命和政治动荡延续的组织。

不同文明可以沿不同路径接近突破：人类擅长汇集多种传统，精灵擅长高精度测量，矮人擅长材料实验，地精擅长大量并行试错，兽人可以研究身体魔纹。没有任何种族被自然规律永久排除。

世家垄断会延缓样本比较和公开验证；灰精灵式知识共有、学校、工坊网络和跨种族交流则可能加速发现。首次成功自主设计新魔纹应当成为地区级或世界级历史事件。

龙族AI的不干预命令允许外部文明自然研究和进步。只要龙族没有泄露知识、操纵方向或提供关键工具，外部文明自行达到高魔阶段不构成龙族干预。

## 魔兽身上的天然魔纹

部分魔兽在漫长演化中形成了能够与魔力场耦合的天然纹路。这些纹路可以存在于：

- 皮肤、鳞片、甲壳和毛发；
- 翼膜、角、骨骼和器官表面；
- 血管、神经和内部组织；
- 发光、变色或只在使用能力时显现的结构。

天然魔纹使魔兽能够聚集魔力、喷吐高温、改变外皮、维持隐蔽、释放电光、强化身体或产生其他稳定效果。魔兽不需要理解纹路原理，就像普通动物不需要理解肌肉和神经才能行动。

天然魔纹的突变、繁衍和环境选择会产生新的魔兽能力。魔兽生态因此是魔法规律的自然产物，而不是前文明实验泄漏的必要结果。

## 人工魔法的起源

人工魔法起源于早期人类对魔兽纹路的观察和模仿。

最初的人类可能经历以下阶段：

1. 发现某些魔兽发动能力时，身体纹路会发光、变色或产生魔力流动；
2. 将皮肤、鳞片、骨片或纹路图案作为护符使用；
3. 用颜料、刻痕、绳结和石块模仿简单纹路；
4. 发现只有特定比例、有向关系、闭合方式和材料能够稳定生效；
5. 为不同完整魔纹建立独立的临摹、材料、供能和使用方法；
6. 通过家族、师徒和其他组织保存这些不可拆分的魔纹。

因此人类不是魔力的创造者，而是最早把天然魔纹系统化为人工魔法的已确认文明。当前人类尚未发现魔纹可以拆分和重新连接，只会复制完整纹路。其他种族后来可以学习、改造临摹方式，或独立保存适合自身身体与文化的完整魔纹。

具体最早模仿了哪种魔兽、发生于哪个地区和年代，仍待历史年表阶段确认。

## 作者层的进阶魔纹语法

客观规律允许完整魔纹被分析为多种基础模块，但当前外部文明尚未发现这种结构。以下内容只属于作者、前文明和极北龙族知识，不能进入普通人物的RAG常识或施法理由。

| 模块 | 功能 |
|---|---|
| 源点 | 接入储能物品、魔力水晶或固定环境收集结构 |
| 导路 | 规定魔力波传播方向 |
| 变换纹 | 改变频率、相位、振幅或耦合对象 |
| 目标纹 | 限定物体、生命、位置或边界 |
| 输出纹 | 把魔力转化为热、力、光、材料变化等结果 |
| 感应纹 | 读取允许范围内的温度、压力、运动或生命反馈 |
| 稳定纹 | 抑制噪声、相位漂移和异常振荡 |
| 终止纹 | 在时间、能量或条件满足时停止效果 |

魔纹只能使用自身拥有的感应能力，不能凭空获得不存在的信息。没有对应感应结构的法术无法自动判断目标身份、善恶、所有权或隐藏事实。

### 连接顺序

纹路连接顺序决定能量和信息处理的先后关系。

```text
接入能量
→ 限定目标
→ 改变频率
→ 形成输出
→ 稳定结果
→ 安全终止
```

顺序错误可能导致能量在限定目标前释放、反馈在稳定前进入循环，或终止条件无法生效。

### 循环

循环结构让魔法持续、自我修正或反复执行：

- 持续维持护盾；
- 根据温度调整导热；
- 反复检查裂纹并修复；
- 在生命状态变化时调整治疗强度；
- 让群体施法不断校正相位。

循环不会创造能量。它会持续消耗来源，错误循环还可能形成失控振荡、过热或地区魔力快速枯竭。

### 分支

分支结构根据感应结果选择不同路径：

```text
若温度过高 → 增强散热
若结构开裂 → 启动修复
若能量不足 → 降低输出
若稳定失败 → 立即终止
```

分支只能判断魔纹实际能够测量的条件，不能把抽象愿望直接转化为现实。

### 并行与嵌套

并行结构允许多个子魔纹同时运行；嵌套结构则把已经验证的魔纹作为更大法术的子模块。

这使魔法在客观规律上能够从简单模块组合为更强或用途更多的复杂法术。当前只有前文明和龙族掌握相关分析与计算，但其他文明可以在未来独立发现。复杂度会带来：

- 更高能量消耗；
- 更大绘制或投影空间；
- 更高精度要求；
- 更多干涉与失败点；
- 更困难的测试、维护和教学；
- 更严重的失控后果。

## 作者层示例：组合火焰法术

以下是龙族或作者对火焰纹的分析，不是当前人类能够自行设计的法术。一个可投射火焰魔纹在底层可能包含：

```text
能量源点
→ 热转换纹
→ 范围约束
→ 球形塑造
→ 前向导路
→ 飞行稳定循环
→ 碰撞或距离终止
```

当前法师只能整体复制已经发现的火焰纹，并通过供能有限调整威力；他们不知道如何加入目标感应、友军排除或能量不足保护。龙族则可以分析并重新计算这些结构。

## 施法方式

### 实体魔纹

使用刻痕、金属、晶体、颜料、骨片、织物或建筑结构形成。适合长期法阵、器物、陷阱和大型工程。

### 投影魔纹

经过训练的法师可以借助法杖或其他施法介质，把脑海中的完整单纹投影到空气、身体表面或目标附近。脑海图形只是模板，真正生效的是介质在现实魔力场中生成的纹路。

当前文明不能让普通思想直接改变现实，也不掌握徒手在空气中投影魔纹的方法。失去法杖后，法师仍可缓慢绘制实体魔纹并接触供能，但无法完成常见的快速投影施法。

### 身体魔纹

魔兽拥有天然身体魔纹；法师也可以通过训练、纹身、饰品或投影，让魔纹与自身生理结构耦合。身体魔纹必须服从真实营养、组织和能量限制。

### 群体施法

当前群体施法只是多名法师按照统一节奏，同时维持相同或不同的完整单纹。效果可以在战术上互相配合，但魔纹本身没有被连接成一个新的复合结构。

前文明与龙族能够让多名施法者或设备分别维持复合魔纹的不同模块，并通过连接纹和同步节点组合；这属于尚未被外部文明发现的进阶技术。

## 法杖上的施法魔纹

法杖内部固化着一个特殊完整单纹，设计层称为“施法魔纹”。它的固定效果不是火焰、治疗或护盾，而是把持有者主动形成的几何神经活动复制成外部低能量魔力纹路。

施法魔纹不会理解语言、愿望和法术用途，也不会分析或设计新结构。它只忠实复制已经存在于持有者神经活动中的完整几何模板。

```text
法师在脑海中重建完整单纹
→ 神经系统形成经过训练的几何活动
→ 施法魔纹读取低能量结构
→ 法杖放大、稳定并定位
→ 杖端在现实中投影完整单纹
→ 法师继续供能
→ 纹路闭合并产生固定效果
```

施法魔纹本身仍被当前文明视为不可拆分的完整纹路。人类知道它能制造法杖，却不知道它如何把神经结构转换成魔力投影，也没有因此发现进阶模块语法。

## 法杖的读取边界

法杖不是读心装置。施法魔纹只响应同时满足以下条件的活动：

- 持有者主动进入受训练的施法共振状态；
- 脑中维持清晰、完整且相干的几何魔纹；
- 持有者与介质接触或保持有效共振；
- 持有者提供最低启动魔力；
- 法杖材料、尺寸和校准能够承受投影。

它不能读取普通语言思想、情绪、记忆、梦境、潜意识或与魔纹无关的想象。一个念头闪过不会触发施法，只有主动维持的几何结构会被转换。

## 完整单纹的记忆内容

法师需要记住的不只是最终平面图案，还包括：

- 精确比例与朝向；
- 线条的有向关系与允许粗细；
- 适用尺度与等比例缩放范围；
- 投影平面的位置和空间朝向；
- 源点、闭合位置和安全供能范围；
- 与法杖运动配合的定位方式。

这些仍属于一个不可拆分的完整单纹。当前法师只知道必须准确重现最终结构，并不知道线条、交叉、封闭区和有向关系在进阶语法中的真实含义。

## 通用法杖与家族法杖

通用法杖只包含施法魔纹和基础稳定结构，不保存任何具体法术。偷走通用法杖不能获得家族魔纹。

家族法杖可以额外固化某个单纹的部分几何引导、安全供能范围、容易出错位置或隐藏投影结构。它能够降低特定魔纹的难度，也可能让旁观者看不到完整投影，因此属于重要家族财产。

法杖是功能分类，不要求所有种族使用木制长杖。短杖、锤、刻刀、骨饰、图腾杆和其他介质都可以固化施法魔纹，只要能够读取神经共振并投影现实纹路。

## 咒语和手势的新位置

魔法效果只由有效魔纹结构、介质、能量和环境决定。咒语与自然语言不是底层必要条件。

某些文化仍会使用咒语、歌唱、鼓点和手势，因为它们能够：

- 帮助记忆完整结构与闭合步骤；
- 统一群体施法节奏；
- 稳定呼吸和注意力；
- 让法师按照固定步骤投影魔纹；
- 在缺少文字时保存复杂结构。

沉默不会从物理上禁止所有魔法，但可能打断依赖歌唱或口令协调的特定传统。

## 地区魔力与枯竭

地区可用魔力取决于魔力场的能量密度、频谱、相干性和环境材料响应。

```text
施法抽取局部场能
→ 可用振幅下降
→ 法术减弱或失效
→ 周边魔力波传播与自然过程逐渐补充
```

消耗超过补充速度会形成魔力枯竭。长期战争、大型法阵和高魔生产可以制造持续贫魔区；反魔法区域可能来自破坏性干涉、强吸收材料或特殊自然背景。

## 环境魔力的产生

环境魔力的主要来源参考现实中的光子产生过程：当物质发生能级跃迁、燃烧、电流、热辐射、生物发光或其他过程并释放光时，输入能量的一部分也会同时进入魔力场，形成向外传播的魔力波。

```text
物理、化学或生命过程提供能量
→ 一部分成为光
→ 一部分进入魔力场
→ 其余成为热、运动和其他损耗
```

总能量必须守恒。魔力不是光之外无代价出现的额外能源。

### 主要来源

- 恒星是行星环境魔力最稳定、规模最大的来源；
- 火焰、熔岩和高温物体会产生少量本地魔力；
- 电光、雷暴和特定放电可以产生具有不同频谱的魔力；
- 生物发光和某些生命代谢可能产生微弱但相干性较高的魔力；
- 人工照明会产生魔力，但受原始燃料或能量输入限制。

不同发光过程的魔力转换比例和频谱不相同。明亮不一定等于高魔力产出，某些昏暗材料也可能具有很高的魔力耦合效率。

### 反射与再发射

镜面反射、普通折射和散射不会凭空制造新魔力，只会改变原有光与伴随魔力波的传播路径。

物质吸收光后重新发光，只有在再次发生真实能量释放时才会产生新的魔力波；新释放的总能量不能超过吸收与额外输入之和。

月光主要来自恒星光的反射与再发射，因此仍伴随魔力，但强度、频谱和相干性会被月面材料与传播过程改变。

### 魔力与光的独立传播

光与魔力在产生时相关，但产生后不必以完全相同方式传播。魔力波可以对部分普通物质表现出更强穿透，也会被某些晶体、矿物、生命组织和魔纹结构吸收、反射或引导。

因此地下并非绝对无魔，但厚重岩层会改变和削弱来自地表的魔力频谱。地下火焰、熔岩、晶体和其他本地过程也可以提供少量补充。

## 贫魔区恢复

施法、储能充能和固定法阵消耗局部场能后，持续到达的新魔力波会使地区逐渐恢复：

```text
太阳与其他光源继续释放魔力
→ 魔力波传播、散射和穿透环境
→ 高浓度区域向低浓度区域重新分布
→ 当地材料与大气重新建立平衡
→ 可用魔力缓慢恢复
```

恢复速度取决于：

- 日照时间与恒星高度；
- 云层、大气和地形；
- 地表与地下材料；
- 周围是否存在持续吸收源；
- 当地频谱是否与储能和法术兼容；
- 昼夜、季节、纬度和天体遮蔽；
- 火山、雷暴、火灾和生物活动等本地来源。

夜晚不会让魔力立即归零，因为环境、材料和大气中仍保存着场能，也仍有星光、月光和其他来源。但长夜、日食、极地季节和持续遮蔽会改变恢复速度与频谱。

## 禁止魔力永动

用魔法产生光，再利用该光产生魔力，不能获得比最初投入更多的能量：

```text
输入魔力
→ 光魔法转换
→ 光与伴生魔力输出
→ 再次收集
→ 可回收总量必然小于原始输入
```

每次转换都会产生热、散射、相位失配和材料损耗。任何宣称能够无限自充的器物，都必须是骗局、误测、隐藏外部能源，或尚未发现其真实消耗来源。

## 神经共振与法师引导

多数智慧种族的神经系统能够与魔力场发生潜在耦合，但普通人的活动微弱、无序，无法被施法魔纹稳定读取。

现役法师在初次引导中，使用低强度标准投影，让学徒反复感受并模仿稳定的魔力波与神经节奏：

```text
导师与法杖产生标准低强度投影
→ 学徒神经活动被带入共振
→ 学徒学习主动维持相干几何活动
→ 施法魔纹能够稳定读取学徒
→ 学徒建立稳定控制与安全导流能力
→ 激活完成
```

书籍可以传授理论和图形，却不能提供第一次稳定共振所需的真实魔力反馈。因此初次激活仍必须由合格法师使用施法介质亲自指导。

激活后，法师只是能够稳定构建几何神经活动、让法杖读取，并安全承受魔力从储能物品流向现实魔纹时产生的场干扰。人体不储存可用于施法的魔力，也不会因为完成激活自动获得长寿。

长时间高功率施法仍会造成神经疲劳、感官紊乱、组织负担和共振失控，但这属于控制通道的承受问题，不是人体魔力电池耗尽。

## 储能物品

法师自身不储存施法魔力。所有快速施法能量来自佩戴、携带或安装在法杖上的储能物品。

魔力水晶等材料能够形成类似共振腔的结构，把特定频谱的魔力波束缚在内部。储能物品可以表现为戒指、手镯、项链、腰带、护符、冠饰、武器、护甲组件或法杖水晶。

每件储能物品至少具有：

| 参数 | 含义 |
|---|---|
| 容量 | 能够保存的总魔力 |
| 输出功率 | 单次能够安全释放的速度 |
| 频谱范围 | 能为哪些魔纹稳定供能 |
| 充能速度 | 从环境吸收并相干化魔力的效率 |
| 泄漏率 | 放置时自然损失能量的速度 |
| 稳定性 | 是否容易过热、开裂或失控 |
| 循环寿命 | 反复充放后产生的衰减 |

容量大不等于输出功率高。储能物品耗尽后必须更换、在富魔环境中缓慢恢复，或由少量专用设施充能。

### 被动吸收

储能材料会与周围魔力场缓慢达到共振，并把少量环境魔力束缚在内部。这个过程不需要法师持续操作，也不需要公共基础设施。

- 环境魔力越浓，恢复越快；
- 材料频谱越匹配，吸收效率越高；
- 接近容量上限时，吸收速度逐渐下降；
- 贫魔区可能几乎无法恢复；
- 多件物品同时吸收会互相竞争当地魔力；
- 长期被动吸收同样遵守地区能量守恒。

普通佩饰可以在数日、数周或更长时间中缓慢恢复，具体速度由材料、容量和环境决定，不设置所有物品通用的固定时间。

### 汇聚储能魔纹

当前文明还掌握一种特殊完整单纹，设计层暂称“汇聚储能纹”。它的固定效果是捕获一定范围内与自身频谱相容的环境魔力，并将其导入刻有该纹路的储能容器。

```text
环境魔力
→ 汇聚储能纹形成吸收范围
→ 过滤不相容频谱与干扰
→ 将相干魔力导入容器材料
→ 容器材料逐渐饱和，吸收自然减慢
```

汇聚储能纹仍是当前文明无法拆分的完整单纹，不包含他们能够理解或修改的循环、分支与控制模块。法师只知道必须按照完整图谱、材料和尺度刻蚀，才能稳定工作。

储能容器必须使用能够保存对应频谱的材料。把纹路刻在普通木箱或劣质陶器上，不能让容器凭空获得无限容量。

### 为佩戴物品充能

戒指、护符、手镯和法杖水晶可以放入或接触充满魔力的储能容器。相容材料之间会逐渐发生能量平衡，把容器中的魔力转移到佩戴物品。

这个过程不需要当前文明把两个魔纹连接成复合结构，只是两个储能材料通过接触或近距离共振进行能量转移。

### 地区影响与风险

- 吸收范围内的魔力浓度会下降；
- 多个容器集中运行会形成局部贫魔区；
- 容器越大，材料、刻蚀精度和维护成本越高；
- 过度充能可能造成裂纹、泄漏、热量和魔力冲击；
- 频谱不相容会降低效率或损坏储能物品；
- 摧毁高容量容器可能一次性释放危险能量。

汇聚储能纹不能制造魔力，也不能突破容器容量。它只是比材料自然吸收更快地搬运和整理周围场能。

### 所有权与社会边界

在人类、传统精灵、矮人、地精和兽人社会中，汇聚储能纹和大型容器通常属于世家、神殿、法师工坊、军队或少数部落传承者。它们可以为内部成员充能，却不构成面向所有居民的公共网络。

灰精灵可以把少量汇聚储能容器作为共同体设施，由轮值法师管理吸收范围、充能配额和地区恢复。极北龙族则使用远超当前文明的魔力场工程，不受单纹容器技术限制。

人体可以感知和控制魔力，却无法在战斗尺度内直接从环境吸收足够相干能量。大型固定法阵可以通过专用收集结构直接使用环境魔力，但这需要知识、材料、维护和长期占地，不是普通法师个人能力。

## 法师寿命的新解释

法师寿命优势来自对治疗单纹、身体维护佩饰、稳定储能和优越生活条件的垄断，而不是施法身份本身。

部分法师家族持有能够持续低强度稳定循环、促进组织修复或抑制部分感染的完整维护单纹。被认可的成员长期佩戴相应器物，因而拥有更长健康寿命。

- 没有维护器物的流浪法师不一定比普通人长寿；
- 失去器物不会瞬间衰老，但延寿和维护效果会停止；
- 持续维护需要消耗储能并定期充能；
- 已确认的各族法师寿命描述拥有完整维护条件者的常见结果，而不是所有会施法者的生物上限。

## 种族倾向

- 人类擅长学习、临摹和适应不同来源的完整魔纹；
- 精灵擅长高精度、低损耗和长期相干；
- 矮人擅长把魔纹固定进材料并调节物性；
- 地精擅长让多人按照节奏同时维持多个独立单纹；
- 兽人擅长让魔纹与自身身体状态耦合；
- 龙族当前使用完整科学理论、传感器和计算设备生成复杂魔纹，其他文明未来也能独立达到这一阶段。

这些是统计倾向和技术传统，不是未激活个体自动拥有的法术。

## 前文明与龙族

前文明没有创造魔力和魔纹规律，只是对自然魔力场建立了完整科学理论，并发展出测量、计算、自动校正、材料工程和科技—魔法联合系统。

极北龙族同时掌握自然魔法科学、生物改造、纳米技术、人工智能和其他前文明科技。纳米机器人仍可用于制造、医疗和身体改造，但不再是魔力本身，也不是外部法师施法的必要条件。

## 硬限制

1. 魔纹不能凭空创造质量和能量；
2. 效果必须属于魔力场与目标可实现的耦合范围；
3. 魔纹不能获得未被感应结构实际读取的信息；
4. 规模、距离、持续时间和复杂度都会提高消耗；
5. 纹路比例、连接、介质和环境错误会造成失败；
6. 循环、分支和并行越多，干涉与失控风险越高；
7. 治疗只能利用真实身体结构和可获得信息，不能无条件复活；
8. 魔力枯竭区无法为耗尽的储能物品补充能量，也无法支撑大型固定法阵；
9. 魔法不会因为施法者“希望更强”就自动补全缺失结构。

## 尚待确认

1. 魔力场的作者层正式名称及其与其他自然场的数学关系。
2. 最早被人类模仿的魔兽、地点、年代和历史证据。
3. 当前人类何时、通过何种事件首次发现魔纹模块与连接语法。
4. 施法魔纹最早被发明或发现的年代与历史持有者。
5. 法杖投影的可见程度、构建速度和空间上限。
6. 神经共振训练的生理变化与激活失败后果。
7. 储能材料与汇聚储能容器的容量、功率、频谱、吸收范围和衰减分类。
8. 不同魔力频谱、材料和元素分类的关系。
9. 各类光源产生魔力的转换比例、频谱和相干性。
10. 魔力穿透、散射、吸收和地区恢复的具体速度模型。
