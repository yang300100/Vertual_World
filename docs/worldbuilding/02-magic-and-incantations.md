# 魔法与咒语的底层逻辑

状态：纳米机器人本质、语言差异、地区魔力和个人储备已确认；具体协议、激活条件和数值待定。

## 已确认的底层事实

魔法的物质基础是失落科技侧文明遗留的纳米机器人。它们以某种方式分布在星球环境、生物体和深层设施之中，并能在满足条件时改变物质、能量或生物状态。

极北龙族社会以外的当代居民不知道“纳米机器人”这一概念。他们所说的魔力，是对一组真实、可测量、可重复但无法理解来源的自然现象的统称。因此魔法在社会层面不是虚假的障眼法，而是已经深度参与生产、医疗、战争、宗教和文化的现实力量。

## 咒语不是当代语言中的命令

前文明语言与当代语言不同。法师并不是用当前语言对某个系统下达自然语言命令，而是在长期试验、传承和偶然发现中，保留了若干能够稳定引发现象的发音组合。

这些发音对当代施法者可能没有语义，只具有经验关系：

```text
特定发音
+ 特定节奏
+ 特定动作或图形
+ 特定环境条件
→ 某种可重复魔法现象
```

不同地区可以使用完全不同的记忆口诀和解释，但有效部分可能共享少量无法翻译的核心音素。长期口传造成的偏移也可以形成法术流派、地方变体和失传现象。

## 长咒语的建议解释

这一部分是当前最合理的解释，但尚未锁死具体技术细节。

前文明的正常使用者可能依靠神经接口、身份凭据和个人终端完成意图、权限、目标和参数传递。简短语音只负责确认，甚至完全不需要语音。

历史断裂后，当前文明缺少原始接口，只能通过遗留的兼容、维护或紧急通道，低效地重现一组完整调用。现代咒语可能依次承担：

```text
唤醒
兼容识别
权限片段
现象类型
目标和范围
限制条件
校验
执行确认
```

前文明设备原本会瞬间完成这些步骤；当前法师只能通过声音、动作、法阵和器具逐段补齐，所以短指令在历史中演化成冗长咏唱。

## 可以由此产生的魔法现象

以下是兼容方向，不等于当代人物知道其原因：

- 发音错误导致调用失败、参数偏移或安全拒绝；
- 法阵保存目标、范围和限制，因此能够缩短临场咏唱；
- 法杖或遗物承担身份、聚焦或稳定作用；
- 熟练施法者掌握可省略的默认部分，能够缩短咏唱；
- 极少数“无咏唱者”可能拥有未知的身体条件或残留接口；
- 沉默能阻止依赖声音的普通法术，却未必影响具备其他调用途径的现象；
- 所谓古代语更适合施法，是因为部分音素更接近遗留协议，而不是因为语言本身神圣。

人物只能总结这些经验，不能由此直接推导出协议、认证或终端等底层概念。

## 魔法研究的认知上限

法师可以发展出严谨的魔法学：比较发音、测量强度、整理法阵、统计失败率并建立教学体系。这不会自动使他们认识前文明。

鉴定类魔法同样依赖遗留纳米机器人，只能访问开放或兼容的信息。面对真正的深层造物，它可能只返回无法确定、没有已知魔力反应或超出测量范围，而不能把底层用途翻译给人物。

一个人可以知道某种咒语会止血，却不知道它在修复组织；可以知道某段符号会打开墙面，却不知道墙后存在储存和运输网络。

## 地区魔力浓度与可用能量

地区魔力不是抽象且无限的背景数值。底层至少由三个因素共同决定：

```text
纳米机器人密度
× 平均剩余能量
× 当前可响应比例
＝ 区域可用魔力
```

当代居民所说的“魔力浓度”，主要对应一个地区中纳米机器人的密度和活跃程度：

- 高密度区域表现为魔力丰饶区、灵脉、圣地或魔法森林；
- 低密度区域表现为贫魔区和难以施法的荒原；
- 纳米机器人极少、休眠或无法连接的区域表现为无魔区；
- 深层生产、能源或分发节点附近可能长期保持异常高浓度。

纳米机器人可以从太阳能、地热、核能设施或其他环境来源获得能量。具体地区采用哪种能源，以及前文明是否存在统一供能网络，仍待后续确定。

## 魔力枯竭与恢复

释放魔法会消耗一定范围内参与执行的纳米机器人储能。当局部消耗速度超过自行充能、外部迁入和节点补充速度时，可响应个体逐渐减少，最终表现为魔力衰退或魔力枯竭。

```text
施法消耗局部储能
  → 周边高能个体迁入并尝试补充
  → 持续消耗超过补充能力
  → 法术减弱、失败或无法发动
  → 区域进入魔力枯竭
  → 经环境充能和纳米机器人迁移逐渐恢复
```

普通施法主要使纳米机器人暂时耗尽能量并进入低响应或休眠状态。某些破坏性法术、故障和灾害也可能直接损坏或永久消耗纳米机器人，使短期枯竭演变为持续多年的贫魔区。

这意味着魔力是地区共享资源。大规模战争、城市过度施法、长期仪式和魔法生产都可能改变一个地区的可用魔力，并进一步影响生态、经济、迁徙和组织冲突。

当代居民可以观察到魔力潮汐、地脉衰退、圣地沉寂和战后魔力荒漠，但无法知道其底层对应纳米机器人迁移、能量耗尽和节点失效。

## 人体内的休眠纳米机器人

所有人的体内都存在纳米机器人。普通人体内的纳米机器人没有被激活，长期保持休眠或最低响应状态，因此不会明显改善身体素质，也不能形成可供主动支配的个人魔力储备。

法师能够通过尚待确定的条件激活体内纳米机器人。激活后，这些个体不只参与施法，也会持续辅助人体：

- 修复微小组织损伤；
- 加快伤口恢复；
- 抑制部分感染和毒素；
- 协助维持神经、肌肉和器官状态；
- 降低长期身体损耗；
- 形成高于普通人的体能、恢复力和寿命。

当代文明只能观察到“魔力觉醒者身体更强健、恢复更快且通常更加长寿”，并会用魔力回路、血脉、灵魂强度或神恩等本地理论解释，不能看到体内纳米机器人。

## 个人储备与环境魔力

法师体内被激活的纳米机器人及其储能构成个人魔力储备。环境中的纳米机器人则构成区域共享魔力。两者共同决定实际施法能力：

```text
个人储备
+ 能够调动的环境魔力
× 控制与协调能力
＝ 当前可执行的法术规模
```

个人储备允许法师在贫魔区域短暂施法；环境浓度则影响恢复速度、持续施法能力和法术规模。多个施法者在同一区域活动时，会共同消耗当地可用魔力。

一个与已确认设定相容、但具体程度尚待决定的后果是：施法会暂时把部分体内纳米机器人从身体维护转移到法术执行。适度施法后法师会疲惫并降低恢复能力；极端透支可能导致发热、颤抖、旧伤复发、器官损伤或寿命折损。它可以防止“长寿法师”同时获得没有代价的无限施法能力。

## 尚待确定的机制

1. 太阳能、地热、核能和深层节点在不同区域的供能比例。
2. 纳米机器人如何维护、复制、限制数量或发生不可逆损耗。
3. 体内纳米机器人通过何种过程进入新生儿，并维持跨世代存在。
4. 引导师通过何种可观察仪式唤醒学徒，以及引导知识和现役法师自身分别承担什么作用。
5. 不同年龄是否都能激活，以及失败会造成什么后果。
6. 法师体质和寿命能够提高到何种程度，衰老是否只能减缓而不能停止。
7. 施法时多少体内纳米机器人会离开身体维护，透支伤害如何分级。
8. 纳米机器人是否仍受某个中心管理，还是已经分裂成多个残缺网络。
9. 高阶魔法的权限从何而来，使用后需要付出何种真实代价。
10. 纳米机器人经过漫长时间后是否发生了演化、漂移或形成新的行为。
