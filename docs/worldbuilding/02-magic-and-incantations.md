# 魔法与咒语的底层逻辑

状态：纳米机器人本质与语言差异已确认；具体协议、能源和天赋机制待定。

## 已确认的底层事实

魔法的物质基础是失落科技侧文明遗留的纳米机器人。它们以某种方式分布在星球环境、生物体和深层设施之中，并能在满足条件时改变物质、能量或生物状态。

当代居民不知道“纳米机器人”这一概念。他们所说的魔力，是对一组真实、可测量、可重复但无法理解来源的自然现象的统称。因此魔法在社会层面不是虚假的障眼法，而是已经深度参与生产、医疗、战争、宗教和文化的现实力量。

## 咒语不是当代语言中的命令

前文明语言与当代语言不同。法师并不是用当前语言对某个系统下达自然语言命令，而是在长期试验、传承和偶然发现中，保留了若干能够稳定引发现象的发音组合。

这些发音对当代施法者可能没有语义，只具有经验关系：

```text
特定发音
+ 特定节奏
+ 特定动作或图形
+ 特定环境条件
→ 某种可重复魔法现象
```

不同地区可以使用完全不同的记忆口诀和解释，但有效部分可能共享少量无法翻译的核心音素。长期口传造成的偏移也可以形成法术流派、地方变体和失传现象。

## 长咒语的建议解释

这一部分是当前最合理的解释，但尚未锁死具体技术细节。

前文明的正常使用者可能依靠神经接口、身份凭据和个人终端完成意图、权限、目标和参数传递。简短语音只负责确认，甚至完全不需要语音。

历史断裂后，当前文明缺少原始接口，只能通过遗留的兼容、维护或紧急通道，低效地重现一组完整调用。现代咒语可能依次承担：

```text
唤醒
兼容识别
权限片段
现象类型
目标和范围
限制条件
校验
执行确认
```

前文明设备原本会瞬间完成这些步骤；当前法师只能通过声音、动作、法阵和器具逐段补齐，所以短指令在历史中演化成冗长咏唱。

## 可以由此产生的魔法现象

以下是兼容方向，不等于当代人物知道其原因：

- 发音错误导致调用失败、参数偏移或安全拒绝；
- 法阵保存目标、范围和限制，因此能够缩短临场咏唱；
- 法杖或遗物承担身份、聚焦或稳定作用；
- 熟练施法者掌握可省略的默认部分，能够缩短咏唱；
- 极少数“无咏唱者”可能拥有未知的身体条件或残留接口；
- 沉默能阻止依赖声音的普通法术，却未必影响具备其他调用途径的现象；
- 所谓古代语更适合施法，是因为部分音素更接近遗留协议，而不是因为语言本身神圣。

人物只能总结这些经验，不能由此直接推导出协议、认证或终端等底层概念。

## 魔法研究的认知上限

法师可以发展出严谨的魔法学：比较发音、测量强度、整理法阵、统计失败率并建立教学体系。这不会自动使他们认识前文明。

鉴定类魔法同样依赖遗留纳米机器人，只能访问开放或兼容的信息。面对真正的深层造物，它可能只返回无法确定、没有已知魔力反应或超出测量范围，而不能把底层用途翻译给人物。

一个人可以知道某种咒语会止血，却不知道它在修复组织；可以知道某段符号会打开墙面，却不知道墙后存在储存和运输网络。

## 尚待确定的机制

1. 纳米机器人使用何种长期能源。
2. 它们如何维护、复制、限制数量或发生不可逆损耗。
3. 魔力地区差异对应节点密度、能源覆盖、网络状况还是其他因素。
4. 魔法天赋为何存在，以及能否通过训练、遗物或身体改造获得。
5. 纳米机器人是否仍受某个中心管理，还是已经分裂成多个残缺网络。
6. 高阶魔法的权限从何而来，使用后需要付出何种真实代价。
7. 纳米机器人经过漫长时间后是否发生了演化、漂移或形成新的行为。
