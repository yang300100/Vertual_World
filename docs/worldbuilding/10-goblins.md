# 地精种族卡

状态：狡诈、身体、生命周期和魔法特点已确认；人口、家庭、法师家族、社会和隐藏起源待讨论。

## 定位

本世界的地精对应哥布林式智慧种族，不指侏儒，也不是天生邪恶、低智或供冒险者无条件讨伐的怪物类别。

地精能够建立家庭、聚落、法律、贸易、战争、政治组织和法师家族。每个地精人物都拥有自己的利益、关系、记忆和道德选择。

## 已确认特点：狡诈

“狡诈”是地精种族层面的统计倾向，主要表现为：

- 快速观察对手、环境和规则中的薄弱位置；
- 在力量不占优势时优先采用间接手段；
- 隐藏真实意图、资源和底线；
- 擅长试探、讨价还价、误导、诱导和临时变通；
- 倾向准备退路、替代方案和低成本试错；
- 能把看似不利的规则转化为可利用条件。

这一倾向不等于：

- 所有地精都会撒谎；
- 地精天生邪恶或不可信；
- 地精可以凭空知道他人的秘密；
- 地精永远比其他种族聪明；
- 地精无法建立忠诚、诚信和长期合作。

狡诈只能使用人物实际知道或观察到的信息。模型裁判不能因为人物是地精，就让其识破未获得证据的阴谋或读取其他人物的隐藏知识。

## 可能的形成压力

地精体型、生命周期和社会环境尚未正式确认，但“狡诈”可以来自长期生存压力：当一个群体难以在正面对抗中取得优势时，观察、欺骗、联盟、陷阱、规则利用和快速撤退更容易让个体存活。

这种能力进入社会后，也可以发展为外交、商业、侦察、法律辩论、风险管理和政治谈判，而不只用于犯罪。

## 社会后果

- 地精协议可能包含大量例外、验证和违约条款；
- 合作双方更重视抵押、见证和可核验记录；
- 公开的狡诈声誉可能让诚实地精也遭受偏见；
- 某些地精文化会把成功误导强敌视为智慧，另一些则会严格区分机智与背信；
- 地精内部同样可能因为短期算计、信任不足和过度复杂的规则付出代价。

种族倾向只提供行为概率和社会背景，具体人物是否狡诈、诚实、冲动或忠诚仍由个人特质、文化、经历、关系和当前处境共同决定。

## 身体与生命周期

- 成年地精身高约0.7至0.9米；
- 身体轻巧、转向和狭窄空间活动较灵活；
- 绝对力量、负重和抗冲击能力相对较弱；
- 大约在8至10岁完成主要身体成熟；
- 社会成年因文化而异，通常位于10至14岁；
- 自然寿命约为35至45年；
- 当前世界条件下常见实际寿命约为25至35年；
- 平均世代间隔约为12至18年。

地精的成熟年龄是该种族自身的生理阶段，不能直接套用人类生命周期判断。其短生命周期使社会观念、政治和知识传承在数十年中经历多次代际更替。

## 法师寿命

- 普通地精法师常见寿命约为60至90年；
- 少数强大、生活稳定且很少长期透支的地精法师可以达到100至120年；
- 法师寿命远超普通地精，因此可能亲自控制多个地精世代；
- 激活仍不能让地精停止衰老或实现永生。

## 魔法特点

地精个人魔力储备较小，单次爆发通常较弱，但擅长快速切换多个低消耗法术，并同时维持多个简单效果。

| 项目 | 地精倾向 |
|---|---|
| 个人储备 | 较小 |
| 单次爆发 | 较弱 |
| 施法切换 | 很快 |
| 低消耗法术 | 很高效 |
| 同时维持简单效果 | 较强 |
| 精密长期效果 | 中等偏弱 |
| 群体协作 | 很强 |

### 群体施法

多个地精法师可以使用统一节奏和明确分工共同完成超出单一个体能力的法术，例如分别负责目标、能量、稳定和不同参数。

群体施法并不是简单相加：

- 参与者需要共同训练并使用兼容传统；
- 协作规模越大，沟通和同步失败风险越高；
- 一名关键成员中断可能使整体失稳；
- 狡诈、保留信息和家族竞争也可能破坏合作；
- 成功协作能够提高能量利用率并分散个人透支。

具体法术知识仍由地精法师家族掌控。普通地精不会因为种族倾向自动获得任何施法能力。

## 尚待确认

1. 生育率、人口增长和家庭结构。
2. 法师家族如何在短生命周期中保存知识和引导术。
3. 地精的主要文化、政权、法律与其他种族关系。
4. 地精在世界底层历史中的真实起源。
