# 地精种族卡

状态：狡诈、身体、生命周期、魔法、人口、扩展家庭、氏族部落和传习营地已确认；具体文化与隐藏起源待讨论。

## 定位

本世界的地精对应哥布林式智慧种族，不指侏儒，也不是天生邪恶、低智或供冒险者无条件讨伐的怪物类别。

地精能够建立家庭、聚落、法律、贸易、战争、政治组织和法师家族。每个地精人物都拥有自己的利益、关系、记忆和道德选择。

## 已确认特点：狡诈

“狡诈”是地精种族层面的统计倾向，主要表现为：

- 快速观察对手、环境和规则中的薄弱位置；
- 在力量不占优势时优先采用间接手段；
- 隐藏真实意图、资源和底线；
- 擅长试探、讨价还价、误导、诱导和临时变通；
- 倾向准备退路、替代方案和低成本试错；
- 能把看似不利的规则转化为可利用条件。

这一倾向不等于：

- 所有地精都会撒谎；
- 地精天生邪恶或不可信；
- 地精可以凭空知道他人的秘密；
- 地精永远比其他种族聪明；
- 地精无法建立忠诚、诚信和长期合作。

狡诈只能使用人物实际知道或观察到的信息。模型裁判不能因为人物是地精，就让其识破未获得证据的阴谋或读取其他人物的隐藏知识。

## 可能的形成压力

地精体型、生命周期和社会环境尚未正式确认，但“狡诈”可以来自长期生存压力：当一个群体难以在正面对抗中取得优势时，观察、欺骗、联盟、陷阱、规则利用和快速撤退更容易让个体存活。

这种能力进入社会后，也可以发展为外交、商业、侦察、法律辩论、风险管理和政治谈判，而不只用于犯罪。

## 社会后果

- 地精协议可能包含大量例外、验证和违约条款；
- 合作双方更重视抵押、见证和可核验记录；
- 公开的狡诈声誉可能让诚实地精也遭受偏见；
- 某些地精文化会把成功误导强敌视为智慧，另一些则会严格区分机智与背信；
- 地精内部同样可能因为短期算计、信任不足和过度复杂的规则付出代价。

种族倾向只提供行为概率和社会背景，具体人物是否狡诈、诚实、冲动或忠诚仍由个人特质、文化、经历、关系和当前处境共同决定。

## 身体与生命周期

- 成年地精身高约0.7至0.9米；
- 身体轻巧、转向和狭窄空间活动较灵活；
- 绝对力量、负重和抗冲击能力相对较弱；
- 大约在8至10岁完成主要身体成熟；
- 社会成年因文化而异，通常位于10至14岁；
- 自然寿命约为35至45年；
- 当前世界条件下常见实际寿命约为25至35年；
- 平均世代间隔约为12至18年。

地精的成熟年龄是该种族自身的生理阶段，不能直接套用人类生命周期判断。其短生命周期使社会观念、政治和知识传承在数十年中经历多次代际更替。

## 法师寿命

- 普通地精法师常见寿命约为60至90年；
- 少数强大、生活稳定且很少长期透支的地精法师可以达到100至120年；
- 法师寿命远超普通地精，因此可能亲自控制多个地精世代；
- 激活仍不能让地精停止衰老或实现永生。

## 魔法特点

地精个人魔力储备较小，单次爆发通常较弱，但擅长快速切换多个低消耗法术，并同时维持多个简单效果。

| 项目 | 地精倾向 |
|---|---|
| 个人储备 | 较小 |
| 单次爆发 | 较弱 |
| 施法切换 | 很快 |
| 低消耗法术 | 很高效 |
| 同时维持简单效果 | 较强 |
| 精密长期效果 | 中等偏弱 |
| 群体协作 | 很强 |

### 群体施法

多个地精法师可以使用统一节奏和明确分工共同完成超出单一个体能力的法术，例如分别负责目标、能量、稳定和不同参数。

群体施法并不是简单相加：

- 参与者需要共同训练并使用兼容传统；
- 协作规模越大，沟通和同步失败风险越高；
- 一名关键成员中断可能使整体失稳；
- 狡诈、保留信息和家族竞争也可能破坏合作；
- 成功协作能够提高能量利用率并分散个人透支。

具体法术知识可以由传习营地、氏族法师或私人导师掌握。普通地精不会因为种族倾向自动获得任何施法能力，第一次激活仍必须由合格的现役法师亲自指导。

## 传习营地

地精社会整体较为原始，不采用城市学院、正式学年、毕业身份和复杂书面合同作为主要传承形式。地精的学校类设施表现为由多名法师共同维持的传习营地。

传习营地可以：

- 由数名法师共同指导年轻成员；
- 使用歌曲、鼓点、舞蹈、图案和实际操作传承；
- 训练群体施法所需的节奏、队形、分工和中断处理；
- 由合格引导师亲自完成初次激活；
- 在季节性集会中与其他氏族交换部分技巧；
- 通过反复演示和多人重复掌握抵抗短生命周期造成的失传。

传习营地没有统一年级和毕业制度。成员学会一项能力后，会在真实狩猎、劳动、治疗、防御和仪式中继续训练。某些氏族仍会对外隐藏特殊法术，但部落内部的基础训练相对开放。

## 人口与聚落

地精人口增长快但波动大：稳定地区通常每年增长约0.3%至0.8%，粮食充足的新聚落可以达到约1%至2%；拥挤、卫生恶化、战争、饥荒和疫病会使人口迅速下降。

常见聚落包括木栅村落、洞穴营地、沼泽高脚聚落、森林隐蔽营地和废弃建筑周围形成的临时社区。当人口超过土地承载能力时，部落更可能分裂迁徙，而不是自然扩建为大型城市。

## 扩展家庭与氏族

地精采用多人共同抚养的扩展家庭：父母、兄姐、叔伯、祖辈和其他亲属共同承担抚养责任，孤儿也较容易被亲属网络吸收。

多个扩展家庭构成氏族，若干氏族可以形成小型部落。部落之间为了战争、迁徙、灾害和资源争夺组成临时联盟，目标结束后联盟可以解散。

这种结构不是蜂巢意识。每个地精仍然拥有个人财产、关系、立场与选择，家庭和氏族内部也会发生继承、抚养、债务和权力冲突。

## 权力与习惯法

地精部落可以由族长、战首、老法师、猎手首领、调停者和多个家庭代表相互制衡。权力依靠能力、支持者、战利品、亲属和声望维持，不建立普遍的正式官僚制度。

社会规则主要通过见证人、当众承诺、礼物交换、抵押物、血亲责任、赔偿、复仇威胁和首领调停执行。地精善于寻找口头约定的漏洞，也重视谁真正有能力迫使约定履行。

狡诈不等于社会没有秩序。反复交往的部落可能形成严格的仪式、见证和赔偿惯例，只是这些规则依赖共同记忆和关系，而不是大量书面档案。

## 长寿法师

活到六十至九十年的地精法师会经历多个普通世代，可能成为部落的老萨满、引导师和历史记忆核心，也可能利用知识与寿命长期影响族长继承。

知识不能只依赖一名老法师。关键歌曲、节奏和仪式应由多名引导师重复掌握，避免一次意外死亡摧毁全部传承。

## 尚待确认

1. 地精的主要文化、具体部落、区域联盟与其他种族关系。
2. 少数接触人类或矮人贸易网络的地精聚落如何逐渐城市化。
3. 地精在世界底层历史中的真实起源。
