# 精灵种族卡

状态：普通与法师寿命、成熟、低生育、感知与魔法特点已确认；文化分支、家族制度和隐藏起源待讨论。

## 定位

精灵是第一版主要基源种族之一。其核心不是全面优于人类，而是生命周期漫长、感知精细、魔法控制稳定，同时人口恢复缓慢、知识更新和社会权力更替困难。

精灵内部可以存在多个国家、语言、宗教和互相敌对的文化。长寿和低生育属于种族生理特点，保守、亲近自然或敌视其他种族不能被直接写成所有精灵共有的性格。

## 生命周期

- 精灵大约在25至30岁完成主要身体成熟；
- 社会认定的成年年龄因文化而异，通常位于35至50岁；
- 自然寿命约为500年；
- 在当前生活、疾病、事故和战争条件下，普通精灵常见实际寿命约350至450年；
- 平均世代间隔约为70至100年；
- 意外、战争、疾病和贫困仍会使许多精灵无法活到自然寿命。

精灵并非在数十年中保持人类幼童状态。早期身体和认知会持续成长，只是在青春期以后，成熟与衰老速度显著慢于人类。

普通精灵的自然寿命已经超过人类高阶法师寿命。精灵法师常见寿命约为700至900年，少数强大、生活稳定且很少长期透支者可以达到1000至1200年。

精灵自身已经具有缓慢衰老的身体，因此维护器物与治疗单纹带来的延寿比例不必像人类那么高，但绝对增加的时间仍然非常可观。精灵法师依然不能永生；失去维护、长期高功率施法、不可修复损伤和身体稳态衰退都会导致衰老和死亡。

## 生育与人口

精灵生育率明显低于人类。家庭通常规模较小，两次养育后代之间可以相隔数十年。

- 和平时期人口也只缓慢增长；
- 战争、迁徙和灾害造成的损失可能需要数百年恢复；
- 一个聚落失去的专业者和法师可能长期无法替代；
- 低人口恢复速度会影响军事、殖民和城市规模；
- 长寿不代表整个生命周期都保持高生育能力。

精灵会因此谨慎评估全面战争，但这不是天生爱好和平。某些精灵政权也可能因为领袖能承担数百年计划，而发动极其漫长的战争。

## 身体与感知

- 听觉敏锐，能够分辨细微音高、节奏和发音变化；
- 对微弱魔力变化和持续干扰较为敏感；
- 动作协调性与精确度较高；
- 绝对力量和负重能力通常不及矮人或兽人；
- 持续噪声、强烈爆响和混乱魔力环境会造成更明显的不适。

敏锐感官有利于辨认魔力波、相位和群体节奏，但不会让未被法师引导的普通精灵自动施法。

## 魔法特点

精灵施法倾向高精度、高稳定、低损耗和长时间维持，而不是极端瞬间爆发。

| 项目 | 精灵倾向 |
|---|---|
| 安全输出与储能利用 | 中等偏高 |
| 精细控制 | 很强 |
| 能量利用效率 | 很高 |
| 持续施法 | 很强 |
| 瞬间爆发 | 中等 |
| 学习陌生完整魔纹 | 较慢 |
| 维持长期效果 | 很强 |

精灵较适合精细治疗、感知、隐蔽、生态管理和需要长期维护的法术工程，但这些只是身体条件提供的倾向。具体知识仍由精灵法师家族掌握，不能把某类法术写成所有精灵的天生能力。

精灵可以学习其他种族保存的完整魔纹，但适应陌生几何、投影方式和供能习惯通常慢于人类。一旦掌握，其重复精度和长期稳定性往往更高。精灵同样不知道如何拆分并重新组合魔纹。

## 长寿社会的后果

- 同一名家族长者可以控制知识和继承数百年；
- 政治职位和财产很难通过自然死亡快速更替；
- 一场争端可以持续多个人类王朝；
- 长者亲历的历史不易遗失，但其错误解释也可能长期固化；
- 年轻精灵可能几十年甚至上百年都无法取得实权；
- 家族叛离者与改革者面对的是仍然活着的祖辈，而不只是旧制度留下的文本。

精灵社会可以发展出长期规划和稳定维护的优势，也会承受权力僵化、人口损失难以恢复和新知识传播缓慢的代价。

## 传统精灵法师家族

传统精灵法师家族通常由仍然活着的古老引导师长期控制。权力不会因普通的代际更替自然交接，一名数百岁的法师也可能继续被千岁始祖视为尚未成熟的继承人。

家族知识按照权限分层：

1. 家族成员都能接触的基础理论；
2. 已激活法师可以学习的常用法术；
3. 少数继承者可以接触的家族核心法术；
4. 只有完整传承者掌握的初次引导方法；
5. 由最古老成员独自保存的危险、失传或政治性知识。

并非每一名精灵法师都能继续引导别人。家族可以数百年不培养第二名完整引导师，这会强化始祖权力，也会使始祖意外死亡成为严重的传承危机。

精灵低生育率迫使家族偶尔通过婚姻、收养、宣誓和师徒关系吸收外人，但完整引导术通常仍掌握在极少数古老成员手中。外来者可能需要几十年甚至上百年证明忠诚。

传统精灵家族可以比国家和王朝更加长寿。一份条约的签署者在几百年后仍然亲自坚持原有解释，年轻精灵也无法只靠等待长者自然死亡获得权力。

## 与灰精灵谱系的关系

灰精灵来自某支精灵在迁徙、隔离和特殊环境中形成的稳定分支。精灵漫长的世代意味着这一分化需要非常久的历史，不能在几十年中完成。

灰精灵始祖因灾害中的知识封锁与传统家族决裂，被放逐后在长期隔离中形成稳定分支。形成地区、选择压力、身体差异、繁衍兼容和双方身份认同仍待后续专门讨论。

## 尚待确认

1. 精灵是否能够由其他种族法师完成初次引导。
2. 精灵的主要文化分支、国家和当前人口规模。
3. 灰精灵形成的具体地区与生理变化。
4. 精灵在世界底层历史中的真实起源。
