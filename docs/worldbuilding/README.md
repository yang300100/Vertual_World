## 文档目的

本目录保存正式世界的世界观、隐藏真相、人物认知边界和后续待定问题。它与 `docs/design/` 的职责不同：

- `docs/design/` 说明世界引擎如何推进、记录和裁判。
- `docs/worldbuilding/` 说明正式世界本身是什么。
- `docs/ARCHITECTURE.md` 只说明当前代码已经实现的运行边界。

当前数据库中的“初始世界”、晨星广场、林澈、白露和瑞恩仍是测试数据，不属于正式世界设定。本文档完成不代表正式世界数据已经重构。

## 写作总原则

作者和世界引擎可以知道底层真相，人物只能知道自己观察、学习或被告知的内容。“前文明”“纳米机器人”“人工智能”和“系统权限”是设计层术语，在人物尚未建立对应概念前，不得直接出现在其对话、记忆、地点描述和主视角日志中。
