## 文档目的

本目录保存正式世界的世界观、隐藏真相、人物认知边界和后续待定问题。它与 `docs/design/` 的职责不同：

- `docs/design/` 说明世界引擎如何推进、记录和裁判。
- `docs/worldbuilding/` 说明正式世界本身是什么。
- `docs/ARCHITECTURE.md` 只说明当前代码已经实现的运行边界。

当前数据库中的“初始世界”、晨星广场、林澈、白露和瑞恩仍是测试数据，不属于正式世界设定。本文档完成不代表正式世界数据已经重构。

## 当前待决定问题

1. 当代居民是前文明殖民者的后代、被改造的原生种族，还是两者混合。
2. 前文明已经灭亡、撤离、失联，还是仍在遥远区域活动。
3. 各基源种族在世界底层历史中的真实起源，以及尚未设计的区域衍生谱系。
4. 神明是否与管理智能有关；即使有关，它们是否仍具有完整记忆和原始使命。
5. 不同能源来源、维修、增殖和永久失效在各种地区的具体比例。
6. 法师亲自引导的具体步骤、年龄、耗时和失败风险。
7. 真正前文明造物的统一材质与视觉特征。
8. 第一片大陆、国家、教会、法师组织和正式人物。
9. 法师寿命、体质增益、个人储备上限和过度施法伤害的具体范围。
10. 各法师家族如何选择继承人、吸收外人、交换知识和惩罚泄密者。
11. 世界启动时是否发生一座深层遗迹重新活动的初始事件。
12. 世界、星球、时代与历史断裂事件的正式名称。
13. 精灵的主要文化、国家、地理分布和当前人口规模。
14. 灰精灵形成地区、环境选择压力、身体差异和与其他精灵的繁衍兼容性。
15. 导致灰精灵始祖决裂的灾害类型、规模、责任者和历史叙事。
16. 不同种族的法师能否互相完成初次引导，以及发音和身体差异如何适配。
17. 灰精灵公共记录、引导师资格、危险施法和对外知识传播的具体治理制度。

## 写作总原则

作者和世界引擎可以知道底层真相，人物只能知道自己观察、学习或被告知的内容。“前文明”“纳米机器人”“人工智能”和“系统权限”是设计层术语，在人物尚未建立对应概念前，不得直接出现在其对话、记忆、地点描述和主视角日志中。
