# 伊瑟拉正典编年与年代对照

> **修订状态**：本文件属于"三大陆 + 13 政体"旧线。当前物理地图与政权线已切换为 Noryia 单大陆 + 21 州(见 `29-noryia-nations-and-factions.md`、W117)，本文件在政体建国年代/历法层面已被取代，仅作旧线背景参考。

状态：作者层统一编年、三大陆主要政体的建国年代与当前年份已确认。各文明的地方历法、口述史和宗教纪年可以不同，但不得与本文件的事件先后关系冲突。

## 作者层时间基准

作者层使用“环后纪年”（简称 `H`）排列事件。`H 0` 定义为星外前文明完成轨道环状巨构并离开伊瑟拉的那一年；它不是任何地表文明普遍使用的历法。当前作者层年份为 **H 24816 年**。

伊瑟拉一年固定为360天，四季各90天；双星周期20天、月相周期30天、双星与月相共同大周期60天。所有下列年份均按这一年长计算。对远早于 `H 0` 的本土生命史只使用“环前”描述，不伪造不可能由当代文明精确测量的年份。

作者层将金白主星称为阿尔萨、橙红伴星称为梅罗、大型月亮称为赛芙。地方历法可以使用完全不同的宗教或航海名称，但其年长、双星周期和月相周期必须服从同一套天文事实。

## 环前：本土生命与早期文明

- **环前久远时代**：伊瑟拉本土生命、魔兽与自然魔纹形成；龙族早期谱系出现并长期独立发展。
- **环前近代**：不同本土智慧谱系在河谷、森林、高原、海岸和岛链形成稳定社会；没有共同帝国或共同文字。
- **H 0 年**：星外前文明完成环状巨构并离开。巨构只记录，不向地表传输知识；外部文明仍无法理解其科技性质。

## H 24001 至当前：现时代局势

当前为 **H 24816 年**。第二次盐粮封锁在法律上已经解除，但实质检查、债务争执和护航紧张仍然存在。三汇水文抄本、卡尔萨水库、黑潮避难港和东门走私单纹构成同一时期互相牵动的五条危机线。

外部文明依旧处于单纹低魔阶段。跨境争端会涉及完整纹路、储能材料和引导师流动，但没有任何外部政体掌握组合魔纹或从环状巨构获得知识。龙族仍未公开介入。

## 诺赫兰中央河网的正式水路

锻河发源于赫塔尔西部山脉，承担金属、木材和山口货物运输；镜河从伊莱北部湖群流出，承担药材、湖运和冬季储粮；赤泉河来自赤原北缘，承担牲畜、皮革和南部商队补给。三河在澜誓城汇合后称为阿德河，并向东流入东澜港和维斯塔裂海。

“锻河—阿德—东澜路”在 H 14622 年获得东岸船籍约保护，是诺赫兰第一条能同时连接西部工坊、中央粮仓、赤原护路与远海港口的稳定贸易路线。它解释了为什么澜誓城既是王都，也是水权、粮价、港税和跨区域法律争端的集中点。
