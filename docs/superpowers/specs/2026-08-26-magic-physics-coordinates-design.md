# 伊瑟拉魔法场物理律 — 坐标系(A+B)设计规格

日期：2026-08-26
状态：A(基础度量与场论)+ B(频谱-材料-元素分类) 已对齐，待审阅后进入撰写计划。C/D/E 后续单独模块。

## 一、背景与目标

`02-magic-field-and-patterns.md` 已给出魔法场的定性框架(魔纹、投影、储能、枯竭、禁永动)。本规格把其中的**度量与分类**立成一套连贯的量化坐标系，作为后续 C(储能参数)、D(环境动力学)、E(施法参数)的依托。

**量化方式**：采用**描述性术语**——用"标准浓度""魔力当量""基准输出""补给率"这类通用读数 + 相对档位来表达，不构造自造单位制、不建立完整公式系统。**但各关系式参考现实中类似的物理表达式**(能量守恒、平方反比、Beer-Lambert 衰减、干涉叠加、一阶恢复动力学)作类比，仅作作者层推演与自洽校验；当代人物不知道公式，只感知相对强度与档位。

**红线**(贯穿全部)：能量守恒、禁永动、单纹低魔、本坐标系=作者层真相(当前文明只经验感知档位，不知底层读数)、不与龙族高魔线与前文明科技混淆、民俗元素不等于作者层谱系。

## 二、模块 A · 基础度量与场论

### A1. 魔力场正式名称(作者层)

作者层将魔力场正式称为 **泓流**(符号写作 `泓`)，与各文化的"魔力、地脉、神恩、灵潮"区分——后者是民俗近似词，不是底层名。文中可用"泓流场""泓流波"。当代人物不知道"泓流"这个作者层称呼。

### A2. 魔力波七属性(量化)

| 属性 | 作者层度量 | 作用 |
|---|---|---|
| 振幅 | 用**场强**，单位 `n`，见 A3 | 当前可用能量与效果强度 |
| 频率 | 用**频谱位置**(相对低频↔高频) | 与哪些材料/生命/自然现象耦合 |
| 相位 | 用相对角度(0-360 分度) | 叠加、抵消、同步 |
| 波长 | 用相对空间尺度(短/中/长) | 影响空间尺度与传播特性 |
| 相干性 | 用相干度 0-1 | 能否保持稳定与精密 |
| 传播方向 | 用方向向量 | 能量与效果到达路径 |
| 边界响应 | 用响应分类(见模块 B3) | 材料/环境对魔力的吸收、反射与引导 |

### A3. 描述性度量坐标系

以**可观测基准**定义 4 个基础量，不造新字，用通用读数 + 档位：

| 量 | 基准 | 描述方式 | 典型档位 |
|---|---|---|---|
| 浓度 | **标准浓度 n=1.0**：标准恒星日正午、晴空、标准海拔下开阔地表的泓流场强 | 用字面倍数描述 | 贫魔 <0.2n、常魔 ≈1n、富魔 >3n、极魔 >10n |
| 容量 | **魔力当量 e**：一件标准刻录石晶的满储容量 | 用当量计 | 低魔 1-3e、中魔 10-30e、高魔 100-300e、秘藏 >1000e |
| 功率 | **基准输出 k**：一次标准火焰纹满持续释放的平均输出 | 用基准倍数 | 微弱 0.1k、标准 1k、强力 10k、近工业级 >100k |
| 流量 | **补给/衰减率**：按每标准日补充或损失的魔力当量 | 用每标准日描述 | 富魔地 ≈3e/日、常魔 ≈0.3e/日、贫魔 ≈0.03e/日 |

作者层用这些读数推演；**当代人物只知道"这件器物比那件耐放""这片地快枯了"这类相对判断**，不知道 n/e/k 的精确值。

### A4. 场论关系(参考现实类似的物理表达式，仅作者层推演用)

- **能量守恒(转换)**：`E泓 = η · Esrc`，η∈(0,1) 为过程/谱系相关的转换效率(类比光电转换与热机效率)。魔力不是无代价新增的能源；任何自充循环宣称都必须找到真实消耗来源。
- **几何 + 介质传播衰减**：自由近场按平方反比减弱 `I(r) = I0 / (k·r^p)`(p≈1~2，由传播形态定——开阔/波导)；叠加介质吸收后 `I = I0 · e^(−αd)`(Beer-Lambert 类比，α=该谱系在该介质的吸收系数，d=路径)，合成 `I(r) = I0 · e^(−αd) / r^p`。
- **干涉叠加**：来自波叠加原理。两束强度 I1、I2、相位差 Δφ 时 `I合 = I1 + I2 + 2√(I1I2)·cos(Δφ)·γ`(双缝干涉强度类比，γ=相干度 0~1)。同相(Δφ≈0)增强、反相抵消；γ 越高叠加越稳定精确。
- **相干度 γ**：类比相干长度/时间，表示泓流场在时间与空间上相位相关的程度，γ 越高越能稳定干涉与精密长期维持。
- **地区耗散与恢复动力学**：浓度改变率 `dN/dt = G(t) − L·N − Σ抽取`。G(t)=供给(正比当地泓流动能，见模块 D)，L=泄漏/耗散系数，N=当前浓度。停施后按一阶趋向平衡恢复 `N(t) = N_eq + (N0 − N_eq)·e^(−λt)`(λ=恢复速率)。贫魔区=抽取>供给，N 持续下沉；恢复随环境因子(日照、材料、吸收源)变化，见模块 D。

## 三、模块 B · 频谱-材料-元素分类

### B1. 频谱轴(作者层)

以**频率**为主坐标，从低频到高频，映射 02 已确认的 5 类耦合；各类有相对频谱区间：

| 谱段 | 频段(相对) | 耦合类型 | 承担的效果 |
|---|---|---|---|
| 低频长波 | 低 | 材料、动量 | 结构改变、硬化、推动/拉拽/偏转/护盾 |
| 中频 | 中 | 热、光-电 | 加热/点燃/熔化、发光/电流/改变光路/视觉隐蔽 |
| 高频短波 | 高 | 生命、精密感知 | 止血/修复/器官稳定、高精度感应 |

### B2. 五大标准谱系(作者层)

| 谱系 | 频段 | 代表单纹效果 | 典型材料 | 民俗常称(不可当底层) |
|---|---|---|---|---|
| **热焰系** | 中频偏热 | 加热、点燃、熔化、热转移 | 焰石、高温矿石 | "火之力" |
| **动势系** | 低频 | 推进、拉拽、偏转、减速、护盾 | 重磁矿、惯导晶 | "风雷/地动" |
| **光曜系** | 中频 | 发光、闪光、电流、改光路、视觉隐蔽 | 曜晶、透明石英 | "光/电" |
| **物性系** | 低频长波 | 硬化、韧化、防裂、导热心、震动调律(矮人"物性调律") | 固化土、金属瓷 | "土之质" |
| **生息系** | 高频短波 | 止血、修复、器官稳定、强化、反应抑制 | 兰木、生肌矿 | "灵/生机" |

### B3. 材料五分类(按对频谱的响应)

| 分类 | 对泓流波的作用 | 典型用途 |
|---|---|---|
| **响应体** | 与魔力波稳定耦合，适合刻纹 | 魔纹载体(石、金属、骨、织物) |
| **导体** | 低损耗传递魔力 | 魔纹导路、法杖芯 |
| **吸收体** | 截留魔力 | 储能、屏蔽 |
| **反射体** | 偏转魔力波 | 护盾层、隐蔽 |
| **绝缘体** | 屏蔽魔力 | 隔绝层、防护 |

同一材料在不同频谱段的响应可不同(某矿对热焰是导体、对生息是绝缘)，正因如此分谱系记录才有意义。

### B4. 作者层 vs 民俗(写死边界)

作者层用**五大谱系 + 描述性读数**；民俗用火/水/风/土/灵等模糊称呼。二者**不等价**：民俗常把不同谱系混称为一个元素，或给同一谱系赋予不同寓意。**任何人物、文化记录或宗教解释不得被当作作者层谱系真相**；模型只能把民俗当作可观察的文化说法，不能据此推断底层物理。
