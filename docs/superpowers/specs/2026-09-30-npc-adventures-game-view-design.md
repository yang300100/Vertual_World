# NPC 自主冒险与 2D 游戏视图设计

日期：2026-09-30

## 目的与验收口径

哥哥希望 NPC 不只写下个人目标，还会持续执行并留下可核验的行动。首个完整场景是冒险者自行接取公会悬赏，走到野兽所在地，完成真实战斗，返回公会领取一次赏金。哥哥也希望直接在地图上观察人物活动，以 WASD 或触屏摇杆控制玩家，在整张世界地图自由移动；进入城镇范围时自动使用城镇详图，离开后回到世界图，并能和附近人物说话、交互。当前地图内的全部 NPC 都显示标记。这是玩家界面的可见范围，不改变 NPC 的情报边界。

验收必须同时检查数据库状态、世界事件、角色坐标、战斗结果和金钱转移；只有界面文字或模型回答声称完成，不算完成。

## 仓库现状

- `NpcGoalService` 能根据预先登记的作息计划推进储蓄与制作；`npc_todos` 会作为文字目标传给裁判。它们都没有悬赏接取、证明击败目标、返程结算的持久状态链。
- 已有世界时钟、人物位置、地理导航、持续移动、战斗裁判、世界事件和 NPC 生活需要。新任务链复用这些事实与动作，不另造战斗或传送结果。
- 网页已有世界图、城镇详图、点击寻路和玩家标记；完整世界快照约五秒刷新一次。地图目前不绘制全部 NPC，也没有 WASD、摇杆或交互式场景同步。世界包含世界图及大量按城镇关联的详图。

## 实现次序

先交付 NPC 悬赏的可运行纵向流程和可读追踪接口，再交付游戏视图。两者共享现有角色坐标、世界事件和任务状态；游戏视图不成为第二套世界模拟器。

## NPC 悬赏任务链

### 数据与状态

新增有世界、发布公会、目标野兽、目的地、赏金、有效期限和可用状态的悬赏记录；发布时从公会资金预留赏金。新增 NPC 接取记录，保存接取者、当前阶段、世界时间、移动与战斗引用、证明事件、失败原因。新增逐步执行记录，每条关联真实世界事件或移动记录。对同一悬赏，领取与支付都有数据库唯一约束及幂等检查。

状态按 `可接取 → 已接取 → 前往目标地 → 交战 → 已取得战果 → 返回公会 → 已支付` 推进。不可达、目标先被别人击败、角色伤重、超时等进入明确的暂停、改选或失败状态；重启后从持久状态恢复。死亡或失效的人物不能继续执行。休息和求生需要可以暂时抢占悬赏，不会把任务误标为完成。

### 自主选择与执行

公会发布悬赏后，符合冒险者身份的 NPC 在世界心跳中主动评估：健康、装备、性格、距离、路线、期限、风险和报酬。选择必须有确定的规则与可解释原因，模型可以影响偏好，但不能直接写入任务成功状态。一个 NPC 同时只执行一条悬赏；其他生活目标仍有机会运行。

赶路调用现有移动与导航服务，记录行程，只有实际抵达才能进入交战。交战调用现有战斗裁判，并要求本人的战斗事件证明指定野兽已被击败；其他人物击败野兽时不得冒领。返程同样必须真实抵达公会。结算在一个事务里核验接取记录、战果、返程位置与预留赏金，生成支付事件并给 NPC 加钱；重复心跳不能重复领赏。

首个演示世界提供一个公会、一个野兽目标和一张悬赏，确保自动推进能在无玩家命令下发生。其他悬赏可沿同一数据模型扩展。

### 可观察性

提供 NPC 当前目标、当前阶段、下一步、受阻原因、位置和按世界时间排序的步骤历史。每一步可追溯到移动、战斗或支付的真实记录。人物详情展示当前计划，地图可高亮追踪选中的冒险者；观察不触发其行动。

## 2D 游戏视图

### 地图与渲染

保留现有地图资源和经纬度坐标系统。新增轻量场景层，使用已有图片作底图，在画布层绘制玩家与当前地图范围内全部 NPC。世界图显示世界范围人物；城镇详图只显示该图范围内人物，并提供缩放、镜头跟随和人物选择。人物多时按屏幕范围裁剪、标签避让；鼠标与触屏都可点选。

服务端依据玩家的真实位置、城镇 `area_radius_km` 与城镇关联详图决定当前场景。进入城镇范围自动切到详图，离开自动切回世界图；坐标始终是同一套世界经纬度。缺少专用详图的城镇使用按地点范围生成的局部地图视图，不把玩家留在全球图上。手动查看其他地图与自动跟随玩家的模式分开，避免镜头争夺。

### 控制与同步

WASD、方向键和触屏摇杆产生同一种方向输入；按住持续移动，松开停止，点击地图仍可用于远距离寻路。新增受限的玩家转向接口，更新现有移动路线或短目标，不接受客户端直接设置角色坐标。服务端校验输入序号、最大速度、导航可达性、当前世界时间和并发版本；暂停世界时间时角色不移动。客户端逐帧插值或预测，收到服务端结果后平滑纠正。

新增轻量场景快照，只传当前地图需要的角色坐标、行程、地图标识、世界时间和所选 NPC 的目标摘要。游戏视图打开且可见时约每秒同步一次；页面隐藏时降频。服务端仍是位置与行动事实来源，普通完整世界快照继续用于其他管理界面。NPC 坐标随世界时钟推进而变化，前端在两次同步间平滑绘制。

玩家靠近 NPC 后可选择“交谈”“查看”“交互”；这些按钮调用既有对话和动作 API，服务端再次校验距离与可执行条件。移动输入不会绕过战斗、背包、房间和交互规则。

### 时间与规模

键盘移动使用现有世界时间和人物速度；世界加速会影响世界内位移，暂停则停止。游戏视图的客户端刷新率只影响画面，不改变世界时钟。轻量场景快照避免每秒传输地图全集；当前地图范围过滤、渲染裁剪和请求降频避免大量 NPC 时卡顿。实现时用代表性世界包做负载验收。

长距离步行与 NPC 行动仍按世界时间发生；在 1 倍流速下，跨洲旅行和数小时后的任务进展也需要对应的现实时间。游戏视图保留世界倍速控制及点击远距离寻路，逐帧动画只表现已经发生或正在进行的行程，不虚构世界进度。世界图上的密集人物标记可以合并显示，放大或选择后仍可定位其中每一名 NPC。

## 验证

1. 在无人下命令的演示世界中，冒险者从发布悬赏走到支付，每个阶段有真实来源；实际坐标与金钱前后可核对。
2. 阻断路线、野兽被别人击败、NPC 受伤、任务过期、服务重启和重复心跳都不会伪造完成或重复支付。
3. 在世界图与城镇图边界移动时自动切换，坐标连续；地图内所有 NPC 出现且随实际行程更新。
4. WASD、摇杆、松手停止、点击寻路、交谈与交互在桌面和触屏可用；客户端预测不能越过服务端速度或地形校验。
5. 跑相关后端测试、完整回归与浏览器交互检查，并检查地图多人场景的同步与渲染性能。

## 明确边界

第一版是可玩的 2D 地图与角色控制，不包含动画战斗场景或完整 RPG 内容库。NPC 悬赏链先实现一个真实闭环，再扩展任务类型。地图上展示全部 NPC 是玩家界面选择；NPC 自己仍依据目击、消息与个人经历制定目标。
