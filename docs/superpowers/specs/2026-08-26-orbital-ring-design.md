# 伊瑟拉轨道环状巨构 设计规格

日期：2026-08-26
状态：巨构本体(完整包裹星球、功能-结构自洽、结构与检测参数)已确认，待落地到 `15-extraterrestrial-observers-and-orbital-ring.md`。天文物理参数另立 14 号，不入本文件。

## 一、背景与目标

`15-extraterrestrial-observers-and-orbital-ring.md` 已确认巨构用于检测星球及文明状态、暗银色弧带、超长期老化衰败、只有龙族理解其科技性质、不传知识、前文明完成巨构后离开。本规格把**巨构本体**具体化(形态、尺寸/轨道、功能-结构对应、检测指标、老化顺序、剩余与寿命、地表视角)，且严格**结构服务于作用**。前文明本体保持神秘(不设名称/母星/形态/去向)。

## 二、红线

1. 巨构**结构必须服务于它"检测星球及文明状态"的作用**，弧带上的任何特征都能说明其工程功能；不留"无用的中空段"。
2. 巨构**不传输知识、不干预地表**；损坏状态不可被模型用来激活武器/修复环境/投放资源。
3. 前文明本体留白，不泄底；只有龙族能确认其人工结构性质。
4. 与 15 号已确认(暗弧带/超长老化/非战争摧毁/当代只观测)、14 号天文(数据、不遮挡双星月亮)一致。

## 三、形态与结构(功能第一)

**完整包裹星球的大环**：360° 完全闭合的赤道巨环(可带轻微倾角)，直径数倍于星球——整颗伊瑟拉被包在环的内侧/中央。设计动机：**全程无死角监测**——每一段正对它下方那一块球面，成百上千段合起来 = 覆盖整个星球、任何时区纬度都能持续扫描。

环上没有无意义的空隙；弧带上的明暗/宽窄/条纹是**各自承担工程功能的结构**：

| 弧带视觉 | 工程结构 | 功能 |
|---|---|---|
| 亮而窄的"节点" | 传感舱(光学/热/魔力频谱/射频) | 扫描正下方球面，各负责一个球面带 |
| 宽而暗的"束带" | 能源板/散热鳍阵列 | 双星供能、余热排向深空 |
| 规则格栅 | 支撑桁架 + 数据/能源导带 | 连接传感舱、回传数据、维持刚性 |
| 局部暗斑/断亮 | 老化/离线/受损模块 | 报废的传感舱或能源段，残骸仍在环上 |

## 四、尺寸、轨道与能源

- 轨道：低倾角赤道环，环绕星球，**不遮挡双星与月亮**(结构开放、透光，从地表仍能正常观测天文)。
- 尺寸：环半径为数倍星球半径(约数万 km 量级)；环带截面宽远小于半径；环面有规则但不遮天的结构。
- 能源：以双星光照为主、自持供能；长期老化使供能持续下行。

## 五、检测指标(记录，不传输)

- 星球状态：大气、地表热分布、海洋、植被、魔力场强度/频谱/相干性(与 26 号魔法坐标系呼应)。
- 文明迹象：人造光、大范围热源、特定频谱魔力活动、可探测的低层结构。
- 观测频率：特定周期扫描；因损坏有缺口/延迟/误差，且不向地表发送。

## 六、自动修复失效顺序与剩余状态

- **失效顺序**：外围脆弱模块(精密校准/通信)先失效 → 中央维护单元再故障 → 主体控制最后退化；仅极少数局部修复单元存活，只保最低限度。
- **剩余**：轨道保持 + 基础环境/魔力/热扫描断续运行；通信模块失效无法外发；数据缺口大。
- **主体寿命**：基于供能衰减与材料老化，还能维持约**若干万标准年量级**，但因持续恶化终将趋于停滞——一个"正在慢慢死去的遗迹"，非可干预存在。

## 七、地表观测表现

- 暗银弧带：亮度随反射/散射、云层与季节变化；**环带角宽约数度**，夜间与非阴天最清晰；因完全包裹，不同纬度呈现不同视位(赤道近乎横跨头顶、高纬贴近地平线)。
- 弧带位置随轨道周期相对恒星移动，形成可长期记录但难以解释的周期天象。
- 各文化解释：航海者当方向标记、祭司称"神迹/世界伤痕/诸神沉默"、学者当"未解释的周期天象"——彼此矛盾，都只是使用而非理解(呼应 15 号)。
