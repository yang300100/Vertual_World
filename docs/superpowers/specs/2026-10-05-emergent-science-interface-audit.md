# 自主科研接口核查记录

日期：2026-10-05。只读核对已有源码；本记录不代表科研功能已经实现或设计已经获批。未启动世界、未调用外部 API、未修改存档。

关联设计：`2026-10-05-emergent-science-design.md`。

## 人物知识边界

`world_engine/knowledge.py:126` 在未传 `audiences` 时允许全部受众，包括作者隐藏资料。不能直接复用默认搜索供科研人物阅读。

`knowledge.py:263` 的角色公共搜索显式限定 `character_common`，可作为安全入口的参考。`knowledge.py:283` 将缺少受众标记的文档默认归为 `author_hidden`。后续实现须在真实提示词边界验证：作者公式、材料隐藏系数与未来科技名单均未进入角色输入；guardrail 也不能自动等同于人物已经知道的事实。

## 突破编年与因果

`world_engine/repository.py:569` 将 `scope=chronicle` 映射为 `importance=major`。仅写一个新事件名称不会保证进入编年。

`world_engine/event_log.py:25` 的重大事件集合尚无 `world.technology_breakthrough`。后续实现必须明确登记其重要性，并在同一事务中登记科技与突破事件。

`world_engine/event_history.py:32` 的自动地方分类仅覆盖部分资源、元素与建筑类型，新增科研事件不会自动取得正确范围。现有自动因果主要来自活动、合同和反应；科研试验、修订和传播的证据前因须通过 `EventHistoryService.link` 明确建立，不能凭编年叙述替代数据库关系。

## 外部 API 上限

哥哥已选择首轮最多 **12 次调用、累计 200000 token**。

`world_engine/collective_runner.py:155` 的现有默认值为 120 次、1500000 token、单次输出 32768 token，不能沿用默认值启动科研运行。

现有 `usage()` 统计全部调用记录；已知输入/输出用量相加，缺少用量时采用预留与已知部分的较大值。构造器拒绝启用技术自动重试的后端。这些保护逻辑可以参考，但仍须实现独立科研会话的累计账目、并发预留及恢复后持续计账。

现有汇总表达式只有 input/output 两项。需核对实际提供方 reasoning 用量是否包含在 output 中，避免漏计或重复计算；不能仅因已有旧账逻辑就宣称新的预算保护通过验证。

## 后续核验范围

设计获批后，实施计划应覆盖上述接口，以及独立一致性副本迁移、真实证据可见性、科技方法实际复用、认证去重、事务回滚和源码冻结。离线验证完成前不启动真实 API 科研运行。

本核查没有重复执行旧灾难或浮空城测试，也没有验证账户余额或产生科研成果。
