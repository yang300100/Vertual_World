# 伊瑟拉条约与宪章集 — 设计规格

日期：2026-08-26
状态：已与作者对齐，待审阅后进入撰写计划

## 一、背景与目标

`docs/worldbuilding/21-war-and-treaty-ledger.md` 已登记影响三大陆格局的主要冲突、条约的**起因、结果与遗留问题**，但都是概要，没有任何一份条约提供**可直接引用的条款正文**。

本规格的目标：为三大陆 13 个政体的立国文书与主要跨区条约，产出一版**统一格式、可引用、内部一致**的条款原文，把世界的法律骨架立起来。人物可以围绕"某条第几款怎么解释"产生真实的法律冲突，而不是凭空争执。

## 四、统一条约卡格式

每份条约卡固定 5 块，保证 14 份高度一致、可互相引用：

1. **定位**——一句话：管什么、约束谁、在哪适用。
2. **立约背景**——2-3 句对应当年的危机（呼应 21 号账本的起因，但不复述全部因果）。
3. **核心条款**——按"第 X 条"编号，每条写清权利 / 义务 / 例外 / 边界，可被人物直接引用。通常 3-6 条。
4. **解释与修订**——谁有权解释、如何改约、条款冲突时以何为准。
5. **作者层注**——各方不同解读、公开与私下的分歧、遗留未决点（对接 21 号账本的遗留问题，为人物冲突埋种子）。

## 五、条款粒度原则

**具体可引用 + 刻意留解释空间**。

- 条款必须写具体：明确的权利、义务、例外、边界，让人物能引用"第 X 条"主张立场。
- 重点条文刻意在文字上留下**两种可成立读法**（如"紧急状态是否可打破次序""何时算达到预警线"），让"条款本身如何解释"成为可争论的法律问题，而非必须靠违法推动冲突。
- 每条的核心条款优先服务该政体的**管辖事务**（见第二节），不写与该条约无关的内容。

## 六、各条约的管辖领域与预留争议点（写作依据）

| 文件 | 核心条款应覆盖 | 刻意留的解释空间 |
|---|---|---|
| 火脊长夜盟约 | 火山观测、预警门槛、迁港顺序、救援船、火山玻璃归属 | 预警到何种程度可停产；私人海湾可否因灾害被征用 |
| 高原议盟条款 | 水库/梯田/牧道/矿区维护责任分席、水量记录、补偿 | 水量记录解释权；水库扩建对下游的影响如何认定 |
| 伊莱互助契约 | 互助仓、冰湖通行、失踪者搜救、药材副本、季节关闭 | 旧债时效（长寿 vs 短寿）；税籍是否覆盖地方通行权 |
| 《河流议约》 | 主水道维护、六席与王权、粮仓优先、水权继承 | 旱季上游可否截流；粮仓是否先供军需 |
| 赤原五誓会 | 五誓席、越冬地、护路、牲畜、边堡、失约处理 | 季节牧道可否变永久税道；非成员/跨境家庭身份 |
| 九炉代表会盟约 | 器物登记、维护、预计寿命、拆解责任、赔偿 | 工艺秘密可否免赔偿；矿脉归属；军需接管边界 |
| 《东岸船籍约》 | 船籍副本、海难救援、债务船员、港口维护、航盟席位 | 中立通行定义；何为"粮食船"；储能物品是否军事物资 |
| 绿冠封河会 | 季节关闭、采集上限、药材记录、护林责任、审计 | 可否永久限制外来测量；采集承载的认定 |
| 南潮互保章程 | 船籍互认、海难救援、中立、港税、城邦主权 | 救援可否被征作军事；粮食条约的边界 |
| 九井共同立约 | 井群登记、商队救援、最低救援水、驿站、失约 | 公开水文记录是否引外来干预；井群所有权边界 |
| 中裂海航盟章程 | 航盟海法、航道税、护航、灯塔、补给、储能标准 | 统一储能标准；港口检查权限；黑潮航线可否军化 |
| 东门中立港章程 | 外商居留、中立、多语言法庭、危险纹路登记、禁令程序 | 中立与安全如何平衡；走私单纹管辖权归属 |
| 黑潮岛盟约 | 风暴观察、救援船、禁航、漂流物归还、避难港 | 避难港可否被搜查；漂流物所有权；中立 vs 军事 |
| 《灯塔停火约》 | 救援中立、禁军事征用、双历法+天象日期、黑潮中立 | 救援中立定义；谁认定"军事"；日期换算规则 |

## 七、与现有一致的约束

- **不对接编年**：所有年份与事件先后必须以 `19-canonical-chronology.md` 为准；本集不新增年代、不改变已确认的建国年。
- **不重复 21 号账本**：21 保留"因果与遗留问题"，本集保留"条文本身"，二者在各自头部声明职责边界。
- **不定义新政体**：本集只服务现有 13 政体，不新增政体、不改变其管辖事务归类。
- **人物可引用本国条约**：条文是政体公共制度，普通人物了解本国契约属于合理常识；但**全套条约全文**不应作为"每个普通人物共享知识"注入。作者层默认 `audience=author_hidden`；哪些条约可进入 `character_common` 由人物知识图（待 D011 实施后）按人物 ID 提供。
- **不泄露隐藏真相**：本集不含龙族、星外前文明、轨道巨构内容，不违反 `author_hidden` 边界。
- **保留叙述分歧**：各政体对同一条约有不同的官方称呼与责任解释（如《河流议约》= "河契建国" vs "堤坝让步"），作者层须保留可验证的先后关系，但人物记忆与史书可互相矛盾，不得把某一政体叙述写成绝对真相。

## 八、验收标准

1. `25-treaties-and-charters.md` 存在，14 份条约卡齐全，每张卡含 5 块。
2. 每份条约卡按首签年排序，分节正确（诺赫兰 7、塞拉菲尔 3、维斯塔 3、跨区 1）。
3. 每份条约的核心条款覆盖其管辖事务，且至少有一个刻意留下的解释空间。
4. `README.md` 索引新增 W112 登记，推荐阅读顺序新增第 25 项。
5. 全文无新增年代、无改动 19 号编年、无隐含龙族/星外底层真相；作者层注均对接 21 号账本的遗留问题。
6. 与 `20-current-powers-and-customs.md` 中的现任代表立场一致（如女王塞芙拉主张扩大调水权、洛弥要求 60 天大周期审计）。
