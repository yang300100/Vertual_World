# 伊瑟拉生命起源与种系设计规格

日期：2026-08-26
状态：共同祖先框架(极远古共源+多谱系演化支)、三大演化超支、分化年代、迁徙要点已对齐，待落地。

## 一、背景与目标

`05-species-and-cultures.md` 已确认多智慧种族、本土演化、星外前文明不是祖先/播种者，并留白"各基源种族是否具有更早共同祖先，由本土生命史解释"。本规格补全这套**生命起源与谱系树**：共同祖先框架、各族演化支归属、分化年代、迁徙要点。

## 二、红线

1. 全部物种来自**本土生命演化**；星外前文明不是任何种族的祖先、播种者或改造者。
2. 不是"同一批被改造的人类"；各族为**多个生态位各自演化出的智慧谱系**。
3. 种族生理 ≠ 文化 ≠ 个人特质(继承 05 的拆分原则)。
4. **作者层 vs 民俗**：真实生物谱系是作者层事实；各文化的创世神话、种族起源故事可以与底层不同，不得误当底层真相。
5. 不新增基源种族、不改变 05 已确认的种族名单与灰精灵/蜥蜴人来历。

## 三、共同祖先框架(极远古共源 + 多谱系演化支)

各族共享本星球生命的**远古非智慧远祖**，但分属互相远缘的演化超支，各自独立走向智慧。这是对"共同祖先"的回答：共同的是生命起点，不是单个智慧祖先。

## 四、三大演化超支与各族归属

| 超支 | 生物来源 | 包含种族 |
|---|---|---|
| 睿兽支 | 温血、社会性、直立的哺乳—灵长演化 | 人类、精灵、兽人、巨人、地精 |
| 主龙支 | 鳞甲、高认知恒温演化的爬行—主龙 | 龙族、蜥蜴人 |
| 麟土支 | 穴居、致密、震动感知的地行演化 | 矮人 |

同超支内各族由不同生态位分化；不同超支之间生物上互相远亲。

## 五、谱系树

```text
本星球生命起点
 ├─ 主龙支(最早)→ 龙族│蜥蜴人(人类×龙族混合)
 ├─ 麟土支   → 矮人
 └─ 睿兽支
     ├─ 巨人(高原孤立生态位)
     ├─ 精灵(古林/湖林,长寿低生育)
     ├─ 兽人(草原/高地,高体能)
     ├─ 地精(丘陵/湿地,短寿群体)
     └─ 人类(河谷/海岸,适应最广)
```

## 六、分化年代(环前相对时序)

| 年代层 | 事件 |
|---|---|
| 环前远古 | 本星球生命起点；三大超支分离；主龙支(龙族)出现最早 |
| 环前上古 | 麟土支(矮人)、巨人(高原)出现 |
| 环前中古 | 精灵(古林)、兽人(草原)、地精(湿地)演化 |
| 环前近代 | 人类(河谷)扩散；各族向三大陆迁徙，形成当今政体分布(18) |

## 七、迁徙要点

- 人类：河谷海岸 → 诺赫兰/塞拉菲尔/维斯塔(各族文化政权)。
- 精灵：古林/湖林 → 伊莱、绿冠。
- 矮人：山脉岩谷 → 赫塔尔、卡尔萨矿区。
- 地精：丘陵/湿地 → 赤原、伊什拉、裂海岛群。
- 兽人：草原高地 → 赤原、卡尔萨牧道、伊什拉护路、部分港城护航。
- 巨人：高原孤立山 → 塞拉菲尔高原边缘、诺赫兰北山、少数海岸集会地。
- 龙族：极北 —— 几乎不迁，对外仅传说；无迁徙。
- 灰精灵：雾幕山林(22)；蜥蜴人：苇湾→河口/岛链(22)。
