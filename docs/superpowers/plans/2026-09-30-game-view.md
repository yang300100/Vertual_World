# 2D 地图游戏视图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有地图上显示当前地图内全部 NPC，以 WASD 控制玩家，并自动切换世界图与城镇图。

**Architecture:** FastAPI 提供轻量场景快照和服务端校验的方向控制；现有地图底图上加画布人物层。客户端逐帧插值，服务端位置与世界时间保持权威，交谈和交互复用已有 API。

**Tech Stack:** FastAPI、SQLite、原生 JavaScript、Canvas、CSS、Pytest、浏览器交互检查。

**Spec:** `docs/superpowers/specs/2026-09-30-npc-adventures-game-view-design.md`

## Global Constraints

- 只用 WASD 作连续手动移动，不加虚拟摇杆或方向键移动。
- 地图点击寻路继续可用；玩家坐标不能由客户端直接写入。
- 当前地图内全部 NPC 可见，NPC 自身情报权限不受界面影响。
- 保留既有世界图、城镇详图和其他管理界面。

## Review Focus

- 玩家恰好跨过城镇边界：地图切换不抖动，坐标不跳跃。
- 无详图的城镇：仍使用局部视图，玩家标记可见。
- 页面失焦或输入框获得焦点：WASD 不误移动，松键请求不丢失。
- 高倍速或暂停：服务端位置不超速，预测会收敛。
- 上百个 NPC 同屏：标记可定位，快照与绘制不阻塞输入。
