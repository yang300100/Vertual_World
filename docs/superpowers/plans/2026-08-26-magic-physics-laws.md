## Task 4: 模块 A — 场论关系(公式贴合伊瑟拉本质)

**Files:**
- Modify: `docs/worldbuilding/26-magic-physics-laws.md`

**A4.** 用现实物理公式类比但**按伊瑟拉本质定制**,逐条写公式 + 参数 + 一句"为何这样定":

- [ ] **能量守恒(伴生光)** — `E泓 = Esrc · η(光谱,过程)`,η≤η_max 由发光过程定。给参数表:
  - 恒星宽频:η≈0.15-0.25,规模大、相干 γ 低(符合 02"恒星是最大最稳定来源");
  - 火焰/熔岩:η≈0.10-0.20;
  - 雷暴/放电:η≈0.05-0.12,γ 中;
  - 生物发光:η≈0.04-0.10,γ 高(精密态)。
  - 写一句:魔力伴生于光,η 非线性、随光谱/干性变化,故"明亮≠高产出,昏暗材料也可能高耦合"。

- [ ] **几何 + 介质衰减** — `I(r)=I0·e^(−α_s·d)/r^p`。p≈1-2(开阔/波导)。给 α_s 相对值表(五谱系在该介质)示意:物性系 α 小但需连续材料接触、光曜系 α 中、生息系 α 中需近距、热焰系 α 高且被实体墙强吸收。写一句:对应 02"多数魔法先作用于路径障碍、能否穿透看耦合类型"。

- [ ] **干涉叠加(同源相干)** — `I合 = I1+I2+2√(I1I2)·cos(Δφ)·γ`(双缝类比)。同相增强、反相抵消;γ 越高越稳定精确。写一句:贴合 02"相干性决定稳定精密"。

- [ ] **相干度 γ** — 类比相干长度/时间;决定能否稳定干涉与精密长期维持。

- [ ] **耗散与恢复(禁永动)** — `dN/dt = G(t) − L·N − Σ抽取`;停施后一阶回补 `N(t)=N_eq+(N0−N_eq)·e^(−λt)`。λ 受日照/材料/吸收源影响(见模块 D)。写一句:贫魔区=抽取>供给,N 持续下沉;正因如此,永动自充必在真实消耗来源。
