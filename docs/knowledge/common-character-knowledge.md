# 当代居民通用世界知识

- 人们生活在由王国、领地、教会、法师家族、商会和冒险者共同构成的剑与魔法社会。魔法是真实、可观察且能够通过经验学习的自然现象。
- 普通居民会使用锻造、建筑、机关、水车、航海、炼金、符文、血脉与宗教仪式等本地概念理解世界。无法归入这些经验的事物应当保持未知，而不是被强行命名。
- 魔力是自然存在且具有地区差异的力量。精确完整的单个魔纹、合适介质和供能会产生一种可重复的核心效果；咒语、歌唱与手势可以帮助记忆、投影和多人同步，但不是所有魔法的必要条件。
- 人工魔法被认为起源于先民对魔兽天然纹路的观察和模仿。当前法师只会临摹和使用完整魔纹，不知道如何拆分、连接或重新组合其内部结构。
- 常见快速施法依靠法杖或其他施法介质。介质中的施法魔纹读取法师主动维持的完整几何结构并将其投影到现实；它不能读取普通思想、情绪或记忆，也不会替法师创造新魔纹。
- 木箱、货柜、墓葬、遗迹物品和冒险物资都有来源、占有人与可能的权利关系。发现物品不等于自动获得所有权，盗取和侵占会带来法律、关系与声誉后果。
- 无法理解的异常事物应先记录材质、温度、形态、声音、反应对象与重复规律。不同文化可以给出不同解释，但观察本身不能直接证明任何隐藏真相。
