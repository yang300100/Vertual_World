# 当代居民通用世界知识

- 人们生活在由王国、领地、教会、法师家族、商会和冒险者共同构成的剑与魔法社会。魔法是真实、可观察且能够通过经验学习的自然现象。
- 普通居民会使用锻造、建筑、机关、水车、航海、炼金、符文、血脉与宗教仪式等本地概念理解世界。无法归入这些经验的事物应当保持未知，而不是被强行命名。
- 晴朗夜空中能够观测到一道横贯天穹的暗银色弧带。不同文化可以称其为天环、神迹、第二天穹或星痕，并围绕它建立历法、航海经验、宗教和神话；各文化没有得到经过验证的统一解释，也不会从中收到知识或指示。
- 魔力是自然存在且具有地区差异的力量。精确完整的单个魔纹、合适介质和供能会产生一种可重复的核心效果；咒语、歌唱与手势可以帮助记忆、投影和多人同步，但不是所有魔法的必要条件。
- 人工魔法被认为起源于先民对魔兽天然纹路的观察和模仿。当前法师只会临摹和使用完整魔纹，不知道如何拆分、连接或重新组合其内部结构。
- 常见快速施法依靠法杖或其他施法介质。介质中的施法魔纹读取法师主动维持的完整几何结构并将其投影到现实；它不能读取普通思想、情绪或记忆，也不会替法师创造新魔纹。
- 当前单个魔纹是具有方向和比例的二维闭合结构。最终几何决定固定效果，平面朝向决定主要作用方向；绘制顺序不改变功能，最后闭合只负责启动。
- 法师身体不储存施法魔力。个人施法能量来自戒指、护符、手镯、法杖水晶等储能物品；物品耗尽后必须更换或在合适地区重新充能。
- 储能物品会缓慢吸收周围环境魔力。刻有特殊汇聚储能纹的容器可以加快收集并为相容佩饰转移能量，但会降低附近魔力浓度，也不能突破材料容量。
- 光产生时通常也会伴随新的环境魔力。太阳是最主要来源，火焰、雷电和部分生物发光也能提供少量补充；贫魔区会随持续光照逐渐恢复，但反射光和魔法照明不能产生无限能源。
- 法师可以通过已知细节纹路有限调整法术距离和范围。多数魔法会先作用于路径上的障碍，只有震动、声音、热传导等适合相应介质的效果能够继续传播，而且会衰减。
- 大多数王国、部落和城市没有公共魔法能源网络。魔法设施通常属于世家、神殿、工坊、军队或少数共同体，普通居民无法普遍接入。
- 木箱、货柜、墓葬、遗迹物品和冒险物资都有来源、占有人与可能的权利关系。发现物品不等于自动获得所有权，盗取和侵占会带来法律、关系与声誉后果。
- 无法理解的异常事物应先记录材质、温度、形态、声音、反应对象与重复规律。不同文化可以给出不同解释，但观察本身不能直接证明任何隐藏真相。
