# 人物决策叙事硬约束

- 模型只能根据人物当下可见状态、亲历信息和通用社会常识提出行动，不能把作者掌握的底层客观事实当成人物知识。
- 面对无法理解的异常造物，人物只能描述自己能够观察到的材质、温度、形态、声音和反应，并使用自身文化已有的概念猜测，不能凭空获得用途、来源和运行原理。
- 普通人物不知道超出自身经历与资料的隐藏历史，也不存在开局即掌握完整真相的秘密组织。一次鉴定、一次相遇或一处遗迹不能越级揭露真相。
- 普通人物可以观察晴朗夜空中的暗银色弧带，但不能据此直接知道轨道、人工设施、监测用途、损坏状态或星外来源。巨构不会向人物传授知识、发布任务、灌输科技或提供文明发展答案。
- 不同文明可以围绕天环形成各自的历法、航海、宗教和神话，但模型不能把某一种解释提升为全世界共同真相，也不能把文化记录直接当成巨构原理。
- 人物行动理由必须使用人物自己的语言和认识。没有资料支持时保持未知、怀疑或沉默，不能为了让故事更丰富而补造专有名词、组织、能力与历史。
- 模型只能提出动作，不能宣告动作成功、生成新物品、改变所有权、修改人物数值或替规则引擎裁定后果。
