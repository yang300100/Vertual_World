# 全球灰孢潮：全部政体共同应对

哥哥要求新的全球危机必须由所有政体协作解决，并尽量不调用模型 API。当前有效设定以 `29-noryia-nations-and-factions.md` 为准：地图的 21 州包括 20 个政体和无主中立地带；文档另保留阿德伦议约王国地方政权。因此验收包括全部 21 个政体，中立地带作为会议场所，不冒充一个国家。

## 危机与必要协作

构造「风携灰孢潮」：灰孢影响各地粮场，各地留存不同菌株的检验样本。完整抑制剂必须利用所有 21 个样本，分三批进行低魔工坊加工，再合制 21 份；遗漏任一地区会遗漏菌株，不能获得全球适用成果。抑制剂实际运回各国并由当地 NPC 施用后，该地粮场恢复；全部政体完成、观察期通过才解除全球危机。

这是测试事件，不是写入世界观正典的既往历史。只使用公开生物观察、工坊制作、传统驿运与外交，不引入龙族干预、隐藏科技或跨国公共魔法网络。

## 人物与自主流程

每个政体各有一名当地检验员和一名有救灾授权的使节。使节因事件前的例行贸易会议已在中立会场附近，各带本国留存样本；检验员仍在真实首都。另有中立工坊协调者，共 43 名 NPC。初始事实不包含救灾目标、签署、转交或制作完成。

当地 NPC 目击粮场灰孢，选择按既有通信地址向本国使节寄报告。驿运是有距离、时间、地址、实物托管和收取条件的运输抽象：送出是 NPC 行动，到达由正常世界时间结算，不能瞬间获知远方报告。现阶段不把每一段驿站劳工作为单独人物模拟。

使节收到报告后实际走访工坊协调者并交流。协调者只有收到具名风险报告才提出合作方案。使节依据自己的授权政策独立评价分配、技术共享和主权条件；不满足条件时明确拒绝并提出修改。协调者据已听到的反馈修订方案，旧版签署不得替代新版。使节知悉有效方案后签署，并通过现有实际 transfer 行动交付本国样本。

协调者依据实际库存，通过现有 craft 活动分批加工、合制抑制剂、领取成果，再分国托管寄送；当地检验员收到实物后自主施用。NPC 的动机、来源事件、行动、拒绝、库存变化和实际结果均入库。

## 完成与反事实核验

- 政体名单须与当前完整目录相符，包括保留的地方政权，不抽取少数国家。
- 每个政体有当地目击、报告实际送达、沟通、新版同意和真实样本交付证据。
- 全部样本实际消耗，三批加工与最终合制有正常活动完成证据；只修改库存不能伪造成果。
- 每个当地接收者实际收到并消耗一份已制作抑制剂；等待观察期后恢复生产。
- 缺任一政体的签署、交付或施用都不能全球解决；测试遍历全部成员验证该门槛，并实际模拟一国不参与的失败世界。
- 假冒使节、远距签署、未知方案、旧版同意、未来邮件、重复施用、未制作实物均被拒绝。
- 测试阻断 HTTP 请求；演示不读取 `.env`，规则决策且关闭世界代理，独立存档不碰主存档。

## 实现边界

新增协作危机与驿运领域服务，接入既有心跳、NPC 目标/规划器与领域执行。生产受阻区间复用既有危机经济核算；不扩大原维修危机的特殊规则。独立脚本输出可读报告、JSON 与数据库，完整列出所有政体证据。

## 已验证的模拟结果

全部政体正例在 1830 个世界小时（76.25 天）完成：21 个报告送达、21 次实际现场报告交流、21 个当前版本同意、21 份实际样本交付、四次制作完成、42 个报告/抑制剂包裹实际送达、21 次当地消耗施用和 21 处观察恢复。初版方案被拒绝一次，协调者依据反馈修订至第二版。继续推进 24 小时后，全部 21 处粮场均有真实再生事件。独立证据位于 `run/cooperation-final-evidence/test_all_polities_actually_coo0/`。

实际 `state-13` 拒绝参与的反事实推进 1200 个世界小时：21 个报告送达，只有 20 个同意和实际样本贡献；制作、施用、恢复和受阻粮场再生均为零，危机保持 `active`。独立证据位于 `run/cooperation-final-evidence/test_a_nonparticipating_polity0/`。正例还逐一撤去全部 21 个成员的签署、贡献和施用证据，63 次检查均不能全局完成。

两例均阻断 HTTP 发送且使用规则决策，用户模型 API 调用为零。这里的自主判断是角色依据自身政策与已知事实进行有限步规划；开放式模型外交推理尚未在本轮验收。
