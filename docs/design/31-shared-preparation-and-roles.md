# 共同筹备与独立分工

玩家和既有 NPC 可以商量一件具体的生活筹备事项，各自承担明确份额，再到真实地点共同核对。当前支持劳动筹钱和备齐本人食物。完成只表示筹备条件已实际核对，不登记出行、用餐、赠与、共有财产或新的亲密关系。

## 独立同意与条件

`SharedPlanIntent` 通过 `shared_plan_intent` 接入 NPC 当面回应、多人交谈、信笺与主动联系；玩家从自然表达或人物档案的“一起筹备与分工”提交自己的选择。

新提议需给出名称、真实核对地点、可选房间、明确期限和双方分工。`own_task` 属于提议者本人，`other_task` 只是向对方提出的职责，收到提议的人独立接受或拒绝。接受时不能暗改条款，也不能接受自己的提议。

期限为一世界小时至三十世界日。规则复核当前活动、路程、完整劳动时间和房间出入权；用于共同筹备的室内地点需要双方已有相应权限，不延长单次访问许可。每个人同时最多参与一份生效的共同筹备，避免重复承诺同一份劳动和资源。

任一方可以结束已经确认的筹备，提议者可撤回待回应的提议。已发生的劳动、工资和采购保留，不通过取消凭空返还资源，也不强制取消本人已经开始的工作。期限到达只记筹备过期，不补写完成或推定故意失约。

## 两类份额

- `earn_money`：目标1至500枚。仅接受确认之后真正开始、完成并得到报酬的工作活动，且本人目前仍持有至少约定金额。已有积蓄、赠与、只有台词的工作、未完成活动以及接受前已开始的工作不计入。使用世界时间和确认事件的真实创建时序共同核验，避免暂停时间时把旧工作算成新劳动。
- `prepare_food`：目标1至12份。核对本人随身携带、归本人所有、完好且未变质的可用食物；本人已隔离或留存的批次不计入。既有真实库存可以满足备食责任，不要求无意义地再买一次。

工资来自原有工作场所预算和实际工作结算。`preparation_work_receipts` 为活动保存唯一回执，既不重复发工资，也不让同一活动被多个筹备计划重复认领。分工本身不扣款、不托管物品、不转移所有权。

## NPC 自主履行

接受分工后，NPC 在现有自主生活调度中推进自己的职责。饥饿、休息、照护孩子、已有活动和已确认赴约继续按原规则处理。为共同筹备专门发起的工作每天至多两次，每次仍需真实一小时并遵守原有劳动额度；本人其它实际劳动也可以提供有效回执。

备食可以使用本人既有库存、合法资源来源或现场真实卖家的库存。`spending_limit` 是该分工授权 NPC 自主采购的累计上限，0表示不授权这类自主采购，同时保留本人基本生活资金。玩家购买始终由本人另行操作，不因分工自动花费玩家钱包。

路程沿既有移动、出门和逐层进门规则执行。未满足的货源、预算或工作条件保存在 NPC 本人的筹备上下文中；困难或临近期限可以产生一次主动联系机会，NPC 自主决定是否解释、调整或退出。

## 到场核对与认知边界

`check_in` 只核对本人份额，需本人实际到达约定地点或房间、结束当前活动并满足职责。核对表示保留一天；过久后需要本人重新核对，也可用 `withdraw_readiness` 撤回上次表示。

双方各自核对过、实际在指定场景20米内、当前资源仍满足且没有正在进行的活动，才记录共同筹备达成。后续真实共同经历进入长期关系记忆，但不会额外发放工资、亲和、信任或房屋权限。

对方没有报告的私下进度、支出与顾虑不显示给玩家。本人可以看到自己的实际进度；另一方只能看到已商量的职责及其本人曾经明确核对的事实，不能借筹备页面查看完整钱包或私人库存。

## 接口与运行验证

使用现有幂等 `/player/social-choices` 保存明确原话与本人选择，新字段为 `shared_plan_choice`。旧关系、家庭、约会与周期回执仍兼容。`GET /shared-plans?character_id=...` 按当前人物筛选，避免其他人的历史记录挤掉当前待回应计划。

真实模型验收中 NPC 先要求讲清楚出行目的，明确条款后才提出分工。玩家接受并核对食物，NPC 完成真实一小时工作取得12枚，再共同核对完成。玩家钱包和食物没有被自动消费或转交。浏览器验证分工确认、等待劳动及最终达成状态，正式玩家未被代为接受计划。

本轮同时修复普通人物扮演的接口契约：非推理模型明确关闭默认推理，并约束 JSON 对象输出，避免短回复预算全被隐藏推理耗尽，或把真实选择只留在裸台词里。推理专用模型保持原有接口路径；异常输出仍不得作为世界状态执行。

当前不包含共同制作、施工、托管物资分配或自动组织出行；这些仍需独立的规则和双方授权。
