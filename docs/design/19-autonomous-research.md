# 冻结运行中的人物自主研究

哥哥要求的新边界：可以在运行前补齐通用能力，正式运行后助手只观察，不改程序、灾害参数、人物方案或库存。具体研究问题、实验取值、安装选择、通信对象与应对流程必须来自 NPC 的模型输出，或其实际收到的同行实测方法。

## 通用能力与初始事件

`research_physics.py` 是固定的、可重复检验的共振器模型。它描述可调供能、工坊相对调谐档位、屏蔽和材料响应；没有研究程序、国别解法或配方。自然法则依据世界观的魔力波、材料响应与单纹低魔边界，但这是一个有限的数值模型，不是完整流体、气候或魔法场模拟。

灾前世界有全部 20 个正式政体和保留的阿德伦地方政权，每处设一台日常公共取水纹器、两位常驻工坊人员。技师和学徒有一般职业技能、日常公共服务目标、正常粮食库存与既有行业通信名册。没有预先指定 API 使用者、研究负责人或救灾分工。实验储备是装置独立的有限数值账户，不是经济系统的物品库存。

新事件“回响潮”只改变共同环境激励，并让现场人物目击本地仪表和取水表现。没有登记救灾配方、合作危机步骤或人物研究程序；远方灾情、隐藏材料参数与响应公式不进入人物输入。灾前存档会保留为 `baseline-world.db`。

公共安全标准在灾前已存在。任何装置持续危险都会使共享背景干扰保持危险，所有装置都必须满足安全与实际供水标准，连续维持 24 个世界小时才算恢复。关闭公共服务不能通过验收。恢复依据实际状态，人物的文字结论不改变状态。

## 人物判断与真实执行

模型只提交带理由的有限程序，操作界面只有测量、指定参数实验、调节已有装置、联系既有收件人和等待。操作界面不包含灾害解决步骤。

请求附带执行器实际生成的 JSON Schema，明确每步的 `op` 字段和参数数组。解析仅兼容 `action` 作为缺省 `op` 的等价写法，以及调节动作中单组参数对象的数组包装；不补步骤、不推断参数、不丢弃歧义或额外字段。失败轮次的已付费响应可离线检查格式兼容，但不会注入后续正式世界。

人物自行选择实验取值、研究时长、候选选择指标、最低供给约束，以及是否向谁分享方法。隔离试台不改变运行装置。后续选择只能使用已经完成的真实实验；不能引用想象中的结果。

研究进入现有持续活动表，占用人物的实际活动时间。执行按最多四小时的劳动段推进，真实扣减精力并受身体、位置、移动和其他活动约束。长实验会保留已完成的分段结果；中断劳动不会作为已经完成的实验。储备在劳动开始时消耗，并记录前后值。

信件按大圆距离、20 km/h 驿运和两小时装卸计算，收件人到期在地址上才能收到。死亡或逾期仍不回址的收件人不会永久占住调度。通信未模拟逐段道路、地形绕行与驿站劳工。

收到的实测程序可由通用证据采纳规则接受：接收者本地仍有需要、没有正在执行的程序，且方法必须先在本地实验，再按本地实测选择。不会直接照搬另一台装置的设置。这部分是确定性的程序判断，不是每个接收者都调用模型作开放式外交判断。

## 节省模型开销

程序根据本人的已知异常、可用技能、已有可执行方法和新证据选择需要 API 的人物。没有指定人物名单。执行已有程序、等待可送达的实测方案时，优先推进普通执行。重复事件编号但测量相同不会被当作新研究证据。

研究后端不自动重试。调用前在数据库内预留次数和保守 token 额度；失败也占用次数，用量未知时按预留额度计入预算。响应解析前就保存提供方的 input/output tokens，截断与格式失败也保留已知消耗；未知不能写成零。默认至多 24 次、60000 tokens；输出上限沿用 `DEEPSEEK_MAX_OUTPUT_TOKENS`，默认 8192，包含模型推理与最终正文。上下文容量与输出上限是不同限制。额度是停止继续花费的边界，达到额度不等于任务成功。

接口截断、空正文、格式或传输错误会记录底层原因、HTTP 状态、finish_reason 与经过凭据遮蔽的响应诊断，停止本轮研究请求并导出失败报告，不换另一位人物重复消耗。人物提出的结构化程序如果在实际操作校验中失败，仍按原有程序与新证据规则处理，不因技术故障自动补写研究方案。

正式运行使用普通 WorldEngine 心跳；独立存档中普通生活和已有动作仍由规则执行，研究模型按需调用。主存档不参与此次灾害模拟。

## 冻结与证据

初始事件注入后，每轮核对 Python 源文件集合和内容。运行存档每个事务核对上一提交的快照；外部修改会停止运行，不能被算作 NPC 自主结果。模型请求在数据库事务外进行，因此长请求期间的外部修改也会在下一事务被发现。

`freeze.json` 记录源码哈希、灾前装置状态、模型名称与调用/输出边界。`report.json` 保留模型请求资料、解析后的模型提交、人物程序、原作者、传播来源、执行事件和储备证据；活动与身体变化可在数据库中核验。`diagnostics_json` 保存响应状态、终止原因、用量相关信息与最多 64000 字符的响应片段，经过凭据遮蔽。`report.md` 提供各政体真实干扰、服务和执行情况。

离线检查使用假后端验证通用执行，不把测试里的方法带入生产场景。真实模型是否能提出有效方法以及灾害是否恢复，必须以正式冻结运行的存档和报告为准，不能用假后端结果代替。

## 使用

只构建初始事件，不花 API：

```powershell
.\.venv\Scripts\python.exe -m scripts.demo_autonomous_disaster --init-only
```

正式自主运行，会按需消耗配置的模型 API：

```powershell
.\.venv\Scripts\python.exe -m scripts.demo_autonomous_disaster
```

禁止模型的负例：

```powershell
.\.venv\Scripts\python.exe -m scripts.demo_autonomous_disaster --offline --hours 72
```

这些命令均创建新的独立目录与存档。运行后不修改参数或填入方案帮助人物成功；如未解决，报告实际未解决状态。
