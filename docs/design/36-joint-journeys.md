# 有限共同旅行

共同旅行衔接已经存在的人际关系、真实地点与各自日常生活。它保存双方明确同意的一份有限路线，每一程仍由玩家本人选择开始，不因邀请、答应或台词而直接移动。

## 同意与行程

`JourneyIntent` 支持提出、接受、婉拒、出发、暂停、恢复与结束。新提议指定集合地点、半小时至七个世界日内的明确期限、一至六个站点及各站零至一百二十分钟停留；只有明确选择返程才附加回到集合点的一站。

提议只能使用本人当前所在或确实到访的有效地点，同一空间层的相邻站点至少相隔五十米。回应引用真实行程编号，不能偷偷修改路线、停留或期限。每人同时最多保留一份已确认而未结束的旅行。

`joint_journeys` 保存双方、条款与状态；`journey_stops` 记录真实到站与停留；`journey_legs` 将每次尝试绑定到双方各自的移动回执。请求编号重试复用原结果；任一人的出发失败，整组移动及出发记录回滚。

## 集合与真实移动

双方必须实际到达集合处、互相二十米内、位于室外、起身、空闲并能徒步。身体、作息、家庭照护、已确认约定和既有活动继续限制出发。NPC 先完成自己的事务，再自行沿真实路线前往集合点；到后最多等一个世界小时，未开始则暂停。

每人保留自己的真实起点与路线，按较慢一方同步抵达时间，不复制坐标或瞬移。最后一站也要完成停留才能记录完成。已在下一站的一方可以原地等候另一方实际走到；双方都已在站点时只核对真实到站，不重复制造移动。

正式确认只支持两人、同层、室外徒步。食宿另行商量，调用既有用餐、休息、交易、住房与许可规则；旅行不自动采购、赠与、花钱、订房或开放私人空间。

## 暂停、恢复与退出

双方均可暂停或结束。暂停只取消本行程绑定的移动，保留实际位置、已走路程与财物；停留计时冻结，恢复后继续剩余时长。恢复须一方请求、另一方明确同意，并重新实际会合；停留期间恢复须回到原站点。

身体需要、睡眠、家庭照护、赴约、场景或交通方式变化、离开共同场景会暂停。自由选路或方向移动需先暂停；NPC 自主选择另一条有效路线时释放原旅行，无效选择则连暂停一并回滚。结束旧旅行不取消后来独立开始的无关移动。

到期保留实际结果；地点不可用则结束，不冒充完成或自动送回。停留结束再等一小时仍未出发也会暂停，释放彼此日常安排。主动攻击结束本次共同旅行。

## 关系连续性与表现

真实完成写入共同事件与各自主观记忆，不额外增加亲和、信任或钱物。NPC 可自行把完成旅行作为持续事项得到回应的证据，规则核验真实完成记录；它不强迫原谅。

可以关联双方已完成的共同筹备，但筹备不替代旅行同意、身体条件或当前资源，已开始兑现的来源不能重复引用。普通交谈、信笺与主动联系均可提出本人旅行候选；规则结算后才显示结果。

人物档案的“一起走一段旅程”展示集合、逐站停留、返程、期限、实际到站与恢复状态，提供玩家自己的操作。NPC 私有集合等待计时不向玩家导出。

## 验收

验收记录见 `run/joint-journeys-regression-final.log`、`run/joint-journeys-model-proof.json` 与 `run/joint-journeys-verification.json`。真实模型、浏览器和正式服务的验证结果以这些产物中实际记录为准。独立评测地图不写入正式世界，正式玩家不被代为接受、旅行或补资源。

311 项相关回归通过，最终 68 项旅行、约会与同行回归以及 30 项旅行专项通过；另有 159 项输入链路回归。独立浏览器存档已经完成两站实际停留与返程，并验证了取消移动会同时暂停双方。真实模型解析出了玩家的完整有限路线；初次回应选择先询问旅行目的，后续供应商多次返回空白内容，原提议保持待回应，不能宣称首次接受已经通过真实模型验收。

页面的初始接受使用明确标注的隔离测试情境。其后的暂停与恢复由页面提交玩家本人选择，再由真实模型独立提出 `resume`，实际结算为恢复；没有代替玩家开始下一程。三程均由页面分别选择出发，并由真实移动、世界时钟和停留回执完成。两种同意来源分别保存在 `run/joint-journeys-ui-context.json` 与 `run/joint-journeys-ui-proof.json`，不能混称为全程真实模型接受。

正式存档已备份，三个新表、API 健康检查与后台心跳通过；正式旅行数及新增测试人物数均为零。当前正式提示快照估算为 7589 token，保留原有 8192 输入上限。正式大存档还暴露了到访地点查询的重复扫描，现将世界时间约束改为固定参数，避免按地点反复扫描全部事件；只读查询实测约 5.8 秒，正式 API 约 6.0 秒，已在正式浏览器核验完整表单及先探索地点的约束。

尚未实现多人旅行、共乘、跨空间层旅行和自动食宿安排。
