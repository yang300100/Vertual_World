# 内核完善：认知、物品、外部调用与长期事务

更新日期：2026-09-06。本文记录本轮实际实现及边界。

## 记忆与认知

记忆整理只接受事件的参与者和事件载荷中明确保存的
`witness_character_ids`。当前同地点或当前主视角可见，均不构成过去目击的证明。
模型返回的候选同样必须通过人物、事件和叙事边界校验。
没有目击记录的旧事件采用保守规则，不根据当前坐标补造目击者。

事件写入时通过 SQLite 触发器在同一事务中创建 `memory_jobs`。
worker 的低优先级任务批量消费队列，不在裁判请求里同步整理最近事件。
状态为 `pending -> processing -> done/failed`；失败退避重试，最多三次。
五分钟领取租约过期后可恢复，提交还需核对领取次数，过期执行者不能覆盖新结果。
同一人物已有该事件记忆时不重复生成听闻副本。

失败超过上限后，可通过以下接口重新入队：

```text
POST /api/worlds/{world_id}/agents/memory-jobs/{job_id}/retry
```

## 物品与库存

- 默认背包容量为两格，人物字段 `inventory_capacity` 可保留个体差异。
- 容量计算使用物品类型的 `slot_size`、`stack_limit` 和实际数量。
- 同类、同品质、同所有者且未满的堆叠可合并；消耗品一次只扣一份。
- 购买、出售、转交均转移真实库存。商人没有库存时不能凭空售货。
- 新物品与旧库中已持有物品记录 `owner_character_id`；已有明确所有权不覆盖。
- 拾取不能拿走他人物品；放下物品保留所有权。武器和护符分别限制一个装备位。
- `use` 元数据的 `operation=unequip/drop` 支持卸下或放下。
- 使用、拾取和交易写入 `inventory_changes`，保存前后状态并关联来源事件。

没有自动给真实世界的商人补造库存，也没有扩展完整生产、补货、赃物、仓库系统。
旧物品若已经超容量或超堆叠上限，迁移保留现状；新增接收操作仍遵守容量规则。

## 模型调用

外部调用使用有并发上限的后台线程，超时后调用方立即回退或返回错误，
不因线程执行器退出而重新等待。无法强行终止的网络请求继续占用有限槽位，
直到其网络超时或正常结束；迟到的结果不提交世界状态。

协调器实际使用 `WORLD_AGENT_TIMEOUT_SECONDS` 和 `WORLD_AGENT_MAX_CONCURRENCY`。
联络信笺、远程回复、长期事务审阅和战斗战术推理均在数据库写事务外执行。
社会交互提交时重新核对世界版本，过期回应返回 409，不写入旧决策。

## 长期事务

仍保留“提交、NPC 回应、玩家确认、原子执行”的入口。
`long_term_operation_requests.status=applied` 表示确认步骤已执行；
真实履约状态由关联的 `contract_fulfillments` 单独记录并返回前端。

| 类型 | 可执行条款与实际行为 |
|---|---|
| 借贷 | `payment` 为本金；`direction=borrow/lend` 指向 NPC 借入或借给 NPC。确认时校验出借方资金。到期自动还本；不足时保留逾期债务，后续心跳重试。支持主动结清，重复结清被拒绝。第一阶段不计算利息。 |
| 委托、雇佣 | 需明确 `fulfillment_action=work`、`work_units`。报酬先托管；在有效工作场所取得足够实际工作完成事件后支付。开始赴工、尚在路上、被拒绝的行动均不算完成。一个事件只能用于一项事务。 |
| 约定 | 以双方在约定地点实际交流为证据；未发生交流不会仅因时间经过而完成。 |
| 租赁 | 当前支持 NPC 拥有的可用载具，使用 `vehicle_id`。租金预付，提前结束不自动退款；使用权独占但所有权不转移。到期停止租用行程，保留当前位置并恢复徒步，不瞬移返还。 |
| 学习 | 继续保留 NPC 技能校验及玩家确认后的既有教学流程。 |

期限使用 `duration_days`（世界日，默认七日）；工作地点可指定 `location_id`，
未指定时采用 NPC 最近的有效工作场所。补充文本可供 NPC 理解，不能代替可验证的履约条件。
因此自由文本中的任意建设成果、复杂修理或权属变化，不会自动被当作普通工作结算。

未完成工作结束时返还托管报酬；借贷必须结清本金才能结束。
结束事务后，沿用既有产品行为移除该事务卷宗、派生待办与相关记忆。
旧版已确认事务没有可靠的履约信息，因此不追溯补扣资金或自动生成履约记录。

```text
POST /api/worlds/{world_id}/long-term-requests/{request_id}/repay
```
