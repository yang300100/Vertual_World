# 挂起载具内的本人照护

共乘途中挂起后，已真实登车且仍有表达能力的本人，可以在载具真实静止时自行休息或等待。休息沿用既有生活活动的世界时间和身体规则；真实地点可以为空，不能把出发港口当成当前位置。安全下车会在同一事务中结束本人的车内活动；恢复或交接启程时仍会逐人核对活动和有效授权。

NPC 只可自行选择休息，或使用自己实际拥有并随身携带的食物、药物。规则核对真实登车来源、同层同位、静止状态、物品、身体和世界时间；食物沿用保质期与物质账，药物沿用已有治疗规则。来源回执阻止同一选择重复消耗，动作与回执在同一事务内结算。未执行或被拒绝的候选不会被展示为已发生的事实。远程对话、旁人和没有结构化本人选择的台词都不能替本人执行。

车内社交和 NPC 回应记录载具的实际地点；途中没有地点时记录为空。人物与载具位置不一致时，本次行动或回应回滚。目击仍依据实际距离计算，不把旧港口上的人当作车内听众。

车辆仍有真实在车乘员时不能被移除，须先由各人安全下车。新发起的旧单人载具选择、路线和方向输入也会检查已定义的有限燃料；在消耗结算实现之前拒绝免费启用。已在运行的旧路线及方向仍沿用原规则，并未补做燃料结算。

现有世界中 NPC 生命值归零关联死亡处理；玩家战斗败北另有既存的苏醒规则。世界尚未建立可核验的非致死无法回应状态，本阶段不把低生命值、未回复或模型失败当作昏迷，不提供代他人救援或自动救活。真正的无法回应者救援、有限运行资源结算、真实 NPC 独立选择与完整共乘样本，仍需要后续实现和验收。
