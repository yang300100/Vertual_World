# 已确认规格与真实燃料装卸

本阶段为 G7 的有限运行资源建立基础。编年者可为同世界、已核实且停靠的车辆提交燃料规格，明确燃料物品类型、油箱整数容量及每公里消耗的有理数；提交后必须另行确认。规格不产生燃料，不能覆盖既有规格、车辆来源或旧 metadata，也不能作用于有未结束共乘、乘员或运行路线的车辆。

规格是编年者确认的世界设定。来源事件必须在车当时所在地点并明确指向该车；事件本身不证明容量或消耗率经过实际测量。登记、原车辆和物品类型的确认事件及规格效果在装卸前重新核验，不能采用未来、丢失或已被改写的来源。

当前车主或有效租客在真实静止车辆附近，可按已确认类型把本人实际拥有的燃料批次装入车辆，也可取回属于自己的批次。真实物质批次、物权及分批状态保留；容量、人物位置和权限在事务内核验。每次装卸同时写入物质账、事件、库存变化和幂等回执；重试原请求不重复转移。车辆有燃料时不能移除，须先由各物主合法取回。

取回也需要当时仍有有效车辆使用权和可核验的登记来源。租约失效、原车或规格来源失效时，自己的燃料暂时保留在车内，当前没有受持有人授权的返还流程；车主不能因此取走他人的燃料。后续需提供合法返还路径。同一种燃料物品的批次质量可能不同，当前容量只按物品份数计，不能直接把每份视为等量能源。

界面仅列出本人当前可操作的车辆与个人批次。结果未知时保留原请求编号供重试，不能自动创建第二次装卸。规范的已确认规格与旧 metadata 中含燃料定义的车辆仍禁止发起免费行驶；分段消耗、耗尽时挂起、重新补给和续程尚未实现。已运行旧路线不回填虚构消耗。

玩家战斗败北已有专门的苏醒规则；NPC 归零后的旧快照不能继续自服药、进食或执行舞台动作，受伤存活者仍按原规则行动。未建立可核验的非致死无法回应状态，不能把未回复或低生命值视为昏迷。
