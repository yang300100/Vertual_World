# 共乘途中驾驶交接

本阶段接续 G7 的挂起恢复，支持原在车成员都能够表达选择时的有限驾驶交接。无法回应者的紧急救援、外部救援人员加入、有限运行资源和跨空间层旅行仍待完成。

## 保留原路线与原选择

只有原路线已经真实出发、途中挂起，且原完整名单仍实际在车，才能提出交接。方案冻结本轮挂起来源、原载具、原路线与进度、原安全目的地、停止请求、原在车名单及各自原登车来源、新驾驶者、合法权利来源和有限的新期限。

原共乘记录的驾驶者字段、旧同意和登车记录均保留。原人物的 `character_movements` 继续作为这辆载具的路线锚；当前实际驾驶者另由有效接管事件确定。车辆和全部在车者仍先结算真实位置，再观察相遇和到站。

## 三种独立决定

提出交接只表达提出者本人的意愿。原驾驶者、新驾驶者和其他在车者各自接受、婉拒或在执行前撤回；旧回应不被覆盖。

载具的真实车主或有效租客必须另行授予本次有限驾驶许可，即使该持有人同时提出方案也不自动授权。许可仅覆盖本次车辆、驾驶者、原路线和期限，不转移所有权、租约、钱物或其他车辆使用权。当前阶段要求该持有人也在原车上。

全员有效接受且合法许可成立后，指定的新驾驶者还须本人选择接管。授权和接受都不自动启动行程。接管前后均核验真实身体、驾驶权、期限、租约、各自承诺、原路线和车辆位置。

## 失效与后续恢复

合法持有人可撤回本人驾驶许可；权利来源变化、租约失效或驾驶者身体不再允许驾驶时，载具在真实位置挂起，全部乘员仍在车上。当前驾驶者身份不会悄悄退回原驾驶者，也不能使用旧授权继续行驶。

已交接后再次挂起，可由原在车者商量新一轮交接。原许可撤销或过期时，同一实际驾驶者也必须取得持有人新授权、各人新同意，再由本人另行接管。原停止请求始终保留。

后续原路线恢复绑定当时实际驾驶者和控制来源，期限不能超出有效驾驶许可；旧恢复记录继续按旧快照核验。交接与恢复在同一世界时刻发生时，按真实事件写入顺序判断当前控制来源，不按最大期限或猜测回退。

## 入口与验收边界

玩家统一 `ride_choice` 与 NPC 的 `ride_intent` 支持提出、各自接受/婉拒/撤回、持有人授权/撤权及新驾驶者单独接管。界面不会把任何一次选择自动变成另一人的同意或驾驶；询问由用户另行发起，失败、空白、缺意图及未回应不补成同意。

当前在车条款、个人偏好、顾虑和其他现行承诺继续保留，8192 输入硬门禁不提高。对没有现行记录且在车期间不可执行的新共同活动、徒步和筹备流程，仅选择当前适用协议；已存在的相应约定仍保留完整规则与事实。

本阶段的受控机械回应只证明规则及真实位置推进，不能证明真实 NPC 的独立意愿。实际浏览器沿用用户已选择的代码与服务验收范围，未运行。
