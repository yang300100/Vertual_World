# 需要、错约与再次联系

当已确认的见面可能因 NPC 自身身体或日程受阻，系统将评估保留为 NPC 本人的真实私人事件，记录本人当时实际地点；评估本身不会自动让远处玩家知道，也不替 NPC 决定说明。后续仅在真实当面或双方已同意且仍有效的信笺渠道下，给 NPC 一个自主考虑是否联系的机会；沉默仍是有效选择。

双方确认的约定已经结束但未共同完成时，NPC 可以基于自己真实知道的原约定，在后续可用联系机会中考虑联系或提出补约；原约与事实保留，补约须由另一方独立接受，实际完成后才记录修复。每对人物每日考虑次数和世界每日成功投递上限维持原规则，不覆盖原来的联系或拒绝，也不猜测对方是否到场、在哪里或为何没来。

饥饿 NPC 只能在实际位置和既有权利允许时购买、采集或吃自己真实持有的食物。无法就地取得时，可依据本人真实知晓的采集经历前往已知地点；也可基于本人当前真实所属、同层且位于其范围内的有效公共城镇，实际走向中心看看。出发决定不读取远处实时库存，到场后才核验现货、权限与身体状态；空地点不会因此凭空产生食物。共同筹备和家庭照护也不能根据未观察到的远处库存选择目的地。

前往熟悉地点寻找食物时，如果已审核地形判定路线不可达，只撤销这一次移动的副作用，保留此前真实的自主目标和受阻判断；之后仍可根据本人实际取得的食物或环境变化重新处理需要。单一候选地点的已知食物查询从人物自己的知情记录开始，仍须核验亲历或目击、时间、资源权利和地点。粗粒度河流格不能证明局部路线可以通行，缺乏可信的岸边路线或渡口时继续遵守现有水域限制；这项处理本身不会生成食物，也不能解决真实的食物短缺。

新世界的基础食物来源从本世界当前时间开始计算再生，不将现实日期到世界日期的差额当成已经过去的生长时间。旧存档中既有来源、库存与历史没有因这个修复而回填或重写。

户外约定以地点中心附近作为个人到场范围，但双方实际共同活动仍需要彼此接近。双方均在范围内、NPC 能实际看到玩家且已确认的约定仍有足够时间时，NPC 可以通过自己的真实路线走近；这不会替玩家开始共同活动，也不会覆盖双方已有的同行安排。无法看到、身体状态不允许、对方正忙或缺少双方亲历的确认记录时，不会触发这一步。

真实模型的错约后自主联系样本、长期连续性及客观世界管理接口的角色权限隔离仍待后续验证或实现；玩家体验、个人日志与个人事件接口按本人知情过滤。
