## 正式内容缺口（已只读核对）

当前正式 `data/world.db`：1世界、32人物、618地点、3种物品类型、2件物品实例。
以下表记录数为0：

- 商品/资源规则 `world_item_profiles`、工资账户 `workplace_accounts`。
- 室内房间 `life_rooms`、家具 `life_fixtures`。
- 生产配方 `activity_recipes`、周期作息 `npc_routine_plans`、准备记录 `npc_routine_supplies`。

因此正式世界还没有按当地设定配置新生活系统的房间、资源、配方和居民作息。
这不是以上模块均未实现：独立存档已验收相应逻辑。原有物品与旧工作地点兼容规则依然存在。
准备记录为空也不是需要模型手填，它应在已登记作息真正执行后由规则产生。

可交给内容模型的是目录、设定依据、5种 Schema 和待审核草案；使用
`run/life-content-packet-20260913.zip` 与[填写说明](../content/life-content-authoring.md)。
官方内容必须继续经过提交和确认，不把模型生成结果直接写成既成事实。
