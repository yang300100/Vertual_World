# 分层地点、自动详细地图与NPC激活设计

状态：第一阶段已实现。

## 地点范围

每个地点包含：

- `area_radius_km`：以地点中心为圆心的归属半径；
- `area_priority`：多个区域重叠时的选择优先级；
- `parent_location_id`：建筑/街区到城镇或遗迹的父级关系。

解析顺序为：优先级高者优先；同优先级选择半径更小者；仍相同时选择距离更近者。因此人物站在粮仓范围内时属于“河畔大粮仓”，离开粮仓但仍在城市范围内时属于“澜誓城”，离开城市范围后成为无名地域。

`characters.location_id`保留为兼容和最近结算地点，实时界面与交互使用可空的 `current_location_id`。移动心跳每次更新精确坐标后重新解析区域，不能用旧地点代替当前位置。

## 详细地图

`world_maps`新增：

- `location_id`：地图绑定的区域；
- `map_role`：`world`、`tile`或`detail`；
- `review_status`：`approved`或`candidate`。

前端按人物预测坐标实时解析区域，并向父级查找详细地图。进入绑定区域自动切换详细地图；离开范围自动恢复世界地图。地图切换不改变人物坐标，也不创造第二份位置状态。

第一张详细地图为澜誓城，包含已确认名称的河务档案区、王室堤岸、粮仓、法师宅区、商旅区、船工区、内河码头、官署、道路、河流和桥渡。名称已确认，几何仍标记为候选。

## NPC激活状态

NPC分为：

- `active`：允许进入自主裁判和模型决策候选；
- `background`：仍存在于客观世界并可被主视角观察，但不自主行动。

激活策略：

- `persistent`：核心人物、掌权者、正式代表及其他特殊人物持续激活；
- `distance`：按与主视角距离计算概率，超过半径后绝不因距离激活；
- `interaction`：主视角点名交谈时临时激活30个世界分钟。

距离概率为：

```text
P(active) = activation_probability × (1 - distance / radius)^1.5
```

每10个世界分钟使用人物ID和时间桶生成确定性随机值，避免每次轮询闪烁。与主角的亲和与信任合计达到100时，无论距离都保持激活。

背景NPC仍随快照返回，前端人物列表和档案明确标注“激活”或“背景”。只有 `activation_state=active` 的NPC会被自主裁判选择；移动中的NPC继续排除在新行动之外。

## 运行边界

- 激活状态是本地规则，不交给LLM自行决定。
- 背景不代表不存在、冻结生理状态或从数据库删除；分钟心跳仍可更新其连续状态。
- 激活只控制高成本行为与模型参与，不改变人物已知信息边界。
- 详细地图和NPC激活变化都必须遵守SQLite世界状态版本与事务规则。
