# 旅途中的长时住宿与完整休息

本阶段将已到站旅行延伸到四至十二个世界小时的同房休息。真实模型、浏览器及本阶段相关回归已验收，正式服务已完成备份、更新和运行核验。旅行、住宿、接待、实际入住与恢复仍分别确认。

## 独立邀请与真实旅行来源

人物档案新增“商量旅途中的长时住宿”，选择双方已真实到站的原旅行、同一停留站点的真实房间、到场时间窗和完整休息时长。提出邀请会暂停原旅行并保存来源；暂停与新住宿在同一保存点成功或回滚，途中或未实际到站的旅行不能使用该入口。

`OvernightIntent` 支持 `propose`、`accept`、`decline`、`cancel` 和 `check_in`。提出时使用真实 `journey_id`、`room_id` 和带时区的 `arrival_world_time`，到场窗为十五至一百二十分钟，休息时长为二百四十至七百二十分钟。到场窗开始必须位于未来一个世界日内，最晚到场再休息完整时长也不能超过原旅行期限。

回应只引用真实 `stay_id`，不能借接受改写房间、时间窗或时长。只有收到待回应邀请的一方可以接受或婉拒；只有本人提出的待回应邀请可以撤回。玩家界面只提交玩家自己的选择，NPC 通过本人结构化输出决定回应，不从台词中的“愿意”推定已执行接受。

新表 `journey_overnight_stays` 保存双方、原旅行、站点、真实到站及暂停事件、房间、到场窗、完整时长、接待者、实际起止、双方活动编号和来源事件。旧约会与共同短休的时长限制保持原值，长时住宿使用独立生命周期。

## 房租、接待与实际入住

房租继续走原住房协商与玩家确认流程，住宿邀请不代订房、不付款，也不替任一方购买食物。房间使用 `AppointmentRoomService` 校验真实租约、管理者、嵌套门路与双方进入条件；有效权限必须覆盖最晚入住至完整休息结束。

`allow_visit` 默认关闭，只能在本人确有接待权时，通过提出或接受明确表达。接受住宿与允许接待是两个独立选择。短时访问只在双方确认、时间有效且接待者实际在约定房间时成立，不写成永久房间许可，也不扩展为钥匙、储物、长期居住或身体接触权限。

双方确认后仍各自逐门进入同一指定房间。NPC 依真实日程和门路赴约；玩家自己开门、进屋，任何人都不能代为移动玩家。只有玩家本人可以在到场窗内选择 `check_in`，双方必须实际在同一房间、当前可开始休息且不存在紧急身体或照护需要。

到场窗起止均允许入住，超过窗末才记为未在窗口内入住。未在窗开始前取得双方同意的邀请过期。晚到不会缩短已同意的休息：实际入住时刻加上完整约定时长，才是实际休息终点。

本阶段的“同房”只表示双方在同一个已获准房间各自休息，没有同床或身体接触的推定，也没有分别入住两间客房的联动流程。

## 活动、身体照护与完成证据

入住创建双方各自真实的 `LifeActivityService` `rest` 活动，并绑定活动编号。精力恢复、饥饿下降、经过的时间和活动中断沿用真实世界规则。住宿不自动进食；开始前需要先处理用饭与身体状态，过程中仍可能因身体或家庭照护中断。

活动完成前先核验租约与接待条件、双方房间和位置、受伤、饥饿、联系界限、家庭照护及活动是否仍有效。worker、主动等候和日程在住宿边界分段推进，不能一次跨过整夜后直接补记成功。对玩家展示必要的泛化原因，不能借中断解释泄露 NPC 私有感受或家庭细节。

取消或中断只结束本住宿绑定且仍在运行的活动，不停止后来独立开始的活动。已经经过的时间和真实消耗保留。只有双方真实完成完整约定时长，才写入完成事件和共同经历记忆；没有额外好感、货币或物品奖励。

状态包括待回应、已确认、进行中、已完成、婉拒、取消、未确认过期、错过到场窗和中断。重启后从持久化住宿与活动事实继续核对；玩家选择仍通过原社会选择回执保持幂等，不因回应模型失败重复执行已经结算的操作。

## 与原旅行及其他日程衔接

待回应、已确认或正在进行的住宿都会阻止恢复原旅行，已确认住宿也进入双方日程冲突及往返房间路程检查。住宿结束不自动退房、传送、付款、离屋或恢复旅行。双方各自离屋并回到原室外站点后，再独立商量恢复并由玩家选择下一程出发。

原旅行结束或改变时，尚未确认的住宿撤销；已独立接受或正在进行的住宿按自身承诺继续核验，不被旅行取消直接强制退房。退出任一安排都保留已发生的世界事实。

## 输入与知识边界

普通对话、信笺和主动联系均可携带 `overnight_intent`，自然语言入口可提出或回应真实住宿。候选输出通过结构化校验，再由本地规则决定是否成立；模型不能修改表中事实或代玩家入住。

NPC 上下文只补入本人可知的活动住宿、房间和已经表达的许可。真实提示在修改前采样，新增规则仍使用原有 8192 输入上限；完整历史保留在存档，不能为长时住宿扩容或泄露 `author_hidden` 信息。修改后的真实提示预算与对话结果已核验，证据见下文。
