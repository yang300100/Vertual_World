# 公共通道上的双人跨层骨架

这一阶段提供受限但真实的两人跨层流程：玩家可以在同一场景向 NPC 提议，各自使用已经建成并有真实开放来源的公共升降通道。两人必须处于正确的出发层、在通道附近及彼此交谈距离内，不能在车内、室内或忙于其他活动。现有短时同行、双人或多人旅行须先由本人结束或退出；跨层不会代替原约定自动授权。

如果尚未到达通道节点，每个人分别选择沿真实路线走近；NPC 的选择由本人在现场对话中提出，玩家由本人操作。移动沿用现有路线和世界时间，不能直接把人移到节点。到达后 NPC 仍需另行选择通过或婉拒；玩家也必须另行选择自己通过。过期、拒绝或任一方中断时保留真实位置，不把另一人的选择补成同意。

NPC 在源层进入通道的实际事件可由当时在场的玩家知晓，目标层事件仍只属于实际观察者；玩家稍后使用通道时不查询 NPC 在另一层的实时位置。双方分别通过只表示两次过渡都曾真实发生，不代表之后仍在一起。撤回、来源失效和通道失败不会制造远处知识，失败事务回滚。

当前只支持已建成的公共升降通道与双人、同方向的有限过程，并非所有空间层、多人跨层或完整跨层旅行。正式世界没有现成的该通道时，界面不会虚构一处或替玩家创建。受控 NPC 回应用于隔离测试，不代表真实模型一定选择同行；真实模型和实际浏览器仍需分别验收。
