# NPC自主科研与科技生长

科研默认关闭。迁移只新增来源表，不产生科技、不启动模型调用。NPC自行提出问题、提交严格程序，进行真实工艺、量器检验、传统对照与两次独立重复。认证后的方法仍需真实实物、供能、劳动与具体版本；依赖来自实际方法调用或可追溯产物，不读取人物声称的父科技。

自然模型是有限近似。它支持常见材料的热传递、结构变化、孔隙、颜料固着等响应，不代表任何自然语言发明都可执行。没有预登记科技名称、配方、研究路线或待发现清单。已有传统陶片、铁件、染色纤维仅用作原世界能力对照。

科研世界心跳按真实事件边界推进，结算劳动、消息与材料，再按需调用人物。科研API显式开启时，引擎其他模型后端关闭。单次运行12次、累计200000 token、输出8192、技术重试0；事先原子预留完整输入和输出，未知用量保留全部预留。普通时钟和饥饿不触发反复调用。停止新请求后，人物已经提交的有限程序继续依正常耗时结算。

`scripts/demo_science.py`用只读SQLite backup建立包含WAL的一致性副本，仅在副本迁移。保留原人物身份、技能、目标、关系与记忆，准备有限工坊与既有熟人/同地渠道。初始无科技和研究程序。冻结源码、世界观、自然规则、初始实物、模型配置和预算。运行配置固定240世界小时、4800心跳观察上限，不承诺突破。

正式运行前必须完成离线验收和独立整体审查，验证摘要保存在计划执行目录。运行使用冻结数据库包装；每个正常事务记录状态摘要和前项链，普通外部库存、配置或源码改动会停止本轮。此为自主性审计机制，并非对抗能任意改写整个数据库及审计文件的攻击者。恢复不会清空调用账目或重发未知请求。

命令使用原虚拟环境解释器，依次执行：

```powershell
python scripts/demo_science.py --source-db C:/Users/14261/Desktop/Vertual_World-main/data/world.db --world-id eb06b024-61f8-4ea8-b4e3-2695e4ccebf6 --output run/science/新时间戳 --prepare-only
python scripts/demo_science.py --output run/science/同一时间戳 --run
python scripts/demo_science.py --output run/science/同一时间戳 --export-only
```

准备和导出不请求模型。运行不调用生图，不写原存档或.env。已停止会话不能恢复付费调用；运行锁须核对进程，禁止开第二份并发实验。

玩家可从“科研卷宗”查看只读科技图、候选、预算与原始过程。`GET /api/worlds/{id}/science`、`technologies`、`technologies/graph`、`technologies/{科技id}/process`、`science/candidates`不调用模型。全局科技图供观察者查看；NPC上下文只含本人知识、实测和真实收到的方法。

导出提供处理过程、全部人物与通信、科技图JSON/SVG、每项突破原始记录、编年、费用、冻结和最终验收。至少3项已验证非预置能力、1条实际依赖及真实后续复用才通过。预算不足或接口失败如实报告，不提高额度，不用离线固定程序成果代替真实NPC判断。
